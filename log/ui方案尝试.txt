## 🧩 分层样式参数（CSS 格式）

### 1. 标题（如章节名、核心抉择）
```css
克苏鲁-标题 {
  color: #E4D9C0;
  text-shadow: 
    2px 2px 0px #2C2321,    /* 深色基底偏移 */
    0px 0px 8px rgba(181, 46, 46, 0.6); /* 血色微光 */
  letter-spacing: 2px;
  font-weight: 900;
  /* 建议搭配衬线字体如 "Cinzel", "Times New Roman" */
}
```

### 2. 正文（描述文本、选项内容）
```css
克苏鲁-正文 {
  color: #C5C0B3;
  text-shadow: 1px 1px 1px #1A1817;
  /* 可选描边 （轻量级） */
  -webkit-text-stroke: 0.4px rgba(44, 35, 33, 0.5);
  line-height: 1.5;
}
```

### 3. 序号（1. / 2. / 3. 或 ◆ 符号）
```css
克苏鲁-序号 {
  color: #9C6B3E;
  text-shadow: 
    0px 0px 6px #D9A13B,   /* 暗金外晕 */
    1px 1px 0px #2E241F;
  font-weight: bold;
  /* 强烈风格化描边 */
  -webkit-text-stroke: 0.5px #1F1A17;
}
```

## 🖼️ 适应不同背景的容器层（核心！）

为了实现「任意场景背景色下清晰可读」，需为选择条目增加 **半透明模糊背景层 + 动态阴影**：

```css
.克苏鲁-选项卡片 {
  background: rgba(20, 18, 17, 0.65);    /* 深底半透明 */
  backdrop-filter: blur(8px);            /* 关键：模糊背景纹理 */
  border-left: 4px solid #9C6B3E;
  border-radius: 12px;
  padding: 1rem 1.2rem;
  margin: 0.8rem 0;
  transition: all 0.2s ease;
  /* 外阴影增加立体感，不依赖背景色 */
  box-shadow: 0 4px 15px rgba(0,0,0,0.5), inset 0 1px 0 rgba(255,255,245,0.08);
}

/* 悬停/选中效果(可选) */
.克苏鲁-选项卡片:hover {
  background: rgba(30, 25, 23, 0.8);
  border-left-color: #B52E2E;
  box-shadow: 0 6px 18px rgba(0,0,0,0.7), inset 0 0 12px rgba(185, 70, 50, 0.2);
}

/* 序号内嵌示例 */
.克苏鲁-选项卡片 .序号 {
  display: inline-block;
  margin-right: 1em;
  /* 复用上面 克苏鲁-序号 样式 */
}
```

## 🌑 场景适应性测试

| 背景示例               | 效果说明                                                                 |
|------------------------|--------------------------------------------------------------------------|
| 深海暗蓝 `#0A1828`     | 模糊层+浅米色文字清晰，暗金序号突出，血色微光形成危险感                  |
| 腐化森林 `#1C2A1F`     | 背景模糊后产生“老旧教堂”感，文字仍保持高可读性                           |
| 诡异白昼 `#E6E2D8`     | 半透明深色层自动提供对比，序号暗金会略微提亮，避免过暗                   |
| 猩红祭坛 `#3A1818`     | 标题血色光晕与环境轻微融合但依然有层次，正文依靠描边不模糊               |

> 💡 若背景极亮（如苍白月光 `#F0EFEA`），可动态增加 `.克苏鲁-选项卡片` 的 `background` 暗度至 `rgba(10,8,6,0.8)`。

```css
  100% { text-shadow: 2px 0px 0px #B52E2E; opacity: 1; }
}
.低理智-选项 {
  animation: insaneGlitch 0.15s infinite;
}
```

## ✅ 总结要点

1. **标题**：骨白+血色光晕，厚重底影  
2. **正文**：暖灰+浅描边，保证阅读  
3. **序号**：古铜暗金+外发光，识别度高  
4. **核心科技**：`backdrop-filter: blur()` + 半透深底 = 通吃所有背景  
5. 可选添加**老照片噪点**、**不规则边缘**或**缓动淡入**强化克苏鲁气氛

这套方案已实际用于 Lovecraftian 风格 AVG 原型，既满足神秘触感，又不牺牲功能清晰度。你可以直接复制 CSS 类名并适配到你的游戏中。
