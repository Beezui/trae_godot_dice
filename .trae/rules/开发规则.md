# Trae CN 开发规则 - 晋升吧骰子项目

## 核心原则

**必须严格遵守现有架构，不得破坏已完成的统一化设计。**

---

## 一、骰子管理（必须遵守）

### ✅ 正确做法
```gdscript
extends Node3D

@onready var dice_manager = $DiceManager

func _ready():
    dice_manager.current_scene = "1001"     # 场景 ID
    dice_manager.dice_count = 3             # 骰子数量
    dice_manager.initialize_dice_pool()     # 自动创建骰子

func throw_dices():
    DiceThrowController.throw_with_charge(
        dice_manager.dice_instances,
        charge_ratio
    )
```

### ❌ 禁止
- 手动实例化骰子：`load("res://scenes/dice_6.tscn").instantiate()`
- 硬编码贴图路径
- 独立的投掷逻辑

---

## 二、投掷系统（必须使用 DiceThrowController）

### ✅ 蓄力投掷
```gdscript
var is_charging = false

func _input(event):
    if event.keycode == KEY_SPACE and event.pressed:
        is_charging = true
        DiceThrowController.start_charge()
    elif event.keycode == KEY_SPACE and not event.pressed:
        is_charging = false
        DiceThrowController.end_charge(dice_manager.dice_instances)

func _process(delta):
    if is_charging:
        var charge_ratio = DiceThrowController.update_charge(delta)
        charge_label.text = "蓄力：%d%%" % (charge_ratio * 100)
```

### ❌ 禁止
- 独立的投掷逻辑：`dice.roll(Vector3(...))`
- 独立的震动实现

## 三、配置管理（使用 JSON）

### ✅ 修改贴图配置

```json
{

    },
    "values": {"0": 1, "1": 2}
  }
}
```

### ✅ 切换配置
```gdscript
dice_manager.current_scene = "skill_10001"
dice_manager.set_scene_config("skill_10001")
```

## 四、场景创建标准

### 必须包含的组件
1. **DiceManager** - 骰子管理器
2. **Camera3D** - 摄像机
3. **DirectionalLight3D** - 光源
4. **Sandbox** - 沙盘（含四面墙）
5. **UI** - ChargeLabel + ResultLabel

### 场景结构
```
NewScene (Node3D)
├─ Camera3D
├─ DirectionalLight3D
├─ Sandbox (StaticBody3D)
│  └─ Ground, Walls
├─ DiceManager (Node3D)
└─ UI (CanvasLayer)
```

---

## 五、禁止事项

❌ **禁止创建测试场景**：`test_*.tscn`, `*_test.gd`  
❌ **禁止修改核心组件**：
- `scripts/dice/dice_texture_manager.gd`
- `scripts/dice/dice_throw_controller.gd`
- `scenes/dice_manager.gd`
- `scenes/dice_6.gd`

❌ **禁止硬编码**：贴图路径、投掷参数、骰子位置

## 六、标准参数值

### 物理参数（dice_6.gd）
```gdscript
mass = 0.5
linear_damp = 0.1
angular_damp = 0.03
gravity_scale = 0.0  # 初始悬浮
```

### 投掷参数（DiceThrowController）
```gdscript
max_charge_time = 2.0    # 秒
max_force = 20.0
min_force_ratio = 0.3
shake_amplitude = 0.05
```

### 骰子间距（DiceManager）
```gdscript
spacing = 1.5  # 标准间距
```
