## 已完成功能

### 1. 角色系统核心代码

#### 目录结构
```
scripts/character/
├── BaseCharacter.gd      # 角色基类
├── PlayerCharacter.gd    # 玩家角色类
├── EnemyCharacter.gd     # 敌人角色类
└── CharacterManager.gd   # 角色管理器 (Autoload)
```

#### BaseCharacter.gd (角色基类)
- 存储角色基础数据 (hero_id, name, 属性等)
- 提供伤害计算、治疗、状态管理方法
- 管理角色骰子引用
- 支持属性值查询 (str/agi/int)
- 血量百分比计算

#### PlayerCharacter.gd (玩家角色类)
- 继承自 BaseCharacter
- 标记为玩家控制
- 提供技能使用检查方法
- 提供属性骰子和技能骰子位置计算

#### EnemyCharacter.gd (敌人角色类)
- 继承自 BaseCharacter
- 标记为敌人控制
- 提供简单 AI 逻辑
- 支持目标选择

#### CharacterManager.gd (角色管理器)
- Autoload 单例，全局访问
- 从 hero.json 加载英雄数据
- 创建和管理角色实例
- 提供角色查询接口
- 支持场景切换时保持角色状态

### 2. Autoload 配置

在 `project.godot` 中添加:
```ini
[autoload]
CharacterManager="*res://scripts/character/CharacterManager.gd"
```

## 使用示例

### 创建玩家角色
```gdscript
# 在任何场景中
var player = CharacterManager.create_character(1, "player")
if player:
    print("玩家角色：", player.name)
    print("HP: ", player.current_hp, "/", player.attr_hp)
```

### 关联骰子
```gdscript
# 创建骰子后关联到角色
player.character_dice = character_dice
player.attribute_dices["str"] = str_dice
player.attribute_dices["agi"] = agi_dice
player.attribute_dices["int"] = int_dice
```

### 伤害计算
```gdscript
player.take_damage(10)
print("剩余 HP: ", player.current_hp)
```

### 治疗
```gdscript
player.heal(5)
print("当前 HP: ", player.current_hp)
```

### 获取属性值
```gdscript
var str_value = player.get_attribute_value("str", 0)
print("力量属性：", str_value)
```
