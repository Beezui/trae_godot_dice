# 晋升吧骰子 - 多个骰子同时投掷功能实现计划

## 项目现状分析

### 现有代码结构
- **dice_6.gd**：骰子核心逻辑，继承自RigidBody3D，实现了单个骰子的物理模拟、结果判定和技能触发
- **dice_demo_script.gd**：演示脚本，控制单个骰子的蓄力投掷

### 现有功能
- 单个骰子的物理模拟
- 蓄力投掷系统
- 骰子结果判定（射线检测）
- 技能触发系统
- 粒子特效

### 限制
- 目前只能一次投掷一个骰子
- 只有两个骰子节点（dice_a和dice_b）
- dice_a用于蓄力显示，dice_b用于实际投掷

## 实现计划

### [ ] 任务1：重构骰子管理系统
- **优先级**：P0
- **依赖**：无
- **描述**：
  - 创建骰子管理器，支持动态管理多个骰子实例
  - 实现骰子池，可配置骰子数量
  - 统一管理骰子的生命周期
- **成功标准**：
  - 能够动态创建和管理多个骰子实例
  - 支持配置骰子数量（2-6个）
  - 骰子池管理正常，无内存泄漏
- **测试要求**：
  - `programmatic` TR-1.1：创建不同数量的骰子（2-6个），验证都能正常初始化
  - `programmatic` TR-1.2：验证骰子池管理，确保骰子正确创建和销毁

### [ ] 任务2：实现多个骰子同时投掷
- **优先级**：P0
- **依赖**：任务1
- **描述**：
  - 修改投掷系统，支持同时投掷多个骰子
  - 为每个骰子生成独立的投掷力和旋转力
  - 确保骰子之间不会相互干扰
- **成功标准**：
  - 能够同时投掷2-6个骰子
  - 每个骰子都有独立的物理运动
  - 骰子之间的碰撞正常
- **测试要求**：
  - `programmatic` TR-2.1：同时投掷2个骰子，验证都能正常物理模拟
  - `programmatic` TR-2.2：同时投掷6个骰子，验证物理性能正常
  - `human-judgement` TR-2.3：观察骰子投掷效果，确保视觉上合理

### [ ] 任务3：多骰子结果判定系统
- **优先级**：P1
- **依赖**：任务1
- **描述**：
  - 实现多骰子结果的同时判定
  - 收集所有骰子的最终点数
  - 处理骰子结果的组合效果
- **成功标准**：
  - 能够正确判定多个骰子的最终点数
  - 能够处理骰子结果的组合（如对子、顺子等）
  - 结果判定准确可靠
- **测试要求**：
  - `programmatic` TR-3.1：测试多个骰子的结果判定准确性
  - `programmatic` TR-3.2：测试不同骰子组合的判定逻辑

### [ ] 任务4：多骰子技能触发系统
- **优先级**：P1
- **依赖**：任务3
- **描述**：
  - 扩展技能系统，支持多骰子组合触发技能
  - 实现组合技能的优先级逻辑
  - 处理技能的同时触发
- **成功标准**：
  - 能够根据骰子组合触发相应技能
  - 技能触发逻辑正确
