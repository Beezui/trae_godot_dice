# 晋升吧骰子 - 动态骰子贴图配置实现计划

## 问题分析

当前骰子系统的实现存在以下限制：
1. 贴图是在初始化时固定加载的，路径硬编码为 `res://textures/dice/dice_face_%d.png`
2. 没有提供动态更新贴图的机制
3. 无法根据不同场景（如投掷场景、技能场景）来动态配置贴图
4. 无法根据骰子类型来动态改变贴图

## 实现目标

1. 支持动态配置骰子每个面的贴图
2. 支持根据不同场景切换贴图配置
3. 确保动态贴图配置与结果检测机制兼容
4. 提供快速验证方法

## 技术实现细节

### 动态贴图配置系统

1. **dice_6.gd 修改**:
   - 添加 `dice_face_config` 字典，格式为 `{face_index: texture_path}`
   - 添加 `update_dice_textures` 方法，根据配置更新贴图
   - 添加 `set_dice_face_config` 方法，设置贴图配置

2. **dice_config.gd 配置文件**:
   - 存储不同场景的贴图配置
   - 示例配置格式：
     ```gdscript
     var scene_configs = {
         "normal": {
             0: "res://textures/dice/dice_face_1.png",
             1: "res://textures/dice/dice_face_2.png",
             2: "res://textures/dice/dice_face_3.png",
             3: "res://textures/dice/dice_face_4.png",
             4: "res://textures/dice/dice_face_5.png",
             5: "res://textures/dice/dice_face_6.png"
         },
         "skill": {
             0: "res://textures/skills/fireball.png",
             1: "res://textures/skills/frost.png",
             2: "res://textures/skills/lightning.png",
             3: "res://textures/skills/heal.png",
             4: "res://textures/skills/shield.png",
             5: "res://textures/skills/strength.png"
         }
     }
     ```

3. **dice_manager.gd 修改**:
   - 添加 `set_scene_config` 方法，用于切换场景配置
   - 实现根据场景配置更新所有骰子贴图的逻辑

### 结果检测兼容性

- 结果检测使用物理方向（射线检测），与贴图配置无关
- 确保射线检测的方向与骰子面的对应关系固定不变
- 贴图配置只影响视觉显示，不影响结果检测

### 测试方法

1. **快速验证**:
   - 创建测试场景，包含场景切换按钮
   - 点击按钮切换不同场景配置，观察骰子贴图是否正确更新
   - 投掷骰子，验证结果检测是否正确

2. **自动化测试**:
   - 编写测试脚本，测试不同场景配置下的贴图更新
   - 测试多个骰子同时使用不同贴图配置
   - 测试场景切换时的贴图更新

## 预期效果

1. 骰子能够根据配置动态更新贴图
2. 不同场景下骰子贴图自动切换
3. 结果检测与贴图配置无关，始终正确
4. 多个骰子能够同时使用不同贴图配置
5. 提供快速验证工具，便于测试和调试

## 风险评估

1. **风险**: 贴图更新可能影响性能
   **缓解措施**: 只在必要时更新贴图，避免频繁更新

2. **风险**: 贴图配置错误可能导致视觉与结果不匹配
   **缓解措施**: 提供验证工具，确保贴图配置与结果检测对应

3. **风险**: 多场景切换可能导致内存占用增加
   **缓解措施**: 实现贴图缓存机制，避免重复加载贴图

3. 修改 `dice_manager.gd`，添加场景切换功能
4. 创建测试场景，验证动态贴图配置功能
5. 测试多个骰子的动态贴图配置
