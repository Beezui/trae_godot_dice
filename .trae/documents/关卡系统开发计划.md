# 关卡系统开发计划

## 📋 需求总结

### 核心功能
1. **全局关卡生成器** - Autoload 单例模式，全局唯一实例
2. **总量控制** - 基础 30 关 + 难度*5，允许±10% 浮动
3. **网状结构生成** - 核心节点构成骨架 + 随机节点填充
4. **可视化验证** - 测试场景展示生成的地图结构

### 技术参数
- **难度系数**：默认 1（后续可扩展）
- **总量公式**：`total_nodes = 30 + difficulty * 5`
- **浮动范围**：±10%
- **随机种子**：支持可重复生成
- **节点连接**：核心节点可一对多分支，随机节点仅串联

## 🏗️ 架构设计

### 1. 全局单例 - LevelGenerator

```
res://scripts/autoreload/level_generator.gd
```

**职责**：
- 加载配置文件（core_nodes.json, random_nodes.json, scenes.json）
- 执行关卡生成算法
- 存储生成的关卡数据
- 提供全局访问接口

**数据结构**：
```gdscript
class LevelData:
    var nodes: Array[NodeData] = []
    var start_node_id: String = ""
    var end_node_ids: Array[String] = []
    var total_nodes: int = 0
    var difficulty: int = 1
    var seed_value: int = 0

class NodeData:
    var id: String
    var name: String
    var type: int  # 1=战斗，2=奇遇，3=交易，4=奖励
    var is_core: bool  # 是否为核心节点
    var position: Vector2  # 用于可视化
    var connections: Array[String]  # 可到达的下一个节点 ID
    var data: Dictionary  # 敌人、NPC、场景等具体数据
```

### 2. 生成算法流程

```
1. 初始化随机数生成器（种子）
2. 计算目标总量：target = 30 + difficulty * 5
3. 生成核心节点骨架：
   - 从 core_nodes.json 中选择初始节点（is_start=true）
   - 根据 next 字段递归构建核心节点链
   - 确保包含至少一个终点节点（is_end=true）
4. 计算需要插入的随机节点数：random_count = target - core_count
5. 在核心节点之间插入随机节点：
   - 遍历核心节点的连接
   - 在每条连接上随机插入 1-N 个随机节点
   - 根据总量控制调整 N 的值
6. 验证所有路径：
   - 检查是否包含起点和终点
   - 检查是否有循环路径
   - 检查路径长度是否在允许范围内
7. 计算节点位置（用于可视化）
8. 存储并广播生成结果
```

### 3. 配置参数化

创建配置文件 `res://config/level_generation_config.json`：

## 🔧 关键技术点

### 1. 核心节点链生成

```gdscript
func generate_core_chain() -> Array[String]:
    var chain = []
    var current_id = find_start_node()
    chain.append(current_id)
    
    while true:
        var node = core_nodes[current_id]
        if node.is_end:
            break
        
        # 从 next 中随机选择一个
        var next_options = node.next
        if next_options.size() > 0:
            current_id = next_options[randi() % next_options.size()]
            chain.append(current_id)
        else:
            break
    
    return chain
```

### 2. 随机节点插入

```gdscript
func insert_random_nodes(
    core_chain: Array[String], 
    target_total: int
) -> Array[String]:
    var full_chain = []
    var random_count_needed = target_total - core_chain.size()
    
    for i in range(core_chain.size()):
        full_chain.append(core_chain[i])
        
        if i < core_chain.size() - 1:
            # 在两个核心节点之间插入随机节点
            var count = randi_range(min_random, max_random)
            count = mini(count, random_count_needed)
            
            for j in range(count):
                var random_node = pick_random_node()
                full_chain.append(random_node)
                random_count_needed -= 1
    
    return full_chain
```

### 3. 路径验证（DFS）

```gdscript
func validate_all_paths() -> bool:
    var start_node = find_start_node()
    var all_paths = []
    var current_path = []
    
    dfs_find_paths(start_node, current_path, all_paths)
    
    for path in all_paths:
        if not validate_single_path(path):
            return false
    
    return true

func dfs_find_paths(
    current_id: String, 
    current_path: Array[String], 
    all_paths: Array
):
    current_path.append(current_id)
    var node = nodes[current_id]
    
    if node.connections.size() == 0:
        # 到达终点
        all_paths.append(current_path.duplicate())
    else:
        for next_id in node.connections:
            if next_id not in current_path:  # 避免循环
                dfs_find_paths(next_id, current_path, all_paths)
    
    current_path.pop_back()
```

### 4. 节点位置计算

```gdscript
func calculate_node_positions():
    var layers = calculate_layers()  # 按层级分组
    var layer_height = canvas_size.y / layers.size()
    
    for layer_idx in range(layers.size()):
        var layer_nodes = layers[layer_idx]
        var node_spacing = canvas_size.x / (layer_nodes.size() + 1)
        
        for node_idx in range(layer_nodes.size()):
            var node = nodes[layer_nodes[node_idx]]
            node.position = Vector2(
                node_spacing * (node_idx + 1),
                layer_height * (layer_idx + 0.5)
            )
```
