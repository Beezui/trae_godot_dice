# 骰子配置动态调整指南

## 问题解答

### Q1: 如果需要更换某个场景内的骰子配置，能直接做到吗？

**答案：可以，完全不需要修改代码！**

当前架构支持三种配置调整方式：

#### 方式 1: 修改 JSON 配置文件（推荐）
```json
// table/NumDices.json
{
  "1001": {  // ← 场景 ID
    "textures": {
      "0": "res://textures/dice/dice_face_1.png",
      "1": "res://textures/dice/dice_face_2.png",
      // ... 修改这里的贴图路径
    },
    "values": {
      "0": 1,
      "1": 2
      // ... 修改这里的点数
    }
  }
}
```

**效果**：
- ✅ 只修改 JSON 文件
- ✅ 无需修改任何代码
- ✅ 重新运行场景即生效
- ✅ 只影响该场景，不影响其他场景

#### 方式 2: 在场景中切换配置
```gdscript
# 在场景脚本中
func change_scene_config(new_scene_id: String):
    dice_manager.current_scene = new_scene_id
    dice_manager.set_scene_config(new_scene_id)
    
# 示例：从数字骰子切换到技能骰子
change_scene_config("skill_10001")
```

**效果**：
- ✅ 运行时动态切换
- ✅ 可响应 UI 按钮等事件
- ✅ 自动应用新贴图

#### 方式 3: 手动配置单个骰子
```gdscript
# 直接设置骰子配置
var texture_config = {
    "0": "res://textures/custom/my_dice_1.png",
    "1": "res://textures/custom/my_dice_2.png",
    # ...
}
var value_config = {
    "0": 1,
    "1": 3,
    # ...
}

dice.set_dice_face_config(texture_config, value_config)
```

**效果**：
- ✅ 完全自定义
- ✅ 适合特殊需求
- ⚠️ 需要写代码

### Q2: 会破坏当前结构吗？

**答案：不会！当前架构就是为动态配置设计的。**

#### 架构分层：
```
┌─────────────────────────────────────┐
│  场景层 (skill_dice_test.tscn)      │ ← 可以任意修改
│  - 添加/删除骰子                    │
│  - 调整骰子位置                     │
│  - 修改配置 ID                      │
└─────────────────────────────────────┘
              ↓ 使用
┌─────────────────────────────────────┐
│  管理器层 (dice_manager.gd)         │ ← 无需修改
│  - 自动加载配置                     │
│  - 自动应用贴图                     │
│  - 自动管理骰子                     │
└─────────────────────────────────────┘
              ↓ 读取
┌─────────────────────────────────────┐
│  配置层 (NumDices.json)             │ ← 经常修改
│  - 贴图路径                         │
│  - 点数配置                         │
│  - 场景 ID 映射                      │
└─────────────────────────────────────┘
```

**修改配置的影响范围**：
```
修改 JSON 配置 → 仅影响该场景 ID
修改场景脚本 → 仅影响该场景
修改管理器   → 影响所有使用该管理器的场景
```

### Q3: 比如需要把 skill_dice_test.gd 原来临时测试的三个属性骰子换成完整的属性骰子？

**答案：可以，有两种方案。**

#### 方案 A: 修改现有骰子配置（简单）

当前 `skill_dice_test.gd` 中有三个属性骰子：
```gdscript
@onready var power_dice = $AttributeDices/PowerDice
@onready var agility_dice = $AttributeDices/AgilityDice
@onready var intelligence_dice = $AttributeDices/IntelligenceDice
```

**如果想更换贴图配置**：
```gdscript
func _setup_attribute_dices():
    # 修改配置 ID 即可
    var power_config = dice_csv_reader.get_num_dice_config("1001")      # ← 改为其他 ID
    var agility_config = dice_csv_reader.get_num_dice_config("1002")    # ← 改为其他 ID
    var intelligence_config = dice_csv_reader.get_num_dice_config("1003") # ← 改为其他 ID
    
    # 后续代码不变，会自动应用新配置
```

**如果想增加骰子数量**（如从 3 个增加到 6 个）：
```gdscript
# 1. 在场景中预先放置 6 个骰子节点
@onready var attr_dices = [
    $AttributeDices/Dice1,
    $AttributeDices/Dice2,
    $AttributeDices/Dice3,
    $AttributeDices/Dice4,  # ← 新增
    $AttributeDices/Dice5,  # ← 新增
    $AttributeDices/Dice6   # ← 新增
]

# 2. 修改配置加载代码
func _setup_attribute_dices():
    var configs = [
        dice_csv_reader.get_num_dice_config("1001"),
        dice_csv_reader.get_num_dice_config("1002"),
        dice_csv_reader.get_num_dice_config("1003"),
        dice_csv_reader.get_num_dice_config("1004"),  # ← 新增配置
        dice_csv_reader.get_num_dice_config("1005"),  # ← 新增配置
        dice_csv_reader.get_num_dice_config("1006")   # ← 新增配置
    ]
    
    for i in range(attr_dices.size()):
        var dice = attr_dices[i]
        var config = configs[i]
        if config and dice.has_method("set_dice_face_config"):
            dice.set_dice_face_config(
                config.get("textures", {}),
                config.get("values", {})
            )
```

#### 方案 B: 使用 DiceManager 动态生成（推荐）

**完全重构为使用 DiceManager**：
```gdscript
# skill_dice_test.gd
extends Node3D

@onready var dice_manager = $DiceManager

func _ready():
    # 设置使用属性骰子配置
    dice_manager.current_scene = "attr_1001"  # ← 属性骰子场景 ID
    dice_manager.dice_count = 6  # ← 设置骰子数量
    dice_manager.initialize_dice_pool()  # ← 自动创建 6 个骰子

func throw_dices():
    # 使用统一的投掷控制器
    DiceThrowController.throw_with_charge(
        dice_manager.dice_instances,
        charge_ratio
    )
```

**优势**：
- ✅ 无需手动放置骰子节点
- ✅ 可动态调整骰子数量
- ✅ 自动应用贴图配置
- ✅ 代码更简洁

### Q4: 或者在新增几个不同的数字骰子或技能骰子？

**答案：可以，非常简单！**

#### 示例 1: 混合使用数字骰子和技能骰子

```gdscript
# 在场景中创建混合骰子
extends Node3D

@onready var dice_manager = $DiceManager

func _ready():
    # 创建 3 个数字骰子
    dice_manager.current_scene = "1001"
    dice_manager.dice_count = 3
    dice_manager.initialize_dice_pool()
    
    # 创建 1 个技能骰子（需要单独处理）
    var skill_dice = create_skill_dice("skill_10001")
    skill_dice.position = Vector3(5, 4, 6)

func create_skill_dice(skill_config_id: String) -> RigidBody3D:
    var dice_scene = load("res://scenes/dice_6.tscn")
    var dice = dice_scene.instantiate()
    add_child(dice)
    
    # 加载技能配置
    var config = dice_csv_reader.get_skill_dice_config(skill_config_id)
    var skill_ids = config.get("skill_ids", [])
    
    # 生成贴图配置
    var texture_config = {}
    for i in range(6):
        if i < skill_ids.size():
            texture_config[i] = "res://textures/skill/skill_" + skill_ids[i] + ".png"
    
    # 应用配置
    dice.set_dice_face_config(texture_config, {})
    return dice
```

#### 示例 2: 使用 DiceManager 的扩展版本

**创建支持多类型骰子的管理器**：
```gdscript
# scripts/multi_type_dice_manager.gd
extends Node3D

enum DiceType { NUM, SKILL, ATTR }

@export var dice_configs: Array[Dictionary] = [
    {"type": DiceType.NUM, "scene_id": "1001", "count": 2, "position": Vector3(-3, 4, 6)},
    {"type": DiceType.SKILL, "scene_id": "skill_10001", "count": 1, "position": Vector3(0, 4, 6)},
    {"type": DiceType.ATTR, "scene_id": "attr_str", "count": 1, "position": Vector3(3, 4, 6)}
]

var dice_instances: Array = []

func _ready():
    for config in dice_configs:
        create_dice_group(config)

func create_dice_group(config: Dictionary):
    var dice_type = config.get("type", DiceType.NUM)
    var scene_id = config.get("scene_id", "1001")
    var count = config.get("count", 1)
    var start_pos = config.get("position", Vector3.ZERO)
    
    for i in range(count):
        var dice = create_dice(dice_type, scene_id)
        dice.position = start_pos + Vector3(i * 1.5, 0, 0)
        dice_instances.append(dice)

func create_dice(dice_type: DiceType, scene_id: String) -> RigidBody3D:
    var dice_scene = load("res://scenes/dice_6.tscn")
    var dice = dice_scene.instantiate()
    add_child(dice)
    
    var config = get_config(dice_type, scene_id)
    dice.set_dice_face_config(
        config.get("textures", {}),
        config.get("values", {})
    )
    return dice

func get_config(dice_type: DiceType, scene_id: String) -> Dictionary:
    match dice_type:
        DiceType.NUM:
            return dice_csv_reader.get_num_dice_config(scene_id)
        DiceType.SKILL:
            return dice_csv_reader.get_skill_dice_config(scene_id)
        DiceType.ATTR:
            return dice_csv_reader.get_attr_dice_config(scene_id)
    return {}
```

**使用**：
```gdscript
# 在场景中
extends Node3D

@onready var dice_manager = $MultiTypeDiceManager

func _ready():
    # 自动创建所有骰子
    pass

func throw_all():
    DiceThrowController.throw_with_charge(
        dice_manager.dice_instances,
        charge_ratio
    )
```

```
AttributeDices (Node3D)

├─ AgilityDice (RigidBody3D)
├─ IntelligenceDice (RigidBody3D)
├─ StrengthDice2 (RigidBody3D)      ← 新增
```

### 示例 3: 完全使用 DiceManager（最简洁）

```gdscript
# 完全重构场景，使用 DiceManager 统一管理
extends Node3D

@onready var dice_manager = $DiceManager
@onready var charge_label = $UI/ChargeLabel

var is_charging = false

func _ready():
    # 配置 DiceManager
    dice_manager.current_scene = "mixed_001"  # 混合配置 ID
    dice_manager.dice_count = 5  # 5 个骰子
    dice_manager.initialize_dice_pool()

func _input(event):
    if event.keycode == KEY_SPACE and event.pressed:
        is_charging = true
        DiceThrowController.start_charge()
    elif event.keycode == KEY_SPACE and not event.pressed:
        is_charging = false
        DiceThrowController.end_charge(dice_manager.dice_instances)

func _process(delta):
    if is_charging:
        var charge_ratio = DiceThrowController.update_charge(delta)
        charge_label.text = "蓄力：%d%%" % (charge_ratio * 100)
```

## 总结

### 当前架构的优势：

1. **配置驱动**：修改 JSON 即可改变骰子配置
2. **动态调整**：运行时可切换配置
3. **场景隔离**：修改一个场景不影响其他场景
4. **易于扩展**：添加新骰子类型只需添加配置
5. **统一管理**：DiceManager 自动处理所有细节

### 推荐做法：

✅ **推荐**：
- 使用 JSON 配置文件管理贴图
- 使用 DiceManager 统一管理骰子
- 使用 DiceThrowController 统一投掷
- 通过修改配置 ID 切换骰子类型

❌ **不推荐**：
- 硬编码贴图路径
- 手动创建和管理每个骰子
- 每个场景独立的投掷逻辑
- 直接修改核心管理器代码

### 修改配置的安全级别：

| 修改内容 | 影响范围 | 安全级别 | 推荐度 |
|---------|---------|---------|--------|
| 修改 JSON 配置 | 仅该场景 ID | ✅ 安全 | ⭐⭐⭐⭐⭐ |
| 修改场景脚本 | 仅该场景 | ✅ 安全 | ⭐⭐⭐⭐ |
| 修改 DiceManager | 所有使用该管理器的场景 | ⚠️ 谨慎 | ⭐⭐⭐ |
| 修改 DiceThrowController | 所有场景 | ❌ 危险 | ⭐ |
