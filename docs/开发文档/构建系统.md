# 构建系统

- 本游戏是一款rougelike游戏，构建玩法是游戏最重要的核心玩法，构建系统负责管理于搭建构建玩法的相关内容
- 玩家将通过本系统来构建自己的角色，包括技能搭配/属性成长等，最终形成一个独一无二的角色并使用角色通过游戏
- 此系统是一个复合系统，由多个子系统组成，每个子系统负责不同的功能

## 构建系统子系统

- 技能系统
    - 这是一个我们已经大致实现的系统，玩家可在游戏中获得不同技能，装配到技能骰子当中（装配效果暂时未实现），并通过骰子触发技能
    - 此系统还包括另一个重要但未实现的部分，既骰子设计：游戏里大部分骰子可看作由两部分组成，1.骰子本体既空白骰子，2.骰面效果，例如技能骰子骰面是技能，属性骰子骰面是属性值
    - 综上，技能系统在构建中由两部分组成，1.技能 2.空白骰子；玩家需要选择不同技能和不同空白骰子进行组合搭配，实现不同构建效果

- 遗物系统：尚未开发，遗物系统主要玩法是玩家可在游戏中获得不同遗物，这些遗物会带有不同效果，遗物不是道具，需要一个独立的遗物背包进行管理，且玩家不会获得重复遗物，例如 遗物：小手斧：最大力量+5  遗物：金币箱：每次战斗结束额外获得5金币；遗物会对游戏产生多种多样的影响，不仅限于战斗
- 职业系统：尚未开发，职业系统主要玩法是玩家可在游戏内获得各类职业，每类职业都有对应的成长晋升路径，并通过成长晋升获得不同的天赋特长

## 开发方式

- 我们将逐步开发每一个系统最终完成全部构建系统，当前技能系统相关内容已经开发完成，下一步需要开发遗物系统。
- 遗物系统需要建立对应的csv表格，并在convert转换工具中添加对应功能，将csv文件转换为json供游戏使用
- 遗物表需要具有以下内容，id 名称 描述 效果 效果参数1 2 3……
- 遗物效果和参数关系例：小手斧：最大力量+【p1】 p1对应参数1
