# 构建系统

## 简介

- 本游戏是一个rougelike类型游戏，构建是游戏最核心的玩法
- 玩家需要通过游戏里的各种手段构建独特的角色并使用角色通关游戏
- 本系统是一个复合系统，由多个子系统构成

## 子系统

- 技能系统：技能系统当前已经基本完成，主要由技能和空白骰子组成技能骰子，玩家通过不同技能和空白骰子搭配可构建出多种多样的技能组成
- 遗物系统：尚未开发，遗物系统主要玩法是玩家可在游戏中获得不同遗物，这些遗物会带有不同效果，遗物不是道具，需要一个独立的遗物背包进行管理，且玩家不会获得重复遗物，例如 遗物：小手斧：最大力量+5  遗物：金币箱：每次战斗结束额外获得5金币；遗物会对游戏产生多种多样的影响，不仅限于战斗
- 职业系统：尚未开发，职业系统主要玩法是玩家可在游戏内获得各类职业，每类职业都有对应的成长晋升路径，并通过成长晋升获得不同的天赋特长；天赋可理解为被动技能，也类似于遗物，会影响游戏内各种内容，但是他的效果较多，且会逐步增加；例如 职业：收尸人：天赋：收尸：每次击败敌人获得敌人尸体，根据敌人属性获得属性成长；职业晋升：收尸人-掘墓者：天赋：掘墓：释放技能时有几率召唤一具尸体，尸体每回合对敌人造成固定伤害。职业晋升方式通过魔药骰子进行，此系统尚未开发，魔药骰子玩法大致如下：玩家可在游戏内获得获得不同的药材道具，并可将药材配置到容器骰子中，每个骰面对应一种药材，不同职业晋升需要不同药材，例如收尸人晋升掘墓者，需要药材 1.人参 2.狼血 3.玉石，核心药材:灵骸，玩家需要把这些药材装配到容器骰子中，数量至少唯一，可以增多，配方完整时，可进行相应投掷，根据投掷结果获得晋升概率，投掷到核心药材必定成功，其他药材逐步递减，成功则晋升，失败暂时记为不晋升，暂不处理，后续可能加入失败成长线，无论成功失败药材全部消耗；晋升后获得新天赋，原本天赋依然保留；每个职业都可以晋升8次（暂定），每次晋升配方不同。

## 开发方式

- 我们将逐步开发每一个系统最终完成全部构建系统，当前技能系统相关内容已经开发完成，下一步需要开发遗物系统。
- 遗物系统需要建立对应的csv表格，并在convert转换工具中添加对应功能，将csv文件转换为json供游戏使用
- 遗物表需要具有以下内容，id 名称 描述 效果 效果参数1 2 3……
- 遗物效果和参数关系例：小手斧：最大力量+【p1】 p1对应参数1
