# 骰子贴图设置指南

## 一、贴图文件准备

### 贴图文件命名规范
请将骰子六个面的贴图文件命名为以下格式，并保存在 `textures/dice/` 目录下：

| 文件名 | 对应点数 | 对应方向 |
|--------|---------|----------|
| `dice_face_1.png` | 1点 | 顶部 (Vector3.UP) |
| `dice_face_2.png` | 2点 | 正面 (Vector3.FORWARD) |
| `dice_face_3.png` | 3点 | 右侧 (Vector3.RIGHT) |
| `dice_face_4.png` | 4点 | 左侧 (Vector3.LEFT) |
| `dice_face_5.png` | 5点 | 背面 (Vector3.BACK) |
| `dice_face_6.png` | 6点 | 底部 (Vector3.DOWN) |

### 贴图要求
- **分辨率**：建议 512x512 或 1024x1024
- **格式**：PNG 格式
- **风格**：与游戏整体风格一致
- **清晰度**：点数清晰可见，易于识别

## 二、导入贴图到Godot项目

1. **打开Godot编辑器**
2. **在文件系统面板中**，导航到 `textures/dice/` 目录
3. **将贴图文件拖放到** `textures/dice/` 目录中
4. **等待Godot自动导入**贴图资源

## 三、修改骰子材质使用贴图

### 方法一：通过编辑器界面设置
1. **打开 `scenes/dice_6.tscn` 文件**
2. **选择 `MeshInstance3D` 节点**
3. **在检查器面板中**，找到 `StandardMaterial3D` 材质
4. **点击 `Albedo Texture` 属性**，选择对应的骰子贴图

### 方法二：修改TSCN文件
1. **打开 `scenes/dice_6.tscn` 文件**
2. **添加外部资源引用**，例如：
   ```gdscript
   [ext_resource type="Texture2D" path="res://textures/dice/dice_face_1.png" id="3_tex1"]
   ```
3. **修改材质设置**，取消注释并修改贴图引用：
   ```gdscript
   [node name="StandardMaterial3D" type="StandardMaterial3D" parent="MeshInstance3D"]
   albedo_color = Color(1, 1, 1, 1)
   roughness = 0.8
   albedo_texture = ExtResource("3_tex1")
   ```

## 四、验证结果检测与贴图一致

### 方向对应关系
确保贴图的六个面与以下方向对应：

| 方向 | 向量 | 对应点数 |
|------|------|----------|
| 顶部 | `Vector3.UP` | 1点 |
| 底部 | `Vector3.DOWN` | 6点 |
| 右侧 | `Vector3.RIGHT` | 3点 |
| 左侧 | `Vector3.LEFT` | 4点 |
| 正面 | `Vector3.FORWARD` | 2点 |
| 背面 | `Vector3.BACK` | 5点 |

### 测试方法
1. **在编辑器中**，手动旋转骰子，检查贴图显示是否正确
2. **运行游戏**，测试骰子投掷后的结果检测
3. **观察**骰子停止后，贴图显示的点数与游戏检测的结果是否一致
4. **测试多个骰子**同时投掷的情况

## 五、故障排除

### 贴图不显示
- 检查贴图文件是否正确导入
- 检查材质设置是否正确
- 检查贴图路径是否正确

### 结果检测与贴图不一致
- 检查贴图的方向对应关系是否正确
- 检查 `check_dice_value()` 函数中的方向和值对应关系
- 确保骰子模型的UV映射正确

### 性能问题
- 优化贴图分辨率，避免使用过高分辨率的贴图
- 确保贴图格式正确，避免使用过大的文件

## 六、示例代码

### 材质设置示例
```gdscript
# 在dice_6.tscn中
[ext_resource type="Script" path="res://scenes/dice_6.gd" id="1_1022k"]
[ext_resource type="Mesh" path="res://models/dice_smooth.gltf" id="2_3k4j5"]
[ext_resource type="Texture2D" path="res://textures/dice/dice_face_1.png" id="3_tex1"]

[node name="Dice6" type="RigidBody3D"]
script = ExtResource("1_1022k")
dice_value = 1
dice_faces = [1, 2, 3, 4, 5, 6]
scale = Vector3(1, 1, 1)

[node name="CollisionShape3D" type="CollisionShape3D" parent="."]

[node name="MeshInstance3D" type="MeshInstance3D" parent="."]
mesh = ExtResource("2_3k4j5")

[node name="StandardMaterial3D" type="StandardMaterial3D" parent="MeshInstance3D"]
albedo_color = Color(1, 1, 1, 1)
roughness = 0.8
albedo_texture = ExtResource("3_tex1")
```

## 七、注意事项

1. **UV映射**：确保骰子模型的UV映射正确，否则贴图可能显示不正确
2. **物理参数**：调整骰子的物理参数，确保滚动效果自然
3. **结果检测**：验证射线检测的准确性，确保结果与贴图显示一致
4. **性能**：优化贴图和材质设置，确保游戏运行流畅

当您完成贴图的创建和导入后，按照本指南进行设置，即可确保骰子的贴图显示与结果检测一致。
