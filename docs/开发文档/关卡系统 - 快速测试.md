## 🔧 交互操作

1. **重新生成**：按 **R** 键或点击"重新生成"按钮
2. **查看日志**：点击"打印日志"按钮
3. **拖动地图**：在地图上按住左键拖动
4. **缩放视图**：使用滚动条

## ⚠️ 如果遇到问题

### 问题 1：运行后没有显示
**解决**：
- 检查控制台是否有错误
- 确认 Autoload 已注册（项目设置 → Autoload）
- 确认 JSON 配置文件存在

### 问题 2：类型转换错误
**解决**：
- 已修复，如果还有类似错误请查看控制台详细信息

### 问题 3：地图空白
**解决**：
- 检查 `core_nodes.json` 和 `random_nodes.json` 是否正确
- 查看控制台日志确认生成是否成功

## 📊 验证要点

### 1. 总量控制
- 难度 1：应该生成 35 个左右（30+5）
- 允许±10% 浮动（31-39 个）

### 2. 节点类型
- 核心节点：只有战斗（红）和奇遇（蓝）
- 随机节点：可能有所有 4 种颜色

### 3. 路径验证
- 所有路径应该从起点到终点
- 不应该有循环路径
- 路径长度应该在允许范围内

### 4. 种子重复性
- 使用相同种子应该生成相同地图
- 可以记录种子值用于测试
