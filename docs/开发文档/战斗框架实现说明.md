# 战斗框架实现说明

**日期**: 2026-04-15  
**状态**: 基础框架完成，待完善

---

## 概述

战斗框架采用回合制设计，支持以下核心功能：
- ✅ 敌方和玩家角色入场（自动投掷）
- ✅ 玩家回合优先
- ✅ 技能骰子系统（消耗 MP）
- ✅ 物品骰子（预留）
- ✅ 敌方 AI 行动
- ✅ 胜负判定
- ✅ 战斗后奖励结算
- ✅ 投掷命运骰子进入下一关

---

## 核心组件

### 1. BattleManager（战斗管理器）

**文件**: `res://scripts/battle/battle_manager.gd`  
**类型**: Autoload 单例

#### 战斗状态

```gdscript
enum BattleState {
    NONE,        # 无状态
    ENTERING,    # 入场中
    PLAYER_TURN, # 玩家回合
    ENEMY_TURN,  # 敌方回合
    RESOLVING,   # 结算中
    FINISHED     # 战斗结束
}
```

#### 战斗阶段

```gdscript
enum BattlePhase {
    PHASE_ENTER,      # 入场阶段
    PHASE_SETUP,      # 准备阶段（生成骰子）
    PHASE_BATTLE,     # 战斗阶段
    PHASE_RESOLVE,    # 结算阶段
    PHASE_TRANSITION  # 转换阶段（投掷命运骰子）
}
```

#### 核心方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `initialize_battle()` | level_node, player_party | bool | 初始化战斗 |
| `start_battle()` | 无 | void | 开始战斗流程 |
| `player_use_skill()` | character, skill_dice, target | bool | 玩家使用技能 |
| `player_end_turn()` | 无 | void | 玩家结束回合 |
| `_calculate_mp_cost()` | skill_dice | int | 计算 MP 消耗 |
| `_recover_mp()` | character | void | 恢复 MP |

#### 信号

```gdscript
signal on_battle_started()
signal on_battle_finished(winner: String)
signal on_turn_started(turn_owner: String)
signal on_turn_ended(turn_owner: String)
signal on_character_action_completed(character: BaseCharacter)
signal on_battle_phase_changed(old_phase: String, new_phase: String)
```

## 战斗流程详解

### 阶段 1: 入场阶段（PHASE_ENTER）

```
1. 敌方角色入场
   ↓
2. 玩家角色入场
   ↓
3. 入场完成
```

**入场逻辑**:
```gdscript
# 敌方先入场
await _character_enter(enemy_characters, "enemy")

# 玩家后入场
await _character_enter(player_characters, "player")
```

**角色入场细节**:
```gdscript
# 1. 角色骰子自动投掷
DiceThrowController.throw_normal([character_dice], 1.0)

# 2. 等待骰子稳定（2 秒）
await get_tree().create_timer(2.0).timeout

# 3. 锁定骰子
character.lock_character_dice()
```

---

### 阶段 2: 准备阶段（PHASE_SETUP）

```
1. 为玩家角色生成技能骰子
   ↓
2. 为玩家角色生成物品骰子（预留）
   ↓
3. 准备完成
```

**生成逻辑**:

### 阶段 3: 战斗阶段（PHASE_BATTLE）

```
玩家回合开始
   ↓
玩家选择技能或物品
   ↓
玩家结束回合
   ↓
敌方回合开始
   ↓
敌方 AI 行动
   ↓
敌方回合结束
   ↓
检查胜负 → 若未结束，返回玩家回合
```

#### 玩家回合

**玩家行动流程**:
```gdscript

```

### 阶段 4: 结算阶段（PHASE_RESOLVE）

```
1. 检查胜负
   ↓
2. 玩家胜利 → 发放奖励
   ↓
3. 玩家失败 → 游戏结束/重试
```

**胜负判定**:
```gdscript
func _check_battle_end() -> bool:
    # 检查敌方是否全部阵亡
    var enemy_alive = false
    for character in enemy_characters:
        if character.is_alive():
            enemy_alive = true
            break
    
    if not enemy_alive:
        _finish_battle("player")  # 玩家胜利
        return true
    
    # 检查玩家是否全部阵亡
    var player_alive = false
    for character in player_characters:
        if character.is_alive():
            player_alive = true
            break
    
    if not player_alive:
        _finish_battle("enemy")  # 玩家失败
        return true
    
    return false
```

## 注意事项

1. **角色入场顺序**:
   - 敌方先入场（营造压迫感）
   - 玩家后入场（主角登场）

2. **MP 平衡**:
   - 基础恢复量 10 点
   - 普通技能消耗 10-20 点
   - 强力技能消耗 30+ 点
   - 根据游戏难度调整

3. **战斗节奏**:
   - 玩家回合：自由操作，无时间限制
   - 敌方回合：AI 行动，建议添加延迟（1-2 秒）

4. **预留扩展**:
   - 物品骰子占位
   - 特殊单位回合（中立 NPC）
   - 多玩家支持
