# 2D 血条功能开发完成

**日期**: 2026-04-19  
**状态**: 已完成并测试通过

---

## 功能概述

为角色骰子添加了 2D 血条显示功能，血条始终平行于屏幕，固定在骰子上方，不跟随骰子旋转。

---

## 实现方案

### 技术方案

- **渲染方式**: SubViewport + Sprite3D + Billboard
- **血条类型**: 2D 矩形进度条
- **朝向**: 始终面向摄像机（`BILLBOARD_ENABLED`）
- **位置**: 骰子正上方固定高度

### 血条配置参数

```gdscript
# scripts/ui/dice_health_bar_2d.gd
var bar_length: float = 0.7       # 血条长度（世界单位）
var bar_height: float = 0.5        # 血条高度（世界单位）
var offset_y: float = 1.2          # 血条在骰子上方的高度

# Viewport 尺寸
viewport.size = Vector2i(180, 16)  # 像素尺寸

# Sprite3D 设置
sprite_3d.pixel_size = 0.012       # 控制 3D 场景中的显示大小

# 字体设置
hp_label.font_size = 14            # HP 文字大小
hp_label.position = Vector2(0, -2) # 文字向上偏移
```

### 血条结构

```
HealthBar2D (Node3D) - 2D 血条脚本
├── HealthBarViewport (SubViewport) - 2D 渲染缓冲区
│   ├── HealthBar2D (Control) - 2D 血条控件
│   │   └── HPLabel (Label) - HP 文字标签
│   └── HealthBarSprite3D (Sprite3D) - 3D 显示精灵
└── Timer - 延迟设置 Texture
```

### 颜色渐变

| 血量百分比 | 颜色 | RGB |
|-----------|------|-----|
| 100% | 绿色 | (0.2, 0.8, 0.2) |
| 50%  | 黄色 | (0.8, 0.8, 0.2) |
| 0%   | 红色 | (0.8, 0.2, 0.2) |

50%-100%: 黄色 → 绿色渐变  
0%-50%: 红色 → 黄色渐变

## 开发过程

### 方案迭代

1. **第一版（3D 弧形血条）**
   - 使用 SubViewport + Sprite3D 渲染 2D 弧形
   - 问题：弧形方向、半径计算复杂，效果不理想

2. **第二版（3D 直线血条）**
   - 使用 MeshInstance3D 制作长方体血条
   - 问题：需要跟随骰子旋转，方向计算复杂

3. **第三版（2D 血条 - 最终方案）**
   - 使用 SubViewport + Sprite3D + Billboard
   - 优点：始终水平，不跟随旋转，实现简单

### 关键调整

| 调整项 | 初始值 | 最终值 | 原因 |
|--------|--------|--------|------|
| Viewport 尺寸 | 200x60 | 180x16 | 优化长宽比 |
| pixel_size | 0.01 | 0.012 | 调整显示大小 |
| 字体大小 | 16 | 14 | 适配血条高度 |
| 字体 Y 偏移 | 0 | -2 | 文字垂直居中 |
| offset_y | 1.0 | 1.2 | 避免与骰子重叠 |

## 使用方式

### 自动创建

角色骰子完全稳定后自动创建血条：

```gdscript
# dice_6.gd - _on_final_wait_timeout()
if dice_type == "character":
    lock_character_dice()
    create_health_bar()  # 自动创建血条
```

### HP 变化时自动更新

```gdscript
# BaseCharacter.gd
func take_damage(amount):
    current_hp -= amount
    update_health_bar()  # 血条自动更新

func heal(amount):
    current_hp += amount
    update_health_bar()  # 血条自动更新
```

### 手动更新血条

```gdscript
# 通过骰子访问血条
if dice.health_bar:
    dice.health_bar.set_hp_percent(0.5)  # 设置 50%
    dice.health_bar.update_hp_text(50, 100)  # 更新文字
```

## 注意事项

1. **血条创建时机**: 血条在角色骰子完全稳定后创建（`_on_final_wait_timeout()`）
2. **角色关联**: 骰子必须通过 `set_character()` 与角色关联，血条才能正确更新
3. **DiceManager**: 建议使用 `DiceManager.create_character_dice()` 创建角色骰子，自动处理关联
4. **Billboard 模式**: 血条使用 `BILLBOARD_ENABLED` 始终面向摄像机，不受骰子旋转影响

## 技术要点

### SubViewport + Sprite3D 方案

```gdscript
# 1. 创建 SubViewport 用于 2D 渲染
viewport = SubViewport.new()
viewport.size = Vector2i(180, 16)
viewport.transparent_bg = true

# 2. 创建 2D Control 绘制血条
health_bar_2d = Control.new()
health_bar_2d.draw.connect(_on_health_bar_2d_draw)

# 3. 使用 Sprite3D 显示 viewport 内容
sprite_3d = Sprite3D.new()
sprite_3d.texture = viewport.get_texture()
sprite_3d.billboard = BaseMaterial3D.BILLBOARD_ENABLED
sprite_3d.pixel_size = 0.012
```

### 2D 血条绘制

```gdscript
func _on_health_bar_2d_draw():
    var bar_color = _get_hp_color(current_hp_percent)
    var bg_color = Color(0.2, 0.2, 0.2, 0.9)
    
    # 绘制背景
    var bg_rect = Rect2(0, 0, viewport.size.x, viewport.size.y)
    draw_rect(bg_rect, bg_color, true)
    
    # 绘制血量填充
    var fill_width = viewport.size.x * current_hp_percent
    var fill_rect = Rect2(0, 0, fill_width, viewport.size.y)
    draw_rect(fill_rect, bar_color, true)
```
