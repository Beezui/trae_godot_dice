# 3D 骰子 Viewport 相机调整记录

**日期**: 2026-04-30

---

## 问题背景

用户希望优化技能穿戴 UI 中 3D 骰子的显示效果：
- 原始效果：正视角度，骰子显示为平面正方形
- 目标效果：从右上方斜向看骰子，骰子占视窗 80%，能看到三个面

---

## 失败的调整尝试

### 尝试 1：直接修改相机位置到斜上方

**修改内容**：
```gdscript
# 原始（能正常显示）
camera.position = Vector3(1.2, 1.2, 2.8)
camera.fov = 45.0

# 修改后（骰子消失）
camera.position = Vector3(3, 3, 3)
camera.fov = 50.0

# 同时添加骰子旋转
mesh_instance.rotation = Vector3(-0.3, -0.3, 0)
```

**结果**：Viewport 内完全没有骰子

**原因分析**：
- 相机从 `Vector3(3, 3, 3)` 看向 `Vector3.ZERO`，但骰子立方体中心也在原点
- `look_at(Vector3.ZERO)` 让相机瞄准原点，但相机位置太远或角度导致骰子不在视野锥内
- FOV 从 45° 增大到 50° 仍然不够
- 骰子旋转后可能进一步偏离视野

---

### 尝试 2：之前的成功/失败循环

1. `(1.2, 1.2, 2.8)` + FOV 45° — 能看到骰子但只有右上角 1/4
2. `(1.8, 1.8, 1.8)` + FOV 65° — 依然只能看到一部分
3. `(0, 0, 3.5)` + FOV 50° — **完整可见**（正视角度，无立体感）
4. `(2, 2, 2.5)` + FOV 50° — 骰子消失
5. `(3, 3, 3)` + FOV 50° + 骰子旋转 — 骰子消失

---

## 关键发现

**正视角度可行公式**：
```gdscript
camera.position = Vector3(0, 0, 3.5)  # Z 轴正方向
camera.look_at(Vector3.ZERO)
```

**等距视角经典配置（待验证）**：
```gdscript
camera.position = Vector3(1, 1, 1).normalized() * distance
camera.look_at(Vector3.ZERO)
# 骰子旋转产生等距效果
mesh_instance.rotation = Vector3(-0.3, -0.3, 0)
```

## 建议的调试方法

由于骰子按钮是动态生成的，编辑器内无法直接调整，建议：

1. **临时测试场景**：创建一个独立的测试场景，手动放置 Camera3D 和 MeshInstance3D，在编辑器中实时调整
2. **运行时调试**：在代码中添加可调参数，通过按键切换不同相机配置
3. **截图反馈**：每次调整后截图，根据可见程度逐步逼近理想角度
