## 奇遇关卡

- 奇遇关卡主要用于承载不同奇遇事件
- 每个奇遇关卡仅对应一个奇遇事件
- 每个奇遇事件对应多个不同抉择
- 玩家需要通过投掷奇遇骰子根据结果决定抉择结果
- 每个抉择对应的骰子面数量按照权重分配
- 奇遇骰子还未实装，需要同步完成开发
- 奇遇骰子投面显示的是数字，代表选项结果对应的序号，例如选项结果有3种，则骰面分别为1，1，2，2，3，3

1. 首先需要创建2个csv文件用来配置各类奇遇事件及结果选项
2. 每个奇遇事件预计包含以下信息：
    - 1. id ： 奇遇事件全局唯一id，用于调用或查找奇遇事件
    - 2. name ： 奇遇名字，用于显示奇遇名称
    - 3. des ： 奇遇描述，用于向玩家显示奇遇内容
    - 4. return ： 选项结果，应为数组形式例如：1；2；3，对应结果选项中的相应id
3. 每个结果选项应包含以下信息：
    - 1. id ： 奇遇结果唯一id，对应奇遇事件中return选项
    - 2. name : 奇遇名字，游戏内没有实际用途，只用于在工作中对应奇遇
    - 3. des ： 选项描述，用于在奇遇选项中显示对应选项内容
    - 4. 效果 ： 选择该选项后的实际游戏逻辑，可能包括属性调整、资源调整、物品获取等，需要根据此效果进行实际的选项结果制作、
