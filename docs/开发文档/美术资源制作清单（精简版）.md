# 关卡美术资源制作清单（精简版）

## 📋 核心概念（必读）

**重要**：
- ❌ **不需要**制作墙体碰撞（程序自动生成）
- ✅ **只需要**制作美观的场景（地面 + 装饰物）
- ✅ 用树林、建筑、岩石等自然元素形成视觉边界

---

## 🎯 必须制作的资源

### 1. 地面（必须）⭐⭐⭐

**尺寸**：
- 最小：24.0 x 13.5
- 推荐：26.0 x 15.0（略大，避免穿帮）
- 厚度：0.1-0.5

**位置**：
- Y 坐标：-4.05 到 -4.0（略低于碰撞面，避免闪烁）
- 中心：(0, -4, 0)

**材质**：
- 村庄：草地 + 石板路
- 熔火之窟：黑色岩石 + 熔岩裂缝
- 神秘商店：魔法符文石板

**文件格式**：`.glb` 或 `.gltf`

---

### 2. 边界装饰元素（必须）⭐⭐⭐

**村庄场景**：
```
树木：10-15 棵
  - 高度：3-5
  - 位置：距离中心 8-10 单位（四周分布）

栅栏：15-20 段
  - 单段尺寸：2 x 1.5 x 0.2
  - 位置：树木之间连接
```

**熔火之窟**：
```
岩石柱：8-12 根
  - 直径：1.5-2.0
  - 高度：6-10
  - 位置：四周边界

熔岩池：1-2 个
  - 尺寸：6 x 4 x 0.5
  - 材质：自发光（橙红色）
```

**神秘商店**：
```
魔法水晶：5-8 个
  - 尺寸：0.5 x 0.5 x 1.0
  - 材质：透明 + 自发光

书架：4-6 组
  - 尺寸：2 x 3 x 0.5
  - 位置：沿边界布置
```

---

### 3. 功能性建筑（可选）⭐⭐

**村庄 - 小屋**（2-3 座）：
```
尺寸：4 x 4 x 4（总高）
位置：东侧或西侧边界
要求：门窗朝向中央区域
```

**熔火之窟 - 祭坛**（1 座）：
```
尺寸：3 x 3 x 3（总高）
位置：北侧或南侧边界（视觉焦点）
```

**神秘商店 - 柜台**（1 个）：
```
尺寸：4 x 2 x 3
位置：北侧边界中央
朝向：南侧入口
```

---

### 4. 低矮装饰物（可选）⭐

**可以放在中央区域边缘**（高度 < 0.5）：

村庄：
- 草丛：20-30 丛
- 小花：10-15 朵
- 木桶：3-5 个

熔火之窟：
- 小岩石：10-15 块

神秘商店：
- 药水瓶：8-10 个

## 📐 关键尺寸要求

### 必须遵守：
```
中央区域：12.0 x 8.0（从中心向四周）
- 保持完全开阔，无任何障碍物
- 地面平坦，无高度变化
- 这是骰子滚动和停留区域

最大高度：y = 10（从地面向上 6 单位）
- 避免遮挡摄像机视线
```

### 建议遵守：
```
美术场景总尺寸：20.0 x 12.0
- 距离碰撞墙边距：2.0 单位
- 中央开阔区：12.0 x 8.0
- 边界装饰区：外围 4.0 单位宽度
```

---

## 🎨 技术规格

### 文件格式：
- 3D 模型：`.glb` / `.gltf`（推荐）或 `.fbx`
- 纹理：`.png`（支持透明）或 `.jpg`
- 纹理尺寸：512/1024/2048/4096（2 的幂次方）

### 网格要求：
- 简单物件：500-2,000 三角面
- 中等建筑：2,000-5,000 三角面
- 复杂场景：5,000-10,000 三角面
- 最大：不超过 20,000 三角面

### 材质：
- 使用 StandardMaterial3D
- 熔岩/魔法效果：使用 emission 自发光参数

## ❓ 快速问答

**Q: 需要制作墙体吗？**
A: **不需要**！碰撞墙由程序自动生成，你只需要制作美观的场景。

**Q: 地面放在什么位置？**
A: Y 坐标 -4.05 到 -4.0 之间。

**Q: 中央区域可以放什么？**
A: 只能放低矮装饰（高度 < 0.5），如草丛、小花。

**Q: 建筑可以做多高？**
A: 建议不超过 y=10（从地面向上 6 个单位）。

**Q: 边界怎么做才自然？**
A: 使用树林、岩石、建筑等不规则布置，避免直线排列。
