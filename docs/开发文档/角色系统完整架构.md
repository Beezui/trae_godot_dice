# 角色系统完整架构文档

## 一、数据配置文件

### 1. hero.json（角色核心数据）
**路径**: `table/hero.json`

**作用**: 所有角色数据的唯一来源

**结构**:
```json
{
  "heroes": [
    {
      "id": "1",
      "name": "测试角色",
      "attr_str": ["5", "11", "17", "23", "29", "35"],  // 力量 6 面值
      "attr_agi": ["4", "10", "16", "22", "30", "32"],  // 敏捷 6 面值
      "attr_int": ["1", "2", "3", "4", "5", "10"],      // 智力 6 面值
      "attr_hp": "100",                                  // 血量
      "attr_mp": "50",                                   // 魔法值 (新增)
      "mp_name": "MP",                                   // MP 名称 (新增)
      "skill_slot": "1",                                 // 技能槽数量
      "skill_dice_id": ["4001"],                         // 技能骰子 ID 数组
      "texture": ["1001", "1001", "1001", "1001", "1001", "1001"],  // 角色骰子贴图 ID
      "portrait": "1",                                   // 立绘 ID
      "hero_texture": ["idle", "idle", "idle", "idle", "idle", "idle"]  // 状态贴图
    }
  ]
}
```

### 2. AttrDices.json（属性骰子颜色配置）
**路径**: `table/AttrDices.json`

**作用**: **仅**配置属性骰子数值文字的颜色 (points_color)，全局配置，不区分角色

**结构**:
```json
{
  "attr_dices": [
    {"id": "5001", "attr_name": "str", "points_color": "#C00000"},
    {"id": "5002", "attr_name": "agi", "points_color": "#A9D08E"},
    {"id": "5003", "attr_name": "int", "points_color": "#8EA9DB"}
  ]
}
```

**字段说明**:
| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| id | String | 是 | 配置 ID（预留） | "5001" |
| attr_name | String | 是 | 属性类型 | "str", "agi", "int" |
| points_color | String | 是 | 属性数值文字颜色（16 进制） | "#C00000" |

**⚠️ 重要约束**:
- `AttrDices.json` **不包含**角色数据，仅定义全局属性颜色
- 属性值来源于 `hero.json` 的 `attr_str/agi/int`
- 该文件只配置颜色，通过 `attr_name` 字段匹配属性类型
- 后续扩展新属性类型（如 "luck"）只需添加一行配置

**颜色对照**:
- 力量 (str) → 红色 (#C00000)
- 敏捷 (agi) → 绿色 (#A9D08E)
- 智力 (int) → 蓝色 (#8EA9DB)

### 3. SkillDices.json（技能骰子配置）
**路径**: `table/SkillDices.json`

**作用**: 定义技能骰子每个面对应的技能 ID

**结构**:
```json
{
  "skill_dices": [
    {
      "id": "4001",
      "face_count": 6,
      "skill_ids": ["10001", "10002", "10003", "10004", "10005", "10006"]
    }
  ]
}
```

### 4. skill.json（技能数据）
**路径**: `table/skill.json`

**作用**: 定义技能的详细信息（图标、MP 消耗等）

**结构**:
```json
{
  "skills": [
    {
      "id": "10001",
      "name": "火球术",
      "description": "发射火球",
      "icon": "10001",
      "mp_cost": 10,
      "parameters": {...}
    }
  ]
}
```

## 二、角色类继承结构

```
BaseCharacter (RefCounted)
├── 属性：hero_id, name, attr_str/agi/int, attr_hp, attr_mp, current_hp, current_mp
├── 属性：skill_slot, skill_dice_ids, texture_ids, portrait_id, hero_textures
├── 引用：character_dice, attribute_dices, skill_dices
├── 方法：load_from_data(), take_damage(), heal(), recover_mp(), get_config()
│
├── PlayerCharacter (extends BaseCharacter)
│   └── 玩家角色特有逻辑
│
└── EnemyCharacter (extends BaseCharacter)
    └── 敌人角色特有逻辑
```

## 三、管理器架构

### 1. CharacterManager（Autoload 单例）
**路径**: `scripts/character/CharacterManager.gd`

**职责**:
- 加载 `hero.json` 到缓存 (`hero_data_cache`)
- 创建角色实例 (`create_character`)
- 管理所有角色的生命周期

**关键方法**:
```gdscript
create_character(hero_id: int, character_type: String) -> BaseCharacter
get_character(hero_id: int) -> BaseCharacter
get_player_character(hero_id: int) -> PlayerCharacter
set_character_dice_scale(hero_id: int, scale: Vector3) -> bool
```

### 2. BattleManager（Autoload 单例）
**路径**: `scripts/battle/battle_manager.gd`

**职责**:
- 管理战斗流程（入场、准备、战斗、结算）
- 创建角色骰子和技能骰子
- 处理回合制逻辑

**关键方法**:
```gdscript
initialize_battle(level_node: LevelNode, player_party: Array[int]) -> bool
start_battle()
player_use_skill(character, skill_dice, target) -> bool
```

### 3. DiceTextureManager（Autoload 单例）
**路径**: `scripts/dice/dice_texture_manager.gd`

**职责**:
- 统一管理骰子贴图应用
- 通过 `set_dice_face_config` 调用

### 4. AttrDiceManager
**路径**: `scenes/attr_dice_manager.gd`

**职责**:
- 创建和管理属性骰子
- 从 `hero.json` 读取属性值
- 应用颜色配置（从 `AttrDices.json`，按 attr_name 匹配）

**关键方法**:
```gdscript
create_attribute_dice(hero_id: int, attr_type: String, scene: Node) -> Node
get_attribute_dice(hero_id: int, attr_type: String) -> Node
```

**颜色读取逻辑**:
1. 从 `AttrDices.json` 读取全局配置
2. 根据 `attr_type` ("str"/"agi"/"int") 匹配对应的 `attr_name`
3. 获取 `points_color` 应用到属性骰子文字

## 四、骰子类型与创建流程

### 1. 角色骰子 (Character Dice)
**场景**: `dice_6.tscn`
**脚本**: `dice_6.gd`

**贴图来源**: `hero.json` 的 `hero_texture` 字段
**贴图路径**: `res://textures/hero/hero_{hero_id}_{state}.png`

**创建流程** (character_test_arena.gd):
```gdscript
func _create_character_dice():
    # 1. 加载骰子场景
    var dice_scene = load("res://scenes/dice_6.tscn")
    
    # 2. 从角色获取贴图配置
    var hero_config = player_character.get_config()
    var hero_texture_ids = hero_config.get("hero_textures", [])
    var hero_id = hero_config.get("hero_id", 1)
    
    # 3. 构建贴图配置
    var scene_config = {}
    for i in range(6):
        var texture_state = hero_texture_ids[i]
        var texture_path = "res://textures/hero/hero_" + str(hero_id) + "_" + texture_state + ".png"
        scene_config[i] = texture_path
    
    # 4. 创建实例并应用配置
    character_dice = dice_scene.instantiate()
    character_dice.set_dice_face_config(scene_config, value_config)
    
    # 5. 关联到角色
    player_character.character_dice = character_dice
```

### 2. 属性骰子 (Attribute Dice)
**场景**: `attr_dice.tscn`
**脚本**: `attr_dice.gd`

**属性值来源**: `hero.json` 的 `attr_str/agi/int`
**颜色来源**: `AttrDices.json` 的 `points_color`（按 `attr_name` 匹配）

**创建流程** (attr_dice_manager.gd):
```gdscript
func create_attribute_dice(hero_id: int, attr_type: String, scene: Node) -> Node:
    # 1. 从 hero_data 获取属性值
    var hero_info = hero_data[str(hero_id)]
    var hero_attributes = {
        "attr_str": hero_info.get("attr_str", [...]),
        "attr_agi": hero_info.get("attr_agi", [...]),
        "attr_int": hero_info.get("attr_int", [...])
    }
    
    # 2. 获取贴图
    var hero_textures = hero_info.get("texture", [])
    
    # 3. 创建属性骰子实例
    var attr_dice = attr_dice_scene.instantiate()
    attr_dice.attr_type = attr_type
    attr_dice.hero_id = hero_id
    
    # 4. 更新属性（内部会应用贴图）
    attr_dice.update_attributes(hero_attributes, hero_textures)
    
    # 5. 添加到场景
    scene.add_child.call_deferred(attr_dice)
```

**颜色配置读取流程** (attr_dice.gd):
```gdscript
func _update_points_color_from_config():
    # 从 AttrDices.json 读取文字颜色配置（新格式：全局配置）
    # 返回格式：{"str": "#C00000", "agi": "#A9D08E", "int": "#8EA9DB"}
    var attr_dices_config = dice_csv_reader.load_attr_dices()
    
    # 直接从 attr_type 获取颜色
    if attr_dices_config.has(attr_type):
        var color_str = attr_dices_config[attr_type]
        points_color = Color(color_str)
```

### 3. 技能骰子 (Skill Dice)
**场景**: `dice_6.tscn`
**脚本**: `dice_6.gd`

**贴图来源**: `skill.json` 的 `icon` 字段
**技能 ID 来源**: `SkillDices.json` 的 `skill_ids`

**创建流程** (character_test_arena.gd):
```gdscript
func _create_skill_dices():
    # 1. 加载骰子场景
    var dice_scene = load("res://scenes/dice_6.tscn")
    
    # 2. 从 CSV 读取技能骰子配置
    var skill_config = dice_csv_reader.get_skill_dice_config("4001")
    var skill_ids_array = skill_config.get("skill_ids", [])
    
    # 3. 构建贴图配置（从 skill.json 获取 icon）
    var scene_config = {}
    for i in range(6):
        var skill_id = skill_ids_array[i]
        var skill_data = skill_reader.get_skill(skill_id)
        scene_config[i] = "res://textures/skill/skill_" + skill_data["icon"] + ".png"
    
    # 4. 创建实例并应用配置
    skill_dice = dice_scene.instantiate()
    skill_dice.set_dice_face_config(scene_config, value_config)
```

## 五、battle_test_scene.gd 缺失的关键逻辑

### 当前问题
`battle_test_scene.gd` 使用 `BattleManager` 创建角色骰子，但 `BattleManager._create_character_dice()` 使用的贴图配置方式与 `character_test_arena.gd` **不同**：

**BattleManager 方式（有问题）**:
```gdscript
# 使用 texture 字段（数字骰子贴图 ID）
for i in range(6):
    var texture_id = character.texture_ids[i]  # "1001"
    texture_config[i] = "res://textures/dice/dice_face_" + texture_id + ".png"
```

**character_test_arena 方式（正确）**:
```gdscript
# 使用 hero_texture 字段（角色状态贴图）
for i in range(6):
    var texture_state = hero_texture_ids[i]  # "idle"
    texture_path = "res://textures/hero/hero_" + str(hero_id) + "_" + texture_state + ".png"
```

### 解决方案
需要修改 `BattleManager._create_character_dice()` 使用 `hero_texture` 字段而不是 `texture` 字段，或者确认 `texture` 字段的正确用途。

## 六、关键字段用途总结

| 字段 | 来源文件 | 用途 | 示例 |
|------|---------|------|------|
| `texture` | hero.json | 数字骰子贴图 ID（用于普通数字骰子） | `["1001", "1001", ...]` |
| `hero_texture` | hero.json | 角色骰子状态贴图（用于角色骰子） | `["idle", "hit", "attack", ...]` |
| `skill_dice_id` | hero.json | 技能骰子配置 ID | `["4001"]` |
| `attr_str/agi/int` | hero.json | 属性骰子的 6 个面值 | `["5", "11", "17", ...]` |
| `points_color` | AttrDices.json | 属性骰子数值文字颜色（全局配置） | `"#C00000"` |

## 七、已验证的正确流程（character_test_arena.gd）

1. **角色创建**: `CharacterManager.create_character(1, "player")`
2. **角色骰子创建**: 使用 `hero_texture` 字段构建贴图路径
3. **属性骰子创建**: `AttrDiceManager.create_attribute_dice(hero_id, attr_type, scene)`
4. **技能骰子创建**: 从 `SkillDices.json` 读取配置，从 `skill.json` 获取贴图
5. **投掷逻辑**: `DiceThrowController` 统一管理

**关键点**: 角色骰子使用 `hero_{id}_{state}.png` 格式，不是 `dice_face_{id}.png`。
