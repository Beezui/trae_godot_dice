# 角色系统使用指南

## 概述

角色系统提供了统一的角色管理功能，包括角色创建、生命周期管理、属性管理等。所有角色代码独立于场景，可在任意场景中使用。

## 核心组件

### 1. BaseCharacter (角色基类)

**位置**: `res://scripts/character/BaseCharacter.gd`

**功能**: 
- 存储角色基础数据 (hero_id, name, 属性等)
- 提供伤害计算、治疗、状态管理方法
- 管理角色骰子引用

**核心属性**:
```gdscript
var hero_id: int          # 角色唯一标识
var name: String          # 角色名称
var attr_str: Array       # 力量属性 (6 个面)
var attr_agi: Array       # 敏捷属性 (6 个面)
var attr_int: Array       # 智力属性 (6 个面)
var attr_hp: int          # 最大血量
var current_hp: int       # 当前血量
var skill_slot: int       # 技能槽位
var character_dice: RigidBody3D  # 角色骰子引用
var attribute_dices: Dictionary  # 属性骰子引用
var skill_dices: Array           # 技能骰子引用
```

**核心方法**:
```gdscript
func take_damage(damage: int) -> int      # 承受伤害
func heal(amount: int) -> int             # 治疗
func is_alive() -> bool                   # 检查是否存活
func is_defeated() -> bool                # 检查是否被击败
func set_state(state: String)             # 设置状态
func get_attribute_value(attr_type: String, face_index: int) -> int  # 获取属性值
func get_hp_percentage() -> float         # 获取血量百分比
```

### 2. PlayerCharacter (玩家角色类)

**位置**: `res://scripts/character/PlayerCharacter.gd`

**功能**: 
- 继承自 BaseCharacter
- 标记为玩家控制角色
- 提供玩家特有方法

**特有方法**:
```gdscript
func can_use_skill() -> bool    # 检查是否可以使用技能
func can_attack() -> bool       # 检查是否可以攻击
func get_attribute_dice_position(attr_type: String) -> Vector3  # 获取属性骰子位置
func get_skill_dice_position(index: int) -> Vector3             # 获取技能骰子位置
```

### 3. EnemyCharacter (敌人角色类)

**位置**: `res://scripts/character/EnemyCharacter.gd`

**功能**: 
- 继承自 BaseCharacter
- 标记为敌人角色
- 提供简单的 AI 逻辑

**特有方法**:
```gdscript
func is_skill_dice_visible() -> bool    # 技能骰子是否可见
func is_attribute_dice_visible() -> bool # 属性骰子是否可见
func select_target(targets: Array) -> BaseCharacter  # AI 选择目标
```

### 4. CharacterManager (角色管理器)

**位置**: `res://scripts/character/CharacterManager.gd`

**功能**: 
- Autoload 单例，全局访问
- 管理所有角色的创建和生命周期
- 从 hero.json 加载英雄数据

**核心方法**:
```gdscript
func create_character(hero_id: int, character_type: String = "player") -> BaseCharacter
func get_character(hero_id: int) -> BaseCharacter
func get_player_character(hero_id: int) -> PlayerCharacter
func get_enemy_character(hero_id: int) -> EnemyCharacter
func remove_character(hero_id: int) -> bool
func get_all_characters() -> Array
func get_hero_data(hero_id: int) -> Dictionary
```

## 使用方式

### 1. 创建角色

在任何场景中，通过 CharacterManager 创建角色:

```gdscript
extends Node3D

var player: PlayerCharacter

func _ready():
    # 创建玩家角色 (使用 hero_id = 1)
    player = CharacterManager.create_character(1, "player")
    
    if player:
        print("创建玩家角色：", player.name)
        print("HP: ", player.current_hp, "/", player.attr_hp)
```

### 2. 创建敌人角色

```gdscript
var enemy = CharacterManager.create_character(2, "enemy")
if enemy:
    print("创建敌人角色：", enemy.name)
```

### 3. 关联骰子

角色创建后，需要将骰子与角色关联:

```gdscript
# 创建角色骰子
var dice_scene = load("res://scenes/dice_6.tscn")
var character_dice = dice_scene.instantiate()
character_dice.position = Vector3(0, 4, 0)
add_child(character_dice)

# 关联到角色
if player:
    player.character_dice = character_dice
```

### 4. 创建属性骰子并关联

```gdscript
# 创建力量骰子
var str_dice = dice_scene.instantiate()
str_dice.position = Vector3(-3, 4, 4)
add_child(str_dice)

# 创建敏捷骰子
var agi_dice = dice_scene.instantiate()
agi_dice.position = Vector3(0, 4, 4)
add_child(agi_dice)

# 创建智力骰子
var int_dice = dice_scene.instantiate()
int_dice.position = Vector3(3, 4, 4)
add_child(int_dice)

# 关联到角色
if player:
    player.attribute_dices["str"] = str_dice
    player.attribute_dices["agi"] = agi_dice
    player.attribute_dices["int"] = int_dice
```

### 5. 创建技能骰子并关联

```gdscript
if player and player.skill_slot > 0:
    var skill_dice = dice_scene.instantiate()
    skill_dice.position = Vector3(0, 4, 8)
    add_child(skill_dice)
    
    # 关联到角色
    player.skill_dices.append(skill_dice)
```

### 6. 伤害计算

```gdscript
# 玩家受到 10 点伤害
player.take_damage(10)
print("剩余 HP: ", player.current_hp)

# 检查是否存活
if player.is_alive():
    print("玩家还活着")
else:
    print("玩家被击败了")
```

### 7. 治疗

```gdscript
# 恢复 10 点 HP
player.heal(10)
print("当前 HP: ", player.current_hp)
```

### 8. 获取属性值

```gdscript
# 获取力量属性值 (索引 0 表示第一个面)
var str_value = player.get_attribute_value("str", 0)
print("力量属性：", str_value)

# 获取敏捷属性值
var agi_value = player.get_attribute_value("agi", 2)
print("敏捷属性：", agi_value)
```

### 9. 血量百分比

```gdscript
var hp_percent = player.get_hp_percentage()
print("血量百分比：", hp_percent * 100, "%")
```

### 10. 移除角色

```gdscript
CharacterManager.remove_character(1)
```

## 最佳实践

### 1. 使用 CharacterManager 管理角色

```gdscript
# ✅ 推荐
var player = CharacterManager.create_character(1, "player")

# ❌ 不推荐
var player = PlayerCharacter.new()
```

### 2. 关联骰子到角色

```gdscript
# ✅ 推荐
player.character_dice = character_dice
player.attribute_dices["str"] = str_dice

# ❌ 不推荐
# 不关联，导致角色和骰子分离
```

### 3. 通过角色管理 HP

```gdscript
# ✅ 推荐
player.take_damage(10)
player.heal(5)

# ❌ 不推荐
player.current_hp -= 10  # 直接修改，缺少状态更新
```

### 4. 检查角色状态

```gdscript
# ✅ 推荐
if player.is_alive():
    # 执行逻辑

# ❌ 不推荐
if player.current_hp > 0:
    # 执行逻辑
```

## 常见问题

### Q1: 如何获取角色的英雄数据？

```gdscript
var hero_data = CharacterManager.get_hero_data(1)
print(hero_data)
```

### Q2: 如何获取所有存活的角色？

```gdscript
var alive_chars = CharacterManager.get_alive_characters()
```

### Q3: 如何清空所有角色？

```gdscript
CharacterManager.clear_all_characters()
```

### Q4: 角色系统是否依赖特定场景？

**不依赖**。角色系统完全独立，可在任何场景中使用。场景只需从 CharacterManager 获取角色实例并显示。

### Q5: 如何在不同场景间保持角色状态？

CharacterManager 是 Autoload 单例，在场景切换时保持数据。只需在场景中使用 `CharacterManager.get_character(hero_id)` 获取角色。

## 扩展开发

### 添加新角色类型

1. 创建新类继承 BaseCharacter:

```gdscript
class_name NPCharacter
extends BaseCharacter

func _init(data: Dictionary = {}):
    super._init(data)
    is_player = false
```

2. 在 CharacterManager 中添加创建方法:

```gdscript
func create_npc_character(hero_id: int) -> NPCharacter:
    var hero_data = get_hero_data(hero_id)
    var npc = NPCharacter.new(hero_data)
    return npc
```

### 添加角色状态效果

在 BaseCharacter 中添加状态效果管理:

```gdscript
var status_effects: Array = []

func add_status_effect(effect: Dictionary):
    status_effects.append(effect)

func remove_status_effect(effect_name: String):
    for i in range(status_effects.size()):
        if status_effects[i].name == effect_name:
            status_effects.remove_at(i)
            break
```

## 总结

角色系统提供了完整的角色管理功能，具有以下特点:

- ✅ **独立性**: 不依赖任何场景
- ✅ **统一管理**: 通过 CharacterManager 集中管理
- ✅ **配置驱动**: 从 hero.json 读取数据
- ✅ **易于扩展**: 继承基类即可创建新角色类型
- ✅ **场景无关**: 可在任意场景中使用
- ✅ **状态持久化**: 场景切换时保持角色状态

使用角色系统时，始终通过 CharacterManager 创建和管理角色，确保数据一致性和可维护性。
