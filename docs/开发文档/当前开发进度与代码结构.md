# 当前开发进度与代码结构

## 项目概述

本项目是一个基于 Godot 4.6.1 的 3D 骰子游戏，名为"晋升吧骰子"。游戏核心功能包括骰子投掷、物理模拟、技能触发等。

## 核心代码文件分析

### 1. dice_6.gd

**功能**：骰子的核心逻辑实现

**主要特性**：
- 继承自 RigidBody3D，实现物理模拟
- 支持骰子滚动、碰撞检测
- 技能系统集成
- 粒子特效系统集成
- 骰子结果判定（通过射线检测）

**关键函数**：
- `roll(force, angular_force)`: 投掷骰子，应用力和旋转力
- `check_dice_value()`: 检测骰子最终点数
- `trigger_skill()`: 根据骰子点数触发技能

**物理参数**：
- 质量：0.5
- 线性阻尼：0.1
- 角阻尼：0.03
- 物理材质：反弹系数 0.1404，摩擦系数 0.8

### 2. dice_demo_script.gd

**功能**：演示场景的控制逻辑

**主要特性**：
- 摄像机控制和视角调整
- 沙盘尺寸计算和碰撞体创建
- 骰子初始状态管理
- 蓄力投掷系统
- 重力设置
- 动态贴图系统集成

**关键参数**：
- 最大蓄力时间：2.0 秒
- 最大投掷力度：20.0
- 重力加速度：39.2 m/s²（4 倍重力）
- 骰子初始位置：高度 6 单位，靠近屏幕下方

**输入控制**：
- 空格键：开始/结束蓄力，投掷骰子
- R 键：重置骰子到初始状态
- A 键：增加骰子（最多 6 枚）
- S 键：减少骰子（最少 1 枚）
- 1 键：切换到 1001 场景配置
- 2 键：切换到 1002 场景配置

### 3. dice_config.gd

**功能**：骰子配置系统

**主要特性**：
- 管理不同场景的骰子配置
- 支持通过 ID 配置骰子面
- 提供场景配置切换功能

**关键函数**：
- `get_scene_config(scene_name)`: 获取指定场景的配置
- `add_scene_config(scene_name, config)`: 添加或更新场景配置
- `get_all_scene_names()`: 获取所有场景名称

### 4. dice_face_manager.gd

**功能**：骰子面管理器

**主要特性**：
- 从 CSV 文件加载骰子面数据
- 管理骰子面 ID 和贴图路径的映射
- 提供根据 ID 获取贴图路径的功能

**关键函数**：
- `load_csv()`: 加载 CSV 文件
- `get_texture_path_by_id(id)`: 根据 ID 获取贴图路径
- `get_face_by_id(id)`: 根据 ID 获取骰子面数据

### 5. dice_csv_reader.gd

**功能**：骰子 CSV 配置读取器

**主要特性**：
- 从 NumDices.csv 文件加载数字骰子配置
- 支持新的 CSV 格式，点数和贴图使用逗号分隔的数组
- 贴图默认前缀为 dice_face_
- 提供获取骰子配置的功能

**关键函数**：
- `load_num_dices()`: 加载数字骰子配置
- `get_num_dice_config(dice_id)`: 获取指定骰子 ID 的配置
- `get_all_num_dice_ids()`: 获取所有数字骰子 ID
- `parse_csv_line(line)`: 解析 CSV 行，处理带引号的字段

### 6. skill_manager.gd

**功能**：技能管理器（Autoload）

**主要特性**：
- 统一管理所有技能
- 提供全局技能调用接口
- 管理技能冷却
- 自动注册技能

**关键函数**：
- `use_skill(skill_id, caster, targets, params)`: 使用技能
- `can_use_skill(skill_id)`: 检查技能是否可以使用
- `_auto_register_skills()`: 自动注册技能
- `_create_skill_instance(skill_id)`: 创建技能实例

### 7. fireball_skill.gd

**功能**：火球术技能实现

**主要特性**：
- 向目标发射火球
- 造成范围伤害
- 包含爆炸粒子特效
- 独立于场景运行

**关键函数**：
- `execute(caster, targets, params)`: 执行技能
- `_launch_fireball(start_pos, target_pos, damage, scene_node)`: 发射火球
- `_trigger_explosion(hit_position, scene_node)`: 触发爆炸效果
- `calculate_damage(formula, dice_results)`: 计算伤害

### 8. blizzard_skill.gd

**功能**：暴风雪技能实现

**主要特性**：
- 在目标区域降下暴风雪
- 持续造成伤害
- 包含粒子特效和视觉指示器
- 独立于场景运行

**关键函数**：
- `execute(caster, targets, params)`: 执行技能
- `_create_blizzard_effect(center_pos, range_bonus, duration, damage_per_second, scene_node)`: 创建暴风雪效果
- `_create_blizzard_particles()`: 创建暴风雪粒子效果
- `calculate_damage(formula, dice_results)`: 计算伤害

### 9. skill_csv_reader.gd

**功能**：技能配置读取器

**主要特性**：
- 从 skill.json 文件加载技能配置
- 提供获取技能数据的接口
- 支持技能数据的快速访问

**关键函数**：
- `load_skills()`: 加载技能配置
- `get_skill(skill_id)`: 获取指定技能配置
- `get_all_skills()`: 获取所有技能配置
- `get_skill_count()`: 获取技能数量

### 10. attr_dice.gd

**功能**：属性骰子核心逻辑

**主要特性**：
- 继承自 RigidBody3D，实现物理模拟
- 六面独立贴图映射（每面显示不同英雄属性）
- 动态纹理生成（SubViewport 技术）
- 属性数值叠加显示（在贴图上加文字）
- 投掷结果检测（向量点积法）
- 完整的调试日志系统

**关键函数**：
- `apply_dice_textures(mesh_instance)`: 为六个面应用独立贴图
- `create_face_texture(face_index, static_texture, dynamic_text, face_size)`: 创建动态纹理
- `create_fallback_mesh()`: 创建备用网格（6 个独立表面）
- `check_dice_value()`: 检测朝上的面并输出详细日志
- `update_attributes(hero_attributes, hero_textures)`: 更新属性和贴图
- `get_attribute_value()`: 获取当前朝上面的属性值

**核心技术**：
- SubViewport 离屏渲染生成动态纹理
- ArrayMesh 六表面独立 UV 映射
- StandardMaterial3D 的 UV1 变换设置
- Control 节点的 PRESET_FULL_RECT 布局
- TextureRect 的 STRETCH_SCALE 拉伸模式

### 11. attr_dice_manager.gd

**功能**：属性骰子管理器

**主要特性**：
- 批量创建属性骰子（str/agi/int 三种类型）
- 从 hero.json 加载英雄属性数据
- 为每个骰子分配不同的英雄贴图
- 管理骰子初始位置和排列

**关键函数**：
- `create_attribute_dice()`: 创建三个属性骰子
- `update_all_dice_attributes()`: 更新所有骰子的属性

### 12. hero_csv_reader.gd

**功能**：英雄数据读取器

**主要特性**：
- 从 hero.csv 文件加载英雄数据
- 解析英雄属性（str/agi/int）
- 生成 hero.json 文件
- 提供英雄数据查询接口

**关键函数**：
- `load_heroes()`: 加载英雄数据
- `get_hero(hero_id)`: 获取指定英雄数据
- `generate_json()`: 生成 JSON 文件

## 关键设置

### 1. 物理设置

- 物理引擎：Jolt Physics
- 重力加速度：39.2 m/s²（4 倍现实重力）
- 骰子重力缩放：初始状态为 0（悬浮），投掷后为 1.0（受重力影响）

### 2. 场景设置

- 摄像机位置：(0, 60, 0)
- 摄像机 FOV：15.0
- 沙盘尺寸：宽度 24.0，高度 13.5（16:9 比例）
- 墙体碰撞：北、南、东、西四面墙

### 3. 投掷系统

- 蓄力机制：按住空格键蓄力，松开投掷
- 蓄力时间：0-2 秒
- 投掷力度：最小 30% 最大力度，随蓄力时间增加
- 抛物线运动：投掷时应用向上的力，模拟抛物线轨迹

### 4. 属性骰子系统

- 六面独立贴图：每面显示不同的英雄属性贴图
- 动态数值显示：在贴图上加黑色数字显示属性值
- SubViewport 尺寸：最小 512x512，根据骰面 AABB 动态调整
- 材质应用：使用 `surface_set_material()` 为每个表面设置独立材质
- UV 映射：每个面独立的 0-1 完整映射
- 结果检测：向量点积法，检测最接近向上的面
- 调试日志：完整的投掷结果检测日志系统

## 技术实现要点

### 1. 骰子物理模拟

- 使用 RigidBody3D 实现物理效果
- 通过调整质量、阻尼等参数优化物理表现
- 投掷时应用力和旋转力，模拟真实骰子滚动

### 2. 蓄力系统

- 跟踪蓄力时间
- 根据蓄力时间计算投掷力度
- 应用震动效果增强用户反馈

### 3. 重力控制

- 初始状态禁用重力，使骰子悬浮
- 投掷时启用重力，模拟真实下落
- 调整重力加速度，控制下落时间在 1 秒以内

### 4. 碰撞检测与结果判定

- 使用向量点积方法确定骰子最终点数
- 碰撞时触发技能效果
- 检测与其他物体的碰撞
- 确保骰子完全停止运动后再进行结果判定
- 支持根据骰子旋转计算朝上的面

### 5. 技能系统实现

- **技能独立性**：技能代码不依赖特定场景，通过参数传递所有需要的数据
- **场景节点传递**：通过 params 参数传递场景节点，确保技能效果能在任何场景中显示
- **伤害计算**：实现表达式解析器，支持复杂的伤害计算公式（+、-、*、/运算符）
- **资源管理**：技能创建的临时对象（粒子效果、计时器等）正确清理
- **计时器使用**：严格遵循先 add_child() 再 start() 的顺序，确保计时器在场景树中才能启动
- **配置系统**：使用 CSV 作为配置源文件，开发转换工具生成结构化 JSON
- **技能冷却**：SkillManager 统一管理技能冷却时间，在_process() 中更新

### 6. 属性骰子贴图映射（新增）

- **SubViewport 动态纹理生成**：
  - 离屏渲染生成动态纹理
  - UPDATE_ONCE 模式节省性能
  - 透明背景支持
  
- **六面独立映射策略**：
  - ArrayMesh 创建 6 个独立表面
  - 每个表面独立的 UV 坐标（0-1 完整映射）
  - 每个表面独立的材质实例
  
- **材质应用**：
  - 使用 `mesh_instance.mesh.surface_set_material()` 应用材质
  - UV1 变换设置为默认值（scale=1, offset=0）
  - 表面数量检查避免越界
  
- **Control 节点布局**：
  - PRESET_FULL_RECT 锚点设置
  - 明确设置 size 属性
  - STRETCH_SCALE 拉伸模式确保完全覆盖
