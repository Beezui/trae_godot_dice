# 当前开发进度与代码结构

## 项目概述

本项目是一个基于Godot 4.6.1的3D骰子游戏，名为"晋升吧骰子"。游戏核心功能包括骰子投掷、物理模拟、技能触发等。

## 核心代码文件分析

### 1. dice_6.gd

**功能**：骰子的核心逻辑实现

**主要特性**：
- 继承自RigidBody3D，实现物理模拟
- 支持骰子滚动、碰撞检测
- 技能系统集成
- 粒子特效系统集成
- 骰子结果判定（通过射线检测）

**关键函数**：
- `roll(force, angular_force)`: 投掷骰子，应用力和旋转力
- `check_dice_value()`: 检测骰子最终点数
- `trigger_skill()`: 根据骰子点数触发技能

**物理参数**：
- 质量：0.5
- 线性阻尼：0.1
- 角阻尼：0.03
- 物理材质：反弹系数0.1404，摩擦系数0.8

### 2. dice_demo_script.gd

**功能**：演示场景的控制逻辑

**主要特性**：
- 摄像机控制和视角调整
- 沙盘尺寸计算和碰撞体创建
- 骰子初始状态管理
- 蓄力投掷系统
- 重力设置
- 动态贴图系统集成

**关键参数**：
- 最大蓄力时间：2.0秒
- 最大投掷力度：20.0
- 重力加速度：39.2 m/s²（4倍重力）
- 骰子初始位置：高度6单位，靠近屏幕下方

**输入控制**：
- 空格键：开始/结束蓄力，投掷骰子
- R键：重置骰子到初始状态
- A键：增加骰子（最多6枚）
- S键：减少骰子（最少1枚）
- 1键：切换到1001场景配置
- 2键：切换到1002场景配置

### 3. dice_config.gd

**功能**：骰子配置系统

**主要特性**：
- 管理不同场景的骰子配置
- 支持通过ID配置骰子面
- 提供场景配置切换功能

**关键函数**：
- `get_scene_config(scene_name)`: 获取指定场景的配置
- `add_scene_config(scene_name, config)`: 添加或更新场景配置
- `get_all_scene_names()`: 获取所有场景名称

### 4. dice_face_manager.gd

**功能**：骰子面管理器

**主要特性**：
- 从CSV文件加载骰子面数据
- 管理骰子面ID和贴图路径的映射
- 提供根据ID获取贴图路径的功能

**关键函数**：
- `load_csv()`: 加载CSV文件
- `get_texture_path_by_id(id)`: 根据ID获取贴图路径
- `get_face_by_id(id)`: 根据ID获取骰子面数据

### 5. dice_csv_reader.gd

**功能**：骰子CSV配置读取器

**主要特性**：
- 从NumDices.csv文件加载数字骰子配置
- 支持新的CSV格式，点数和贴图使用逗号分隔的数组
- 贴图默认前缀为dice_face_
- 提供获取骰子配置的功能

**关键函数**：
- `load_num_dices()`: 加载数字骰子配置
- `get_num_dice_config(dice_id)`: 获取指定骰子ID的配置
- `get_all_num_dice_ids()`: 获取所有数字骰子ID
- `parse_csv_line(line)`: 解析CSV行，处理带引号的字段

### 6. skill_manager.gd

**功能**：技能管理器（Autoload）

**主要特性**：
- 统一管理所有技能
- 提供全局技能调用接口
- 管理技能冷却
- 自动注册技能

**关键函数**：
- `use_skill(skill_id, caster, targets, params)`: 使用技能
- `can_use_skill(skill_id)`: 检查技能是否可以使用
- `_auto_register_skills()`: 自动注册技能
- `_create_skill_instance(skill_id)`: 创建技能实例

### 7. fireball_skill.gd

**功能**：火球术技能实现

**主要特性**：
- 向目标发射火球
- 造成范围伤害
- 包含爆炸粒子特效
- 独立于场景运行

**关键函数**：
- `execute(caster, targets, params)`: 执行技能
- `_launch_fireball(start_pos, target_pos, damage, scene_node)`: 发射火球
- `_trigger_explosion(hit_position, scene_node)`: 触发爆炸效果
- `calculate_damage(formula, dice_results)`: 计算伤害

### 8. blizzard_skill.gd

**功能**：暴风雪技能实现

**主要特性**：
- 在目标区域降下暴风雪
- 持续造成伤害
- 包含粒子特效和视觉指示器
- 独立于场景运行

**关键函数**：
- `execute(caster, targets, params)`: 执行技能
- `_create_blizzard_effect(center_pos, range_bonus, duration, damage_per_second, scene_node)`: 创建暴风雪效果
- `_create_blizzard_particles()`: 创建暴风雪粒子效果
- `calculate_damage(formula, dice_results)`: 计算伤害

### 9. skill_csv_reader.gd

**功能**：技能配置读取器

**主要特性**：
- 从skill.json文件加载技能配置
- 提供获取技能数据的接口
- 支持技能数据的快速访问

**关键函数**：
- `load_skills()`: 加载技能配置
- `get_skill(skill_id)`: 获取指定技能配置
- `get_all_skills()`: 获取所有技能配置
- `get_skill_count()`: 获取技能数量

## 关键设置

### 1. 物理设置

- 物理引擎：Jolt Physics
- 重力加速度：39.2 m/s²（4倍现实重力）
- 骰子重力缩放：初始状态为0（悬浮），投掷后为1.0（受重力影响）

### 2. 场景设置

- 摄像机位置：(0, 60, 0)
- 摄像机FOV：15.0
- 沙盘尺寸：宽度24.0，高度13.5（16:9比例）
- 墙体碰撞：北、南、东、西四面墙

### 3. 投掷系统

- 蓄力机制：按住空格键蓄力，松开投掷
- 蓄力时间：0-2秒
- 投掷力度：最小30%最大力度，随蓄力时间增加
- 抛物线运动：投掷时应用向上的力，模拟抛物线轨迹

## 技术实现要点

### 1. 骰子物理模拟

- 使用RigidBody3D实现物理效果
- 通过调整质量、阻尼等参数优化物理表现
- 投掷时应用力和旋转力，模拟真实骰子滚动

### 2. 蓄力系统

- 跟踪蓄力时间
- 根据蓄力时间计算投掷力度
- 应用震动效果增强用户反馈

### 3. 重力控制

- 初始状态禁用重力，使骰子悬浮
- 投掷时启用重力，模拟真实下落
- 调整重力加速度，控制下落时间在1秒以内

### 4. 碰撞检测与结果判定

- 使用向量点积方法确定骰子最终点数
- 碰撞时触发技能效果
- 检测与其他物体的碰撞
- 确保骰子完全停止运动后再进行结果判定
- 支持根据骰子旋转计算朝上的面

### 5. 技能系统实现

- **技能独立性**：技能代码不依赖特定场景，通过参数传递所有需要的数据
- **场景节点传递**：通过params参数传递场景节点，确保技能效果能在任何场景中显示
- **伤害计算**：实现表达式解析器，支持复杂的伤害计算公式（+、-、*、/运算符）
- **资源管理**：技能创建的临时对象（粒子效果、计时器等）正确清理
- **计时器使用**：严格遵循先add_child()再start()的顺序，确保计时器在场景树中才能启动
- **配置系统**：使用CSV作为配置源文件，开发转换工具生成结构化JSON
- **技能冷却**：SkillManager统一管理技能冷却时间，在_process()中更新

## 总结

当前项目已经实现了骰子游戏的核心功能，包括物理模拟、蓄力投掷、技能系统等。技能系统已经完成了完整的架构设计和实现，包括技能管理器、具体技能实现、配置系统和测试场景。系统采用了配置驱动的设计模式，通过CSV配置文件即可设计新技能，无需修改代码。

技能系统的核心特性包括：
- 技能独立性：不依赖特定场景，可在任意场景中通过技能ID调用
- 配置驱动：通过CSV配置文件管理技能数据
- 动态伤害计算：支持基于属性的复杂伤害公式
- 粒子特效：集成了火球术和暴风雪的视觉效果
- 冷却系统：统一管理技能冷却时间

后续开发可以在此基础上添加更多技能类型，实现技能等级系统，以及优化UI界面，打造更加完善的骰子游戏体验。
