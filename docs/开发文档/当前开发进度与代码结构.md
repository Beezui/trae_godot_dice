# 当前开发进度与代码结构

## 项目概述

本项目是一个基于Godot 4.6.1的3D骰子游戏，名为"晋升吧骰子"。游戏核心功能包括骰子投掷、物理模拟、技能触发等。

## 核心代码文件分析

### 1. dice_6.gd

**功能**：骰子的核心逻辑实现

**主要特性**：
- 继承自RigidBody3D，实现物理模拟
- 支持骰子滚动、碰撞检测
- 技能系统集成
- 粒子特效系统集成
- 骰子结果判定（通过射线检测）

**关键函数**：
- `roll(force, angular_force)`: 投掷骰子，应用力和旋转力
- `check_dice_value()`: 检测骰子最终点数
- `trigger_skill()`: 根据骰子点数触发技能

**物理参数**：
- 质量：0.5
- 线性阻尼：0.1
- 角阻尼：0.03
- 物理材质：反弹系数0.1404，摩擦系数0.8

### 2. dice_demo_script.gd

**功能**：演示场景的控制逻辑

**主要特性**：
- 摄像机控制和视角调整
- 沙盘尺寸计算和碰撞体创建
- 骰子初始状态管理
- 蓄力投掷系统
- 重力设置
- 动态贴图系统集成

**关键参数**：
- 最大蓄力时间：2.0秒
- 最大投掷力度：20.0
- 重力加速度：39.2 m/s²（4倍重力）
- 骰子初始位置：高度6单位，靠近屏幕下方

**输入控制**：
- 空格键：开始/结束蓄力，投掷骰子
- R键：重置骰子到初始状态
- A键：增加骰子（最多6枚）
- S键：减少骰子（最少1枚）
- 1键：切换到normal场景配置
- 2键：切换到skill场景配置

### 3. dice_config.gd

**功能**：骰子配置系统

**主要特性**：
- 管理不同场景的骰子配置
- 支持通过ID配置骰子面
- 提供场景配置切换功能

**关键函数**：
- `get_scene_config(scene_name)`: 获取指定场景的配置
- `add_scene_config(scene_name, config)`: 添加或更新场景配置
- `get_all_scene_names()`: 获取所有场景名称

### 4. dice_face_manager.gd

**功能**：骰子面管理器

**主要特性**：
- 从CSV文件加载骰子面数据
- 管理骰子面ID和贴图路径的映射
- 提供根据ID获取贴图路径的功能

**关键函数**：
- `load_csv()`: 加载CSV文件
- `get_texture_path_by_id(id)`: 根据ID获取贴图路径
- `get_face_by_id(id)`: 根据ID获取骰子面数据

## 关键设置

### 1. 物理设置

- 物理引擎：Jolt Physics
- 重力加速度：39.2 m/s²（4倍现实重力）
- 骰子重力缩放：初始状态为0（悬浮），投掷后为1.0（受重力影响）

### 2. 场景设置

- 摄像机位置：(0, 60, 0)
- 摄像机FOV：15.0
- 沙盘尺寸：宽度24.0，高度13.5（16:9比例）
- 墙体碰撞：北、南、东、西四面墙

### 3. 投掷系统

- 蓄力机制：按住空格键蓄力，松开投掷
- 蓄力时间：0-2秒
- 投掷力度：最小30%最大力度，随蓄力时间增加
- 抛物线运动：投掷时应用向上的力，模拟抛物线轨迹

## 技术实现要点

### 1. 骰子物理模拟

- 使用RigidBody3D实现物理效果
- 通过调整质量、阻尼等参数优化物理表现
- 投掷时应用力和旋转力，模拟真实骰子滚动

### 2. 蓄力系统

- 跟踪蓄力时间
- 根据蓄力时间计算投掷力度
- 应用震动效果增强用户反馈

### 3. 重力控制

- 初始状态禁用重力，使骰子悬浮
- 投掷时启用重力，模拟真实下落
- 调整重力加速度，控制下落时间在1秒以内

### 4. 碰撞检测与结果判定

- 使用射线检测确定骰子最终点数
- 碰撞时触发技能效果
- 检测与其他物体的碰撞
