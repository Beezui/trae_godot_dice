## 本次完成的工作

### 1. 命运骰子结果检测优化

#### 1.1 问题背景
初始实现中，骰子结果检测过快，骰子尚未完全稳定就切换场景，导致：
- 玩家看不清最终结果
- 体验缺乏节奏感和"余韵"

#### 1.2 核心优化

**A. 严格稳定检测（dice_6.gd）**

```gdscript
# 新增变量
var stable_check_count: int = 0
const REQUIRED_STABLE_CHECKS: int = 10  # 连续 10 次检查（共 1 秒）
var is_in_final_wait: bool = false  # 余韵等待状态
const FINAL_WAIT_TIME: float = 1.5  # 余韵时间（秒）

# 检测逻辑
func _on_roll_timer_timeout():
    if is_in_final_wait:
        return
    
    if linear_velocity.length() < 0.03 and angular_velocity.length() < 0.03:
        stable_check_count += 1
        if stable_check_count >= REQUIRED_STABLE_CHECKS:
            is_in_final_wait = true
            final_wait_timer.start()  # 启动 1.5 秒余韵计时器
        else:
            roll_timer.start()  # 继续检查
    else:
        stable_check_count = 0
        roll_timer.start()
```

**B. 余韵等待机制**

```gdscript
## 最终等待超时（余韵时间结束）
func _on_final_wait_timeout():
    is_rolling = false
    is_in_final_wait = false
    check_dice_value()
    
    if dice_type == "character":
        lock_character_dice()
    
    var parent = get_parent()
    if parent and parent.has_method("on_dice_stopped"):
        parent.on_dice_stopped()
```

**C. 状态查询方法**

```gdscript
func get_is_rolling() -> bool:
    # 包括余韵期间也返回 true
    return is_rolling or is_in_final_wait
```

#### 1.3 计时器配置

| 计时器 | 等待时间 | 用途 |
|--------|---------|------|
| roll_timer | 0.1 秒 | 每 0.1 秒检查一次速度 |
| final_wait_timer | 1.5 秒 | 完全稳定后的余韵等待 |

#### 1.4 测试场景等待逻辑（destiny_dice_sandbox_test.gd）

```gdscript
func _wait_for_dice_stable(dices: Array) -> void:
    print("【投掷】等待骰子稳定（包含余韵 1.5 秒）...")
    
    var max_wait_frames = 300  # 约 5 秒（60fps）
    var wait_frames = 0
    
    while wait_frames < max_wait_frames:
        var all_stopped = true
        for dice in dices:
            if dice and is_instance_valid(dice):
                if dice.has_method("get_is_rolling"):
                    if dice.get_is_rolling():
                        all_stopped = false
                        break
        
        if all_stopped:
            break
        
        await get_tree().process_frame
        wait_frames += 1
    
    print("【投掷】骰子已稳定（耗时：", wait_frames / 60.0, "秒）")
```

## 完整时间线

```
投掷 → 每 0.1 秒检查速度
      ↓
    速度 < 0.03 持续 1 秒（10 次检查）
      ↓
    进入余韵状态（is_in_final_wait = true）
    final_wait_timer.start() (1.5 秒)
      ↓
    余韵结束 → check_dice_value() → on_dice_stopped()
      ↓
    切换场景/处理结果
```

**总耗时**: 约 2.5 秒（稳定检测 1 秒 + 余韵 1.5 秒）+ 结果处理

## 设计原理

### 为什么需要余韵？

1. **视觉确认**: 玩家骰子停止后需要时间看清结果
2. **节奏感**: 避免过快切换破坏体验
3. **期待感**: 1.5 秒停顿营造"即将揭晓"的紧张感
4. **自然流畅**: 停止 → 停顿 → 切换，符合直觉

### 稳定检测算法

```
传统方案：速度 < 阈值 → 立即判定停止
          问题：可能误判（骰子还在微动）

改进方案：速度 < 阈值 → 开始计数
          连续 N 次都稳定 → 才判定停止
          优点：过滤微小晃动，更可靠
```
