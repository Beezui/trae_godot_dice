### 4. 血条系统（2D 血条）

#### dice_health_bar_2d.gd
- **文件**: `res://scripts/ui/dice_health_bar_2d.gd`
- **类型**: Node3D（使用 SubViewport + Sprite3D 渲染 2D 血条）

**已实现功能**:
- ✅ 血条始终平行于屏幕（BILLBOARD_ENABLED）
- ✅ 固定在骰子正上方 1.2 单位
- ✅ 不跟随骰子旋转
- ✅ HP 文字显示（14 号字体，居中）
- ✅ 血量颜色渐变（绿→黄→红）
- ✅ 平滑过渡动画
- ✅ 自动创建（角色骰子完全稳定后）

**血条配置**:
```gdscript
var bar_length: float = 0.7       # 血条长度（世界单位）
var bar_height: float = 0.5        # 血条高度（世界单位）
var offset_y: float = 1.2          # 血条在骰子上方的高度
viewport.size = Vector2i(180, 16)  # Viewport 像素尺寸
sprite_3d.pixel_size = 0.012       # 3D 显示大小
hp_label.font_size = 14            # HP 文字大小
```

## 注意事项

1. **MP 平衡**
   - 基础恢复量：10 点/回合
   - 火球术消耗：15 点
   - 暴风雪消耗：25 点
   - 可根据游戏难度调整

2. **技能图标路径**
   - 格式：`res://textures/skill/skill_{id}.png`
   - 如果贴图不存在，骰子会使用备用颜色

3. **敌人配置**
   - 在 LevelNode 的 `data["enemies"]` 中配置敌人 ID 列表
   - 敌人必须是 hero.json 中存在的 ID
