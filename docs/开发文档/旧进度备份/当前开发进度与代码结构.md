# 当前开发进度与代码结构

## 项目概述

本项目是一个基于 Godot 4.6.1 的 3D 骰子游戏，名为"晋升吧骰子"。游戏核心功能包括骰子投掷、物理模拟、技能触发等。

**核心架构特点**：
- ✅ **统一化管理**：所有骰子类型（数字/技能/属性）通过 DiceTextureManager 统一管理
- ✅ **配置驱动**：通过 JSON 配置文件管理骰子属性，无需修改代码
- ✅ **策略模式**：贴图系统采用策略模式，不同骰子类型使用不同策略
- ✅ **Autoload 单例**：核心系统（投掷、检测、贴图、技能）均为 Autoload 单例

## 核心代码文件分析

### 1. dice_6.gd

**功能**：骰子的核心逻辑实现

**主要特性**：
- 继承自 RigidBody3D，实现物理模拟
- 支持骰子滚动、碰撞检测
- 技能系统集成
- 粒子特效系统集成
- 骰子结果判定（通过射线检测）

**关键函数**：
- `roll(force, angular_force)`: 投掷骰子，应用力和旋转力
- `check_dice_value()`: 检测骰子最终点数
- `trigger_skill()`: 根据骰子点数触发技能

**物理参数**：
- 质量：0.5
- 线性阻尼：0.1
- 角阻尼：0.03
- 物理材质：反弹系数 0.1404，摩擦系数 0.8

### 2. dice_demo_script.gd

**功能**：演示场景的控制逻辑

**主要特性**：
- 摄像机控制和视角调整
- 沙盘尺寸计算和碰撞体创建
- 骰子初始状态管理
- 蓄力投掷系统
- 重力设置
- 动态贴图系统集成

**关键参数**：
- 最大蓄力时间：2.0 秒
- 最大投掷力度：20.0
- 重力加速度：39.2 m/s²（4 倍重力）
- 骰子初始位置：高度 6 单位，靠近屏幕下方

**输入控制**：
- 空格键：开始/结束蓄力，投掷骰子
- R 键：重置骰子到初始状态
- A 键：增加骰子（最多 6 枚）
- S 键：减少骰子（最少 1 枚）
- 1 键：切换到 1001 场景配置
- 2 键：切换到 1002 场景配置

### 10. attr_dice.gd

**主要特性**：
- 继承自 RigidBody3D，实现物理模拟

- 动态纹理生成（SubViewport 技术）
- 属性数值叠加显示（在贴图上加文字）
- 投掷结果检测（向量点积法）
- 完整的调试日志系统

**关键函数**：
- `apply_dice_textures(mesh_instance)`: 为六个面应用独立贴图
- `create_face_texture(face_index, static_texture, dynamic_text, face_size)`: 创建动态纹理
- `create_fallback_mesh()`: 创建备用网格（6 个独立表面）
- `check_dice_value()`: 检测朝上的面并输出详细日志
- `update_attributes(hero_attributes, hero_textures)`: 更新属性和贴图
- `get_attribute_value()`: 获取当前朝上面的属性值

**核心技术**：
- SubViewport 离屏渲染生成动态纹理
- ArrayMesh 六表面独立 UV 映射
- StandardMaterial3D 的 UV1 变换设置
- Control 节点的 PRESET_FULL_RECT 布局
- TextureRect 的 STRETCH_SCALE 拉伸模式

### 11. CameraManager.gd（新增）

**功能**：摄像机统一管理器（Autoload 单例）

**主要特性**：
- 统一管理所有场景的摄像机配置
- 提供全局摄像机参数调整接口
- 支持多种预设配置（default, high, low, wide）
- 键盘快捷键控制（Home/End/PageUp/PageDown）
- 3D 倾斜视角，增强视觉立体感

**标准配置**：
- 位置：Vector3(1.3, 50, 14.1)
- 旋转：Vector3(-75 * PI/180, 5.1 * PI/180, -4.9 * PI/180)
- FOV：15.0 度

**关键函数**：
- `register_camera(camera)`: 注册摄像机到管理器
- `apply_to_all_cameras()`: 应用配置到所有注册的摄像机
- `set_preset(preset)`: 切换预设配置
- `reset_to_default()`: 重置为默认配置
- `print_camera_parameters()`: 输出详细参数（调试用）

**使用方法**：
```gdscript
# 在场景脚本中
@onready var camera = $Camera3D

func _ready():
    # 注册摄像机到 CameraManager
    if camera:
        CameraManager.register_camera(camera)
    
    # 可选：切换预设
    # CameraManager.set_preset("high")

func _input(event):
    # 键盘快捷键
    if event.is_action_pressed("ui_home"):
        CameraManager.set_preset("high")
    elif event.is_action_pressed("ui_end"):
        CameraManager.set_preset("low")
```

## 关键设置

### 1. 物理设置

- 物理引擎：Jolt Physics
- 重力加速度：39.2 m/s²（4 倍现实重力）
- 骰子重力缩放：初始状态为 0（悬浮），投掷后为 1.0（受重力影响）

### 2. 场景设置

- **摄像机统一管理**：使用 CameraManager（Autoload 单例）
- **标准配置**：
  - 位置：Vector3(1.3, 50, 14.1)
  - 旋转：Vector3(-75 * PI/180, 5.1 * PI/180, -4.9 * PI/180)
  - FOV：15.0 度
- **3D 倾斜视角**：提供立体感，同时保持场景完整性
- **沙盘尺寸**：宽度 24.0，高度 13.5（16:9 比例）
- **墙体碰撞**：北、南、东、西四面墙
- **预设配置**：default, high, low, wide 四种预设

### 3. 投掷系统

- 蓄力机制：按住空格键蓄力，松开投掷
- 蓄力时间：0-2 秒
- 投掷力度：最小 30% 最大力度，随蓄力时间增加
- 抛物线运动：投掷时应用向上的力，模拟抛物线轨迹

### 4. 属性骰子系统

- 六面独立贴图：每面显示不同的英雄属性贴图
- 动态数值显示：在贴图上加黑色数字显示属性值
- SubViewport 尺寸：最小 512x512，根据骰面 AABB 动态调整
- 材质应用：使用 `surface_set_material()` 为每个表面设置独立材质
- UV 映射：每个面独立的 0-1 完整映射
- 结果检测：向量点积法，检测最接近向上的面
- 调试日志：完整的投掷结果检测日志系统

## 技术实现要点

### 1. 骰子物理模拟

- 使用 RigidBody3D 实现物理效果
- 通过调整质量、阻尼等参数优化物理表现
- 投掷时应用力和旋转力，模拟真实骰子滚动

### 2. 蓄力系统

- 跟踪蓄力时间
- 根据蓄力时间计算投掷力度
- 应用震动效果增强用户反馈

### 3. 重力控制

- 初始状态禁用重力，使骰子悬浮
- 投掷时启用重力，模拟真实下落
- 调整重力加速度，控制下落时间在 1 秒以内

### 4. 碰撞检测与结果判定

- 使用向量点积方法确定骰子最终点数
- 碰撞时触发技能效果
- 检测与其他物体的碰撞
- 确保骰子完全停止运动后再进行结果判定
- 支持根据骰子旋转计算朝上的面

### 5. 技能系统实现

- **技能独立性**：技能代码不依赖特定场景，通过参数传递所有需要的数据
- **场景节点传递**：通过 params 参数传递场景节点，确保技能效果能在任何场景中显示
- **伤害计算**：实现表达式解析器，支持复杂的伤害计算公式（+、-、*、/运算符）
- **资源管理**：技能创建的临时对象（粒子效果、计时器等）正确清理
- **计时器使用**：严格遵循先 add_child() 再 start() 的顺序，确保计时器在场景树中才能启动
- **配置系统**：使用 CSV 作为配置源文件，开发转换工具生成结构化 JSON
- **技能冷却**：SkillManager 统一管理技能冷却时间，在_process() 中更新

### 6. 属性骰子贴图映射（新增）

- **SubViewport 动态纹理生成**：
  - 离屏渲染生成动态纹理
  - UPDATE_ONCE 模式节省性能
  - 透明背景支持
  
- **六面独立映射策略**：
  - ArrayMesh 创建 6 个独立表面
  - 每个表面独立的 UV 坐标（0-1 完整映射）
  - 每个表面独立的材质实例
  
- **材质应用**：
  - 使用 `mesh_instance.mesh.surface_set_material()` 应用材质
  - UV1 变换设置为默认值（scale=1, offset=0）
  - 表面数量检查避免越界
  
- **Control 节点布局**：
  - PRESET_FULL_RECT 锚点设置
  - 明确设置 size 属性
  - STRETCH_SCALE 拉伸模式确保完全覆盖

### 7. 贴图管理系统（新增）⭐

- **DiceTextureManager 统一管理**：
  - 所有骰子类型使用统一接口 `apply_textures_to_dice()`
  - 自动识别骰子类型并选择对应策略
  - Autoload 单例，全局访问
  
- **策略模式实现**：
  - `_apply_normal_dice_textures()` - 数字/技能骰子策略
  - `_apply_attr_dice_textures()` - 属性骰子策略（集成 SubViewport 技术）
  - 支持扩展新策略
  
- **配置格式兼容**：
  - 支持数组格式：`{"values": [1, 2, 3]}`
  - 支持字典格式：`{"values": {0: 1, 1: 2}}`
  - 自动转换：`_preprocess_*_config()` 方法
  
- **Viewport 场景树集成**：
  - 关键：Viewport 必须添加到场景树才能渲染
  - 自动添加到 `mesh_instance.get_parent()`
  - 备用方案：添加到根场景
  - 设置 `auto_cleanup` 标记
  
- **属性骰子文字效果**：
  - 基础字号：288（原始 96 的 300%）
  - 描边效果：双层渲染（331 号深色层 + 288 号主色层）
  - 描边颜色：`darkened(0.8)`（深 80%）
  - 自适应缩小：根据文字长度自动调整
  
- **错误处理**：
  - 完善的日志系统
  - 备用方案（贴图加载失败时使用颜色）
  - 类型安全检查

### 8. 属性骰子文字颜色配置（新增）

- **配置来源**：`attr_dices.json`
- **颜色映射**：
  - 力量（str）：`#C00000`（红色）
  - 敏捷（agi）：`#A9D08E`（绿色）
  - 智力（int）：`#8EA9DB`（蓝色）
- **读取方式**：`_update_points_color_from_config()`
- **默认值**：黑色（配置不存在时）
- **应用**：通过 DiceTextureManager 统一应用

### 9. 角色骰子锁定机制（新增）

- **锁定触发**：骰子停止运动后（速度 < 0.1）自动触发
- **锁定方法**：`lock_character_dice()`
- **锁定步骤**：
  1. 禁用重力：`gravity_scale = 0.0`
  2. 清除速度：`linear_velocity = Vector3.ZERO` 和 `angular_velocity = Vector3.ZERO`
  3. 设置睡眠：`sleeping = true`（防止物理引擎继续计算）
  4. 禁用碰撞：`collision_layer = 0` 和 `collision_mask = 0`
- **类型判断**：通过 `dice_type == "character"` 判断是否为角色骰子
- **类型设置**：创建时调用 `set_dice_type("character")`
- **效果**：角色骰子停止后完全固定，不受任何外力影响
