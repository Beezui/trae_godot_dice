## 开发内容

本次开发完成了从标题界面到游戏主入口的完整流程，实现了以下功能：

### 1. 游戏主入口场景 (game_main)

**文件**: `scenes/game_main/game_main.gd`

**核心功能**:
- 作为关卡网的初始入口场景
- 负责生成关卡数据并设置初始节点（奖励关卡）
- 管理玩家角色和命运骰子的入场流程
- 处理玩家投掷命运骰子选择下一节点

**主要方法**:
```gdscript
_spawn_player()           # 玩家角色入场
_spawn_destiny_dice()     # 命运骰子生成
_start_throw()            # 开始蓄力
_end_throw()              # 投掷骰子
_on_destiny_roll_completed()  # 投掷完成回调
_transition_to_node()     # 关卡转换
```

### 2. 全局加载动画 (LoadingOverlay)

**文件**: `scripts/ui/loading_overlay.gd`

**功能**: 场景切换通用的淡入淡出效果
- 黑色蒙版覆盖层 (CanvasLayer)
- fade_in() / fade_out() 方法
- 信号：fade_in_completed, fade_out_completed
- 辅助方法：wait_fade_in(), wait_fade_out()

**使用示例**:
```gdscript
LoadingOverlay.fade_in(0.3)
await LoadingOverlay.wait_fade_in()
# 加载场景...
LoadingOverlay.fade_out(0.3)
```

### 3. 角色选择界面 (CharacterSelect)

**文件**: `scenes/ui/character_select/character_select.gd`

**功能**:
- 从 hero.json 加载可用角色（type=1 的玩家角色）
- 卡片式选择 UI（支持 1-3 个角色）
- 点击选择/取消选择
- 确认后传递 hero_ids 数组到游戏主入口

**UI 组成**:
- 角色卡片容器（GridContainer）
- 每个卡片包含：头像、名称、属性、选择指示器
- 确认按钮

### 4. 标题界面 (TitleScreen)

**文件**: `scenes/ui/title_screen/title_screen.gd`

**功能**:
- 游戏标题显示
- 开始游戏按钮 → 进入角色选择界面
- 退出游戏按钮

### 5. 地图显示功能

**文件**: `scripts/ui/destiny_dice_map_overlay.gd`

**功能**: 完整复用 destiny_dice_sandbox_test 的地图实现
- 按 M 键显示/隐藏地图
- 显示当前节点和可选择的下一节点
- 高亮显示当前节点

## 游戏流程

```
[标题界面]
    │
    ├─ 点击"开始游戏"
    ▼
[角色选择界面]
    │
    ├─ 选择 1-3 个角色
    ├─ 点击"确认开始游戏"
    ▼
[LoadingOverlay 淡入] (黑色蒙版)
    │
    ├─ 切换到 game_main 场景
    │   - 生成关卡网
    │   - 设置初始节点（奖励关卡）
    │   - 玩家角色入场
    │   - 命运骰子入场
    ▼
[LoadingOverlay 淡出]
    │
    ├─ 按 M 显示地图
    ├─ 按空格键投掷命运骰子
    ▼
[等待骰子稳定]
    │
    ├─ 显示投掷结果
    ├─ 选择下一节点
    ▼
[关卡转换]
    │
    └─ 循环（关卡内流程）
```

## 修复的问题

在开发过程中修复了以下错误：

| 错误 | 修复方式 |
|------|----------|
| `Identifier "PLAYER" not declared` | enum 改为 const (TYPE_PLAYER) |
| `Class "LoadingOverlay" hides autoload` | 移除 class_name 声明 |
| `border_width 属性赋值错误` | 改为 set_border_width_all(2) |
| `get_start_node 方法不存在` | 改为 get_node(level_data.start_node_id) |
| `dice_scene 属性错误` | 改用 destiny_dice_manager.destiny_dice_scene |
| `event.released 属性不存在` | 改为 not event.pressed |
| hero.csv 转 hero.json 数据错乱 | 使用正确的转换脚本 |
