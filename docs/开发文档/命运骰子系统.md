# 命运骰子系统开发文档

## 概述

命运骰子系统用于在关卡转换时，通过投掷骰子的方式选择下一个关卡节点。每个关卡结束时，玩家投掷命运骰子，根据投掷结果前往对应的下一层节点。

## 核心组件

### 1. DestinyDiceConfig（配置数据结构）
文件：`scripts/levels/destiny_dice_config.gd`

负责：
- 存储命运骰子的面配置
- 管理节点类型到骰面的映射
- 处理投掷结果和节点选择

主要属性：
- `faces`: 骰面配置数组（6 个面）
- `current_node_id`: 当前所在节点 ID
- `is_boss_battle`: 是否为 Boss 战
- `type_to_nodes_map`: 类型到节点 ID 的映射
- `dice_face_config`: 骰子面贴图配置

### 2. DestinyDiceManager（管理器）
文件：`scripts/levels/destiny_dice_manager.gd`

负责：
- 生成命运骰子配置
- 创建和管理骰子实例
- 处理投掷流程
- 提供投掷结果查询

主要方法：
- `initialize()`: 初始化命运骰子
- `create_destiny_dice()`: 创建骰子实例
- `throw_destiny_dice()`: 投掷骰子
- `on_roll_completed()`: 处理投掷完成

### 3. LevelTransitionController（关卡转换控制器）
文件：`scripts/levels/level_transition_controller.gd`

负责：
- 处理关卡转换流程
- 管理 Boss 战逻辑
- 触发结算界面

主要方法：
- `start_destiny_dice_flow()`: 启动命运骰子流程
- `execute_transition()`: 执行关卡转换
- `on_boss_battle_completed()`: Boss 战完成处理

### 4. DiceTextureManager 扩展
文件：`scripts/dice/dice_texture_manager.gd`

新增功能：
- 命运骰子类型贴图支持
- Boss 专属贴图支持
- 预加载命运骰子贴图

## 骰面类型

| 类型 ID | 名称 | 颜色 | 说明 |
|--------|------|------|------|
| 1 | 战斗 | 红色 | 普通战斗关卡 |
| 2 | 奇遇 | 蓝色 | 事件/剧情关卡 |
| 3 | 交易 | 黄色 | 商店/补给关卡 |
| 4 | 奖励 | 绿色 | 奖励/宝藏关卡 |
| 5 | 精英战斗 | 深红色 | 精英敌人关卡 |
| 99 | Boss | 紫色 | Boss 专属关卡 |

## 骰面分配规则

1. **统计连接节点类型**：统计当前节点连接的所有下一层节点的类型数量
2. **计算比例**：每种类型的节点数 ÷ 总节点数 = 该类型的比例
3. **分配面数**：比例 × 6 = 该类型应得的面数（向下取整）
4. **剩余分配**：剩余的面数按类型顺序依次分配

### 示例

当前节点连接到 5 个下一层节点：2 战斗、2 奇遇、1 交易

- 战斗：2/5 × 6 = 2.4 → 2 面
- 奇遇：2/5 × 6 = 2.4 → 2 面
- 交易：1/5 × 6 = 1.2 → 1 面
- 已分配：5 面，剩余 1 面
- 剩余 1 面分配给战斗（顺序第一）

最终：战斗 3 面、奇遇 2 面、交易 1 面

## Boss 战处理

### 通向 Boss 的关卡
- 当所有连接节点都是 Boss 节点时，骰子所有面显示 Boss 专属图标
- 投掷后必定进入 Boss 战

### Boss 战后
- Boss 战后无后续节点：直接触发结算，不显示骰子
- Boss 战后有后续节点：正常投掷选择下一关

## 使用示例

### 在关卡场景中集成

```gdscript
extends Node3D

var level_transition_controller: LevelTransitionController
var current_node: LevelNode
var level_data: LevelData

func _ready():
    # 获取控制器实例
    level_transition_controller = LevelTransitionController.get_instance()
    
    # 初始化关卡数据
    level_data = level_generator.get_level_data()
    level_transition_controller.initialize(level_data)
    
    # 设置当前节点
    current_node = level_data.get_node("1")  # 起始节点
    level_transition_controller.set_current_node(current_node)
    
    # 启动命运骰子流程
    level_transition_controller.start_destiny_dice_flow(self)

func _on_throw_button_pressed():
    # 投掷命运骰子
    level_transition_controller.throw_destiny_dice()

func _on_transition_completed(target_node: LevelNode):
    # 关卡转换完成
    current_node = target_node
    print("已到达：", target_node.name)
    
    # 继续下一轮
    if target_node.connections.size() > 0:
        level_transition_controller.start_destiny_dice_flow(self)
```

### 信号连接

```gdscript
func _connect_signals():
    var controller = LevelTransitionController.get_instance()
    controller.on_transition_started.connect(_on_transition_started)
    controller.on_transition_completed.connect(_on_transition_completed)
    controller.on_boss_battle_started.connect(_on_boss_battle_started)
    controller.on_game_clear_triggered.connect(_on_game_clear)
```

## 贴图要求

### 命运骰子类型贴图
需要创建以下贴图文件到 `textures/destiny/` 目录：

- `destiny_type_1.png` - 战斗类型
- `destiny_type_2.png` - 奇遇类型
- `destiny_type_3.png` - 交易类型
- `destiny_type_4.png` - 奖励类型
- `destiny_type_5.png` - 精英战斗类型
- `destiny_boss.png` - Boss 通用贴图

### Boss 专属贴图（可选）
- `boss_<boss_id>.png` - 特定 Boss 的专属贴图

如果贴图不存在，系统会使用备用颜色。

## 项目配置

在 `project.godot` 中添加 autoload：

```ini
[autoload]
DestinyDiceManager="*res://scripts/levels/destiny_dice_manager.gd"
LevelTransitionController="*res://scripts/levels/level_transition_controller.gd"
```

运行 `scenes/test/destiny_dice_test.tscn` 进行测试。

## 注意事项

1. **节点连接**：确保关卡节点的 `connections` 数组正确设置
2. **Boss 判定**：通过节点 `data.boss_id` 判断是否为 Boss 节点
3. **终点处理**：终点节点的 `is_end` 属性应设置为 `true`
4. **贴图加载**：贴图路径使用 `res://` 前缀
5. **信号连接**：确保在投掷前连接好信号
