# 关卡美术场景制作规格说明

## 📋 重要概念澄清

### 双层架构说明

**1. BoundarySystem（碰撞边界系统）- 程序生成**
- 这是**不可见的碰撞墙**，用于限制骰子滚动范围
- 四面墙（北、南、东、西）是**程序动态生成**的碰撞体
- **美术资源中不需要制作墙体碰撞**
- 碰撞墙位置固定，不可更改

**2. VisualSystem（可视系统）- 美术场景**
- 这是**可见的美术场景**，完全由美术资源构成
- **没有"墙体"概念**，使用自然景观、建筑等作为视觉边界
- 例如：村庄场景用树林、房屋、栅栏作为边界
- 完全自由创作，只要不遮挡摄像机视线

### 关键理解

❌ **错误理解**：
- "我需要制作四面墙的美术资源"
- "美术场景要有墙体结构"

✅ **正确理解**：
- "碰撞墙由程序自动处理，我只需要制作美观的场景"
- "用树林、房屋、栅栏、岩石等自然元素作为视觉边界"
- "碰撞墙在场景内部，玩家看不到，只负责阻挡骰子"

## 🎨 美术场景制作要点

### 1. 边界处理技巧

**自然过渡**：
```
❌ 错误做法：
- 在碰撞墙位置制作一堵真实的墙
- 边界过于生硬，像 boxing ring

✅ 正确做法：
- 用树林、岩石、建筑等自然元素形成边界
- 边界元素可以**略微超出**碰撞范围（视觉效果）
- 营造开放感，而非封闭空间
```

**视线引导**：
```
技巧：
1. 边界元素高度渐变（外侧高，内侧低）
2. 使用雾气、光效等模糊边界
3. 边界元素颜色偏暗，降低存在感
4. 中央区域明亮，吸引注意力
```

### 2. 中央开阔区域

**必须遵守**：
```
中央区域：12.0 x 8.0（从中心向四周扩展）
- 保持完全开阔，无任何障碍物
- 地面平坦，无高度变化
- 这是骰子滚动和停留的主要区域
```

**可以添加**：
```
- 地面纹理变化（石板、草地等）
- 低矮装饰（高度 < 0.5，如草丛、小花）
- 粒子特效（不阻挡骰子）
```

### 3. 边界元素布置

**村庄示例布局**：
```
北边界（z = -6.75 附近）：
- 密集树林（3-5 棵树，间距 2-3 单位）
- 木质栅栏（连接树木）
- 地面：草地 + 落叶

- 两侧：路灯 + 花坛

东边界（x = 12 附近）：
- 小屋 1：尺寸 4x4x3，位置 (8, -2.5, -3)
- 小屋 2：尺寸 4x4x3，位置 (8, -2.5, 3)
- 篱笆：连接小屋

西边界（x = -12 附近）：
- 小溪：宽度 2，沿 z 轴延伸
- 石头：3-5 块，随机分布
- 树木：2-3 棵
```

**熔火之窟示例布局**：

**神秘商店示例布局**：

西边界：

### 3. 材质和着色器

**StandardMaterial3D**（Godot 标准材质）：
```
常用参数：
- albedo_color: 基础颜色/贴图
- metallic: 金属度 (0=非金属，1=金属)
- roughness: 粗糙度 (0=镜面，1=完全粗糙)
- normal: 法线贴图 (可选)
- emission: 自发光 (用于熔岩、魔法效果)
```

**特殊效果**：
- **熔岩**：使用 emission 参数 + 动画 shader
- **魔法符文**：使用 emission + 透明混合
- **水面**：使用透明 + 反射

### 4. 纹理尺寸

**推荐尺寸**（2 的幂次方）：
- 小物件：512x512 或 1024x1024
- 建筑墙体：1024x1024 或 2048x2048
- 地面：2048x2048 或 4096x4096

**压缩设置**：
- VRAM 压缩：启用
- Mipmap：启用（避免远处闪烁）
- 各向异性过滤：4x 或 8x（提升斜视角质量）

## 📋 导出和导入流程

### 1. DCC 软件导出设置（Blender/3ds Max/Maya）

**Blender 导出 glTF 2.0**：
```
☑ 应用变换 (Apply Transform)
☑ 前向轴：-Z (Forward Axis: -Z)
☑ 上方向轴：Y (Up Axis: Y)
☑ 导出相机：不勾选 (不要导出相机)
☑ 导出光源：不勾选 (不要导出光源)
☑ 导出 PBR 材质：勾选
☑ 顶点颜色：勾选（如有）
☑ 压缩：不勾选（保持高质量）
```

**单位比例**：
- Blender：1 单位 = 1 米 = Godot 1 单位
- 导出前确认比例正确

**坐标系**：
- Godot：Y 轴向上，-Z 轴向前
- Blender：Z 轴向上，-Y 轴向前
- 导出时自动转换，但需检查

### 2. Godot 导入设置

**3D 模型导入**：
```
导入选项：
- 缩放：1.0 (保持原尺寸)
- 生成碰撞：不勾选（我们使用自定义碰撞）
- 材质：从文件加载
- 网格压缩：启用
- 压缩法线：启用
```

**纹理导入**：
```
导入选项：
- 压缩模式：VRAM 压缩
- 有损压缩：禁用（保持质量）
- Mipmap：启用
- 重复模式：重复（地面材质）或禁用（独特纹理）
```

### 3. 场景组装

**在 Godot 中创建美术场景**：
```gdscript
# 示例：村庄美术场景
res://art_scenes/village.tscn

节点结构：
Village (Node3D)
├── Ground_Mesh (MeshInstance3D)  # 地面
├── Trees (Node3D)                # 树木容器
│   ├── Tree_1 (MeshInstance3D)
│   ├── Tree_2 (MeshInstance3D)
│   └── ...
├── Houses (Node3D)               # 建筑容器
│   ├── House_1 (MeshInstance3D)
│   └── House_2 (MeshInstance3D)
├── Props (Node3D)                # 装饰物容器
│   ├── Fence_1 (MeshInstance3D)
│   ├── Barrel_1 (MeshInstance3D)
│   └── ...
└── Particles (Node3D)            # 粒子特效（可选）
```

**替换 VisualSystem**：
```gdscript
# 在关卡场景脚本中
func _setup_visual_system_art():
    var visual = $VisualSystem
    
    # 清除临时墙体
    for child in visual.get_children():
        child.queue_free()
    
    # 加载美术场景
    var art_scene = load("res://art_scenes/village.tscn").instantiate()
    visual.add_child(art_scene)
    
    # 调整位置（如果需要）
    art_scene.position = Vector3(0, 0, 0)
```

## ⚠️ 重要注意事项

### 1. 尺寸相关（必须遵守）

- ❌ **绝对不要**更改碰撞边界尺寸（24.0 x 13.5）
- ❌ **绝对不要**移动墙壁碰撞位置
- ✅ **必须确保**中央 12x8 区域开阔
- ✅ **必须确保**地面覆盖整个碰撞区域
- ✅ **建议**美术场景在 20x12 范围内

### 2. 性能优化

**Draw Call 优化**：
- 合并相同材质的网格
- 使用纹理图集（Texture Atlas）
- 避免过多独立小物件

**光照优化**：
- 使用烘焙光照（Baked Lightmap）
- 减少实时光源数量
- 使用光照探针（Light Probes）

**LOD 系统**：
- 为大型建筑创建 2-3 个 LOD 层级
- LOD0（高模）：100% 细节
- LOD1（中模）：50% 细节，距离 20 单位
- LOD2（低模）：25% 细节，距离 40 单位

### 3. 视觉一致性

**风格统一**：
- 三个场景应保持统一的美术风格
- 材质 shader 使用应一致
- 光照风格应统一（写实/卡通）

**色彩搭配**：
- 神秘商店：紫色 + 金色 + 暖黄光
- 熔火之窟：红色 + 橙色 + 暗色调
- 村庄：棕色 + 绿色 + 自然光

### 4. 游戏性考虑

**骰子滚动空间**：
- ✅ 中央区域（12 x 8）必须保持开阔
- ❌ 避免在投掷路径上放置障碍物
- ✅ 装饰物应靠边放置

**摄像机视野**：
- ✅ 确保所有重要元素在摄像机视野内
- ❌ 避免过高建筑遮挡视线
- ✅ 考虑摄像机角度（俯视 75°）

**边界视觉引导**：
- ✅ 使用高度渐变引导视线
- ✅ 边界元素颜色偏暗
- ✅ 中央区域明亮突出

## 📞 常见问题

### Q1: 边界应该怎么做？需要墙吗？
**A**: **不需要墙**！使用树林、岩石、建筑等自然元素形成视觉边界。碰撞墙由程序自动生成，玩家看不到。

### Q2: 地面应该放在什么位置？
**A**: Y 坐标 -4.05 到 -4.0 之间，略低于碰撞地面，避免 Z-fighting 闪烁。

### Q3: 中央区域可以放什么？
**A**: 只能放低矮装饰（高度 < 0.5），如草丛、小花、小石头。不能放阻挡骰子滚动的物体。

### Q4: 建筑可以做多高？
**A**: 建议不超过 y=10（从地面向上 6 个单位），避免遮挡摄像机视线。

### Q5: 模型导入后尺寸不对怎么办？
**A**: 检查 DCC 软件的导出设置，确保单位比例为 1.0，并在 Godot 导入设置中调整缩放。

### Q6: 材质显示为粉色？
**A**: 材质丢失或路径错误。重新指定材质或检查纹理路径是否正确。

### Q7: 地面和碰撞面闪烁？
**A**: Z-fighting 问题。将地面网格略低于碰撞面 0.05-0.1 单位。

### Q8: 场景太暗看不清？
**A**: 增加环境光或添加额外光源。可以使用 WorldEnvironment 节点调整环境光。

### Q9: 性能太低怎么办？
**A**: 
1. 减少网格顶点数
2. 使用 LOD 系统
3. 烘焙光照
4. 减少实时光源
5. 合并相同材质的网格
6. 减少边界元素数量

### Q10: 如何让边界看起来更自然？
**A**: 
1. 使用高度渐变（外高内低）
2. 不规则布置元素（避免直线排列）
3. 使用雾气、光效模糊边界
4. 边界元素颜色偏暗
5. 中央区域明亮突出
