## 🔧 故障排除

### 如果还有类型转换错误

**症状**：`Trying to assign an array of type "Array" to a variable of type "Array[String]"`

**解决**：
1. 关闭 Godot 编辑器
2. 删除 `.godot/` 文件夹（Godot 缓存）
3. 重新打开 Godot
4. 重新运行场景

### 如果地图不显示

**检查**：
1. 控制台是否有错误
2. 确认 `core_nodes.json` 和 `random_nodes.json` 存在
3. 确认 LevelGenerator 已注册为 Autoload

### 如果节点挤在一起

**调整**：
编辑 `res://config/level_generation_config.json`：
```json
{
  "layout": {
    "node_spacing_x": 200,  // 增大这个值
    "node_spacing_y": 150,  // 增大这个值
    "layer_padding": 100
  }
}
```
