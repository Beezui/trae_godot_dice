## 游戏主流程

```
标题界面 → 开始游戏
  → 角色选择界面 → 选择角色（单选）→ 确认
    → 游戏主入口（game_main.gd）
      → 生成关卡网
      → 初始节点（奖励关卡）
      → 命运骰子选择下一节点
      → 循环处理关卡节点：
        ├── 战斗/精英战斗 → BattleManager.initialize → 战斗 → 命运骰子
        ├── 奇遇 → 玩家入场 → 奇遇3D面板 → 奇遇骰子 → 效果执行 → 命运骰子
        ├── 贸易 → 商人入场 → 玩家入场 → 折扣骰子 → 商店 → 命运骰子
        └── 奖励 → 玩家入场 → 奖励3D面板 → 奖励骰子 → 效果执行 → 命运骰子
      → 终局节点 → on_game_clear_triggered → 游戏结算
```

### 已知问题与经验

| 问题 | 解决方案 | 日期 |
|------|---------|------|
| layout_mode = 2 导致容器尺寸 0x0，SubViewport/Label 等全部不可见 | **根本原因：`layout_mode = 2` 会让容器报告基于内容的首选尺寸，空内容时宽高都为 0，完全覆盖 `custom_minimum_size` 设置。** 误判过程：6 种方案（SubViewportContainer、MarginContainer、Control 叠加等）全部失败，实际不是渲染问题而是尺寸问题。正确做法：移除父级容器的 `layout_mode = 2`，改用 `custom_minimum_size` 控制尺寸，SubViewport 可通过 SubViewportContainer 正常嵌套在 ScrollContainer 中 | 2026-04-30 |
| BoxMesh 无法为每个骰面设置独立材质 | **BoxMesh 是单一 surface，整个立方体共享一个 `material_override`。** 需要 6 面独立贴图时，必须用 `ArrayMesh.add_surface_from_arrays()` 创建 6 个独立表面，再通过 `mesh.surface_set_material(i, material)` 设置每个面的材质。与 `dice_6.gd` 的 `create_fallback_mesh()` 保持一致。 | 2026-05-01 |
| 技能装配数据未应用到战斗 | **根本原因：`PlayerData.dice_instances` 中存储的用户装配数据（faces）未被战斗系统读取，战斗使用的 `character.skill_dice_ids` 是 `hero.json` 中的静态模板 ID。** 解决方案：修改 `BattleManager._generate_skill_dices_for_character()`，优先从 `PlayerData.get_all_dice_instance_ids()` 读取用户装配的骰子实例，使用 `DiceManager.create_skill_dice_from_player_data()` 创建技能骰子（该方法已支持从 PlayerData 读取 faces 配置）。新增回退方法 `_generate_skill_dices_from_static_config()`：当 PlayerData 中无骰子实例时，使用静态配置。所有核心代码已添加中文注释。 | 2026-05-09 |
| 战斗UI骰子显示空白 + 技能切换锁定 | **问题1（显示空白）**：`_get_skill_icon_path_for_dice()` 查找 `skill_dice_id` meta，但从 PlayerData 创建的骰子只设置 `skill_dice_instance_id`/`skill_dice_template_id`，导致返回空字符串。**问题2（切换锁定）**：`_find_skill_dice_in_scene()` 只查找 `skill_dice_id` meta，旧骰子永远无法被识别移除，场景中骰子累积。**解决方案**：1）修改 `_get_skill_icon_path_for_dice()` 支持两种 meta，从 PlayerData 读取贴图数据；2）修改 `_find_skill_dice_in_scene()` 同时检查两种 meta；3）修改 `_create_skill_button()` 和 `_create_dice_3d_scene()` 为每个面单独设置贴图（与技能装配界面一致）；4）新增 `skill_dice_mesh_instances` 字典保存 mesh 引用。 | 2026-05-09 |

## 关键设计决策记录

1. **关卡模板 ≠ 战斗基类**：关卡模板（`关卡模板.gd`）是 3D 美术场景模板（摄像机/光照/墙体），战斗基类（`BattleSceneBase`）是战斗逻辑框架，两者职责不同，无需统一
2. **角色选择为单选**：从多选改为单选（`50bb225`），简化流程
3. **奇遇骰子 UI 使用序号**：选项显示 1/2/3 等序号，骰子面也显示对应序号数字，当前无需优化
4. **SubViewport 可以通过 SubViewportContainer 嵌套在 ScrollContainer 中**：前提是父级容器不能使用 `layout_mode = 2`（空内容时尺寸 0x0），需用 `custom_minimum_size` 控制尺寸
