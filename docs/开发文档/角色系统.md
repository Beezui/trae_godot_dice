# 角色系统

## 简介

- 管理游戏内的角色相关配置
- 包括玩家角色、敌人角色、npc角色等

## 角色组成

游戏内所有角色都具备以下特征

- 每个角色有各自独立id
- 角色形象为骰子
- 角色拥有血量、力量、敏捷、智力四种基础属性，其中力量、敏捷、智力，在需要使用时通过骰子形式表示，例如某技能需要根据力量进行最终伤害计算，则投掷力量骰子，根据骰子点数计算最终伤害
- 角色拥有携带骰子槽位，不可携带多于槽位的骰子
- 角色只作为技能的发动者和目标

## 角色配置

角色相关配置文件为table/hero.json

- id：角色唯一标识
- name：角色显示名称
- attr_str：角色基础属性，力量
- attr_agi：角色基础属性，敏捷
- attr_int：角色基础属性，智力
- attr_hp：角色基础属性，血量
- skill\_slot：角色携带技能骰子槽位数量
- skill\_dice\_id：角色自带的技能骰子id
- texture：角色属性骰子贴图
- portrait：角色立绘
- hero_texture：角色贴图

表头解析
|表头|是否必填|功能|示例|
|--|--|--|--|
|id|是|角色唯一标识|1|
|name|是|角色显示名称|大脸猫|
|attr_str|是|角色基础属性，力量，数组，对应属性骰子六个面|10;20;30;40;50;60|
|attr_agi|是|角色基础属性，敏捷，数组，对应属性骰子六个面|10;20;30;40;50;60|
|attr_int|是|角色基础属性，智力，数组，对应属性骰子六个面|10;20;30;40;50;60|
|attr_hp|是|角色基础属性，血量|100|
|skill_slot|是|角色携带技能骰子槽位数量|1|
|skill_dice_id|是|角色自带的技能骰子id|10001|
|texture|是|角色属性骰子六个面的贴图,默认路径为"textures\hero\",默认前缀hero_|1001;1002;1003;1004;1005;1006|
|portrait|是|角色立绘，路径为"textures\portrait\",默认前缀portrait_|1|
|hero_texture|是|角色贴图，路径为"textures\hero\",默认前缀hero_id_，这里的“id”就是角色id|idle;hit;attack;anger;happy;die| 例如 hero_1_idle.png

## 角色使用方式

- 必须具备一个场景
- 生成角色时通过id生成
- 生成后以投掷形式入场，但此为自动投掷，除特殊说明外，无需玩家进行，有相应表现即可、
- 角色投掷不响应投掷
- 角色投掷不响应重置位置功能
- 入场后，角色骰子不可被其他外力施加位移
- 入场后，根据角色配置为玩家控制角色生成对应技能骰子和属性骰子，也就是在屏幕下方位置参考已有文档进行相应骰子生成
- 非玩家角色入场后，其技能骰子和属性骰子暂时不用出现在棋盘上，会在后续ui中展示
- 玩家角色在游戏期间相应属性、技能、物品等需进行记录，切换不同关卡、场景时需继承相应内容
- 相应血量以简易ui在角色骰子上展示
