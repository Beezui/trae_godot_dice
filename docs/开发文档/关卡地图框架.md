# 关卡地图框架 - 核心节点剧情设计

## 世界观背景

**蒸汽朋克 + 克苏鲁**混合世界观：
- 蒸汽机械与古老邪神并存
- 科技发展与神秘信仰交织
- 七大教派暗中操控世界走向
- 玩家将在探索中逐渐发现真相，最终反抗邪神

---

## 剧情结构框架

```
初始节点（随机开局）
    ↓
身份节点（身份揭示）
    ↓
成长节点链（意外/奇遇/危机/教派接触）
    ↓
转折节点（发现真相/加入教派/反抗萌芽）
    ↓
最终节点（迎战 BOSS）
```

## 完整剧情路径示例

以下是几条从开局到终局的完整路径示例：

### 路径 1：调查员的正面对决
```
1 异世界重生 → 21 调查员 → 41 村庄异变 → 51 生命教派邀请 → 62 发现邪恶 → 73 调查真相 → 81 爱与生命之母
```
**剧情概述**：穿越异世界后成为调查员，在村庄调查异变时发现生命教派的阴谋，逐步揭开真相，最终直面生命教派的邪神。

### 路径 2：富二代的救赎之路
```
2 灾变幸存者 → 22 富二代 → 42 黑市遭遇 → 54 大墓地秘密 → 64 反抗萌芽 → 76 集结力量 → 84 原点
```
**剧情概述**：灾变后幸存，利用财富在黑市中获得情报，发现大墓地的秘密后加入反抗军，最终挑战死亡邪神。

### 路径 3：佣兵的杀戮之旅
```
3 古老家族后裔 → 23 自由佣兵 → 43 意外撞破 → 52 战争神殿试炼 → 65 背叛逃亡 → 77 最终准备 → 82 唯一胜者
```

## 设计说明

### 1. 剧情跨度
- **出生** → 初始节点（10 种不同开局）
- **成长** → 身份节点 + 三层成长节点（40 个节点）
- **最终 BOSS** → 10 个不同结局

### 2. 多路线设计
- 每个节点有 2-3 个出口，形成网状结构
- 玩家的不同选择导致不同的剧情走向
- 最终迎战不同的 BOSS

### 3. 世界观融合
- 蒸汽朋克元素：蒸汽机械、齿轮、飞艇、钟塔
- 克苏鲁元素：邪神、低语、疯狂、未知恐惧
- 七大教派：贯穿剧情始终

### 4. 叙事风格
- 简短介绍，留有想象空间
- 节点之间不必完全交代，保持神秘感
- 玩家在选择中逐步发现真相

### 5. 教派设定
- 前期：接触、诱惑、试探
- 中期：发现邪恶、动摇信仰
- 后期：反抗、决战
