# 关卡系统测试说明

## 🎮 如何测试

### 1. 打开测试场景
在 Godot 编辑器中打开：
```
res://scenes/test/level_map_test.tscn
```

### 2. 运行场景
- 按 **F5** 运行整个项目，或
- 按 **F6** 仅运行当前场景

### 3. 查看结果
场景启动后会自动：
1. 初始化 LevelGenerator 单例
2. 生成关卡地图
3. 在 UI 上显示

### 4. 交互操作
- **按 R 键**：重新生成关卡
- **点击"重新生成"按钮**：重新生成关卡
- **点击"打印日志"按钮**：在控制台输出详细日志
- **拖动地图**：在地图上按住左键拖动查看

## 📊 UI 说明

### 顶部信息栏
- **难度**：当前游戏难度（默认 1）
- **总关卡**：生成的总节点数
- **种子**：随机种子值（用于重复生成相同地图）

### 地图区域
- **红色节点**：战斗关卡
- **蓝色节点**：奇遇关卡
- **黄色节点**：交易关卡
- **绿色节点**：奖励关卡
- **粗边框**：核心节点
- **细边框**：随机节点
- **白色连线**：节点之间的路径（箭头指示方向）

### 底部按钮
- **重新生成**：重新生成关卡地图
- **打印日志**：在控制台输出详细信息

## ⚠️ 常见问题

### Q: 运行后没有任何显示？
A: 检查控制台日志，查看是否有错误信息。确保：
- LevelGenerator 单例已正确注册
- core_nodes.json 和 random_nodes.json 存在
- 场景中的节点引用正确

### Q: 按 R 键报错？
A: 确保 LevelMapDisplay 节点已正确加载。检查：
- 场景文件中的节点引用
- level_map_display.gd 脚本是否附加到正确的节点

### Q: 地图显示不完整？
A: 使用滚动条或拖动查看完整地图。地图会自动调整大小以适应所有节点。

### Q: 节点挤在一起看不清？
A: 可以修改 config/level_generation_config.json 中的布局参数：
- `node_spacing_x`：增大 X 轴间距
- `node_spacing_y`：增大 Y 轴间距
- `layer_padding`：增大层级边距
