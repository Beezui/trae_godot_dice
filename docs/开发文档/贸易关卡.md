# 贸易关卡

生成需求如下
1. 需要一个npc商人，为此，在hero表中新增了一个type=5的类型，代表商人
2. 商人可能有多个，生成逻辑和创建敌人逻辑相同，需要考虑stage字段和type字段
3. 入场方式保持当前入场方式，但是贸易关卡中商人优先入场，玩家角色后入场
4. 需要创建一个折扣骰子，用于打开商店页面及计算折扣
5. 折扣骰子采用固定配置，骰面分别为0%/10%/10%/15%/20%/50%
6. 玩家入场后，生成相应折扣骰子，玩家投掷后根据骰子结果计算折扣并打开商店页面
7. 创建一个新的csv文件，用于管理游戏全部道具，并在tool/convert_skill_csv_to_json.py中添加对该文件的处理逻辑
8. 道具表需具备以下字段：
   - id：道具id
   - name：道具名称
   - type：道具类型
   - price：道具价格
   - description：道具描述
   - icon：道具图标路径,默认前缀路径为"res://textures/items/"
   - weight：道具权重，在商店中根据权重随机显示道具
9. 创建商店页面，需为全局唯一单例，每个贸易关卡都公用同一个页面
10. 玩家进入贸易关卡时需初始化商店页面，按照道具表权重随机生成道具并显示在商店页面，每个商店随机刷新8-10个道具，每个道具占一个网格单元，每个道具在当前商店只允许购买一次
11. 玩家投掷折扣骰子后，根据骰子结果计算折扣并更新商店页面，保留整数，并显示相应折扣数量
12. 处理玩家购买道具逻辑，包括检查玩家是否有足够的金币，更新玩家金币数量，更新商店页面道具数量等
13. 商店页面中需要有前进按钮，点击后结束本次交易，生成命运骰子，重复默认关卡流程
