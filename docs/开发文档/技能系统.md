# 技能系统

## 简介
- 管理游戏内的技能相关配置

## 技能组成
- 技能id：每个技能都有一个独立id，用于区分不同的技能
- 技能名称：每个技能都有一个名称，用于显示在游戏内
- 技能描述：每个技能都有一个描述，用于详细说明技能的功能和效果
- 技能图标：每个技能都有一个图标，用于显示在游戏内

## 技能配置
游戏全部技能配置在table/skill.csv文件中
表格信息如下
|表头名|是否必填|功能|示例|
|id|是|技能id|10001|
|名称|是|技能名称|技能1|
|描述|是|技能描述|技能1的描述|
|属性类型|是|根据技能效果，例如力量、敏捷、智力等，可能涉及多枚骰子，于描述中序号对应|
|图标|是|技能图标,路径为"textures/skill/"目录下，前缀为skill_|
示例：
|10001|火球术|向最近目标发射一枚火球，造成力量骰子点数（骰子1）×2点伤害,命中目标后爆炸，对范围内敌人造成敏捷骰子点数（骰子2）×2点伤害|1:力量,2:敏捷|10001|

## 技能释放流程

1.施法者投掷技能骰子
2.根据技能骰子结果触发技能
3.触发该技能后，根据技能配置，投掷对应属性骰子
4.施法者释放技能
5.根据属性骰子结果进行结果判断

示例：
1.玩家行动时准备释放技能
2.玩家投掷技能骰子，结果为10001，则触发火球术技能
3.根据技能配置，火球术需投掷力量骰子和敏捷骰子，结果分别为3和2
4.玩家释放火球术，向目标发射一枚火球，命中目标后爆炸
5.根据属性骰子结果，命中目标时造成3（力量骰子点数）×2=6点伤害，对范围内敌人造成2（敏捷骰子点数）×2=4点伤害
