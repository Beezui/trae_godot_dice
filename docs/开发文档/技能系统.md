# 技能系统开发文档

## 简介

技能系统使用 CSV 配置 + JSON 数据的方式管理游戏内所有技能。通过修改 CSV 配置文件即可设计新技能，无需修改代码。

## 系统架构

```
skill.csv (配置源文件)
    ↓
convert_skill_csv_to_json.py (转换工具)
    ↓
skill.json (游戏运行时数据)
    ↓
skill_system.gd (技能管理系统)
    ↓
游戏场景 (调用技能)
```

## CSV 配置格式

### 表头结构

```csv
id，名称，描述，图标，p1, p2, p3, p4, p5, p6
```

| 列名 | 说明 | 示例 |
|------|------|------|
| id | 技能 ID（唯一标识） | 10001 |
| 名称 | 技能名称 | 火球术 |
| 描述 | 技能描述，使用 p1/p2 等占位符 | "造成 p1 点伤害" |
| 图标 | 技能图标标识 | 10001 |
| p1-p6 | 参数计算公式（最多 6 个） | str*2 |

### 参数公式语法

支持以下属性变量：
- `str` - 力量（Strength）
- `agi` - 敏捷（Agility）
- `int` - 智力（Intelligence）

支持的运算符：
- `*` - 乘法
- `/` - 除法
- `+` - 加法
- `-` - 减法
- 小数 - 如 `1.5`、`0.5`

**公式示例**：
```csv
str*2           # 力量 × 2
agi*3 + int     # 敏捷 × 3 + 智力
int*1.5         # 智力 × 1.5
str*2 + agi     # 力量 × 2 + 敏捷
```

### 完整 CSV 示例

```csv
id，名称，描述，图标，p1,p2,p3,p4,p5,p6
10001，火球术，"向最近目标发射一枚火球，造成 p1 点伤害，命中目标后爆炸，对范围内敌人造成 p2 点伤害",10001,str*2,agi*2,,,,
10002，闪电链，"对目标及周围敌人造成 p1 点伤害",10002,int*3,,,,,
10003，冰冻术，"冻结目标 p1 秒",10003,int*1,,,,,
10004，毒爆术，"造成 p1 点伤害，并在 p2 秒内每秒造成 p3 点伤害",10004,int*2,int*1,int*0.5,,,
```

## JSON 数据结构

### 技能对象字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 技能 ID |
| name | String | 技能名称 |
| description | String | 技能描述（含 p1/p2 占位符） |
| icon | String | 技能图标 |
| parameters | Object | 参数公式集合 {p1: "str*2", ...} |
| attribute_dice | Object | 属性骰子映射 {1: "力量", 2: "敏捷"} |
| damage_formulas | Object | 伤害公式集合（同 parameters） |

### 2. CSV 读取器（skill_csv_reader.gd）

```gdscript
extends RefCounted

var skills = {}

func _init():
	load_skills()

func load_skills():
	var file = FileAccess.open("res://table/skill.json", FileAccess.READ)
	if not file:
		print("Error: Cannot open skill.json")
		return
	
	var json_text = file.get_as_text()
	file.close()
	
	var json = JSON.new()
	var parse_result = json.parse(json_text)
	
	if parse_result != OK:
		print("Error parsing skill.json: ", json.get_error_message())
		return
	
	var data = json.get_data()
	if not data is Dictionary or not data.has("skills"):
		print("Error: skill.json missing 'skills' array")
		return
	
	var skills_array = data["skills"]
	for skill_data in skills_array:
		if skill_data is Dictionary and skill_data.has("id"):
			var skill_id = str(skill_data["id"])
			skills[skill_id] = skill_data
			print("Loaded skill: ", skill_id, " - ", skill_data.get("name", "Unknown"))
	
	print("Skill JSON loading complete. Total skills: ", skills.size())

func get_skill(skill_id: String) -> Dictionary:
	return skills.get(skill_id, {})

func get_all_skills() -> Dictionary:
	return skills

func get_skill_count() -> int:
	return skills.size()
```

### 3. 伤害计算（fireball_skill_test.gd 参考）

```gdscript
# 伤害计算主函数
func _calculate_damage():
	print("=== 伤害结算 ===")
	
	# 获取技能配置
	var skill = skill_system.get_skill(current_skill_id)
	if skill.is_empty():
		print("Error: Skill configuration not found!")
		return
	
	var parameters = skill.get("parameters", {})
	var attribute_dice_map = skill.get("attribute_dice", {})
	
	# 获取骰子结果
	var dice_results = {}
	_collect_dice_results(attribute_dice_map, dice_results)
	
	# 根据参数公式计算伤害
	var damage_results = {}
	for param_name in parameters.keys():
		var formula = parameters[param_name]
		var damage = _calculate_formula(formula, dice_results)
		damage_results[param_name] = damage
		print("参数 ", param_name, " (", formula, ") = ", damage)
	
	# 显示伤害结算信息
	_print_damage_results(damage_results)

# 收集骰子结果
func _collect_dice_results(attribute_dice_map: Dictionary, dice_results: Dictionary):
	if attribute_dice_map.has("1"):
		var attr_type = attribute_dice_map["1"]
		if attr_type == "力量" and power_dice:
			dice_results["str"] = power_dice.get_dice_value()
		elif attr_type == "敏捷" and agility_dice:
			dice_results["agi"] = agility_dice.get_dice_value()
		elif attr_type == "智力" and intelligence_dice:
			dice_results["int"] = intelligence_dice.get_dice_value()
	
	if attribute_dice_map.has("2"):
		var attr_type = attribute_dice_map["2"]
		if attr_type == "力量" and power_dice:
			dice_results["str"] = power_dice.get_dice_value()
		elif attr_type == "敏捷" and agility_dice:
			dice_results["agi"] = agility_dice.get_dice_value()
		elif attr_type == "智力" and intelligence_dice:
			dice_results["int"] = intelligence_dice.get_dice_value()

# 计算公式
func _calculate_formula(formula: String, dice_results: Dictionary) -> int:
	# 替换变量
	var evaluated_formula = formula
	
	if dice_results.has("str"):
		evaluated_formula = evaluated_formula.replace("str", str(dice_results["str"]))
	if dice_results.has("agi"):
		evaluated_formula = evaluated_formula.replace("agi", str(dice_results["agi"]))
	if dice_results.has("int"):
		evaluated_formula = evaluated_formula.replace("int", str(dice_results["int"]))
	
	# 计算表达式
	var result = _evaluate_expression(evaluated_formula)
	return result

# 表达式求值（支持 + - * /）
func _evaluate_expression(expr: String) -> int:
	var tokens = expr.replace(" ", "").split("+")
	var total = 0.0
	
	for token in tokens:
		if "-" in token and token != tokens[0]:
			var parts = token.split("-")
			if parts.size() == 2:
				total += _evaluate_multiplication(parts[0])
				total -= _evaluate_multiplication(parts[1])
			else:
				total += _evaluate_multiplication(token)
		else:
			total += _evaluate_multiplication(token)
	
	return int(total)

func _evaluate_multiplication(expr: String) -> float:
	var tokens = expr.split("*")
	var result = 1.0
	
	for token in tokens:
		if "/" in token:
			var div_parts = token.split("/")
			if div_parts.size() == 2:
				result *= float(div_parts[0]) / float(div_parts[1])
			else:
				result *= float(token)
		else:
			result *= float(token)
	
	return result
```

## 技能设计示例

### 示例 1：单体伤害技能

```csv

```

**效果**：
- 使用力量骰子
- 伤害 = 力量 × 2

### 示例 2：多重伤害技能

```csv
10002，毒爆术，"造成 p1 点伤害，并在 p2 秒内每秒造成 p3 点伤害",10002,int*2,int*1,int*0.5,,,
```

**效果**：
- 使用智力骰子
- 初始伤害 = 智力 × 2
- 持续时间 = 智力 × 1 秒
- DOT 伤害 = 智力 × 0.5

### 示例 3：混合属性技能

```csv
10003，圣光术，"造成 p1 点神圣伤害，并恢复 p2 点生命值",10003,str*1.5,int*2,,,,
```

**效果**：
- 使用力量骰子和智力骰子
- 伤害 = 力量 × 1.5
- 治疗 = 智力 × 2

### 示例 4：复杂公式技能

```csv
10004，闪电链，"对目标造成 p1 点伤害，并连锁到附近敌人",10004,int*2+agi,,,,,
```

- 使用智力和敏捷骰子
- 伤害 = 智力 × 2 + 敏捷

## 注意事项

1. **CSV 编码**：使用 UTF-8 编码，避免中文乱码
2. **占位符格式**：描述中使用 `p1`、`p2`，不要用其他格式
3. **公式变量**：只能使用 `str`、`agi`、`int` 三个变量
4. **参数数量**：最多支持 p1-p6 共 6 个参数
5. **空参数**：不使用的参数列留空
6. **转换后重启**：修改 CSV 后需要运行转换工具并重启 Godot
