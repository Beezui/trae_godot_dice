# 技能系统配置格式说明

## 概述

技能配置使用 CSV 格式存储，通过转换工具生成 JSON 文件供游戏使用。

## CSV 格式

### 表头结构

```
id, 名称，描述，图标，p1, p2, p3, p4, p5, p6
```

- **id**: 技能 ID（如：10001）
- **名称**: 技能名称（如：火球术）
- **描述**: 技能描述，使用 `p1`、`p2` 等占位符代表参数值
- **图标**: 技能图标标识
- **p1-p6**: 参数计算公式（最多支持 6 个参数）

### 参数公式

参数公式支持以下属性变量：

| 变量 | 含义 | 对应属性骰子 |
|------|------|-------------|
| `str` | 力量 (Strength) | 力量骰子 |
| `agi` | 敏捷 (Agility) | 敏捷骰子 |
| `int` | 智力 (Intelligence) | 智力骰子 |

### 公式示例

```csv
str*2      # 力量骰子点数 × 2
agi*3      # 敏捷骰子点数 × 3
int*2+5    # 智力骰子点数 × 2 + 5
str+agi    # 力量骰子 + 敏捷骰子
```

## 完整示例

### CSV 配置

```csv
id，名称，描述，图标，p1,p2,p3,p4,p5,p6
10001，火球术，"向最近目标发射一枚火球，造成 p1 点伤害，命中目标后爆炸，对范围内敌人造成 p2 点伤害",10001,str*2,agi*2,,,,
```

### 转换后的 JSON

```json
{
  "skills": [
    {
      "id": "10001",
      "name": "火球术",
      "description": "向最近目标发射一枚火球，造成 p1 点伤害，命中目标后爆炸，对范围内敌人造成 p2 点伤害",
      "icon": "10001",
      "parameters": {
        "p1": "str*2",
        "p2": "agi*2"
      },
      "attribute_dice": {
        "1": "力量",
        "2": "敏捷"
      },
      "damage_formulas": {
        "p1": "str*2",
        "p2": "agi*2"
      }
    }
  ]
}
```

## 字段说明

### parameters（参数配置）
- 存储所有 p1-p6 的计算公式
- 用于描述中的占位符替换
- 用于实际伤害计算

### attribute_dice（属性骰子映射）
- 自动根据公式中的变量生成
- `str` → "力量"
- `agi` → "敏捷"
- `int` → "智力"
- 用于确定需要投掷哪些属性骰子

### damage_formulas（伤害公式）
- 与 parameters 相同
- 用于技能释放时的伤害计算

## 使用流程

### 1. 编辑 CSV 配置

在 `table/skill.csv` 中添加或修改技能：

```csv
id，名称，描述，图标，p1,p2,p3,p4,p5,p6
10001，火球术，"造成 p1 点伤害",10001,str*2,,,,,
10002，闪电链，"对目标及周围敌人造成 p1 点伤害",10002,int*3,,,,,
10003，冰冻术，"冻结目标 p1 秒",10003,int*1,,,,,
```

### 2. 运行转换工具

```bash
cd tools/
python convert_skill_csv_to_json.py
```

### 3. 在游戏中使用

```gdscript
# 获取技能配置
var skill = skill_system.get_skill("10001")

# 获取参数公式
var p1_formula = skill.parameters.p1  # "str*2"

# 计算伤害（伪代码）
var str_value = get_attribute_dice_result("力量")
var damage = str_value * 2

# 或者使用公式计算器
var damage = calculate_formula(p1_formula, {
    "str": str_value,
    "agi": agi_value,
    "int": int_value
})
```

## 注意事项

1. **描述占位符**：使用 `p1`、`p2` 等，不要使用 `attr_dice_1` 等旧格式
2. **公式变量**：只能使用 `str`、`agi`、`int` 三个变量
3. **公式格式**：支持基本的数学运算（+、-、*、/）和小数
4. **空参数**：不使用的参数留空即可
5. **编码格式**：CSV 文件使用 UTF-8 编码，避免中文乱码

## 转换工具

### 位置
```
res://tools/convert_skill_csv_to_json.py
```

### 功能
- 自动检测 CSV 编码（UTF-8、GBK、GB2312）
- 解析 p1-p6 参数公式
- 自动识别属性类型（str/agi/int）
- 生成结构化的 JSON 文件

### 运行方式
```bash
# 默认路径
python tools/convert_skill_csv_to_json.py

# 指定路径
python tools/convert_skill_csv_to_json.py path/to/skill.csv path/to/skill.json
```
