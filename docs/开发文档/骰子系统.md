## 简介
- 管理游戏内的骰子相关配置
- 包括骰子的物理模拟、投掷系统、碰撞检测、结果判定等

## 骰子分类
游戏内骰子大致分为以下几类
- 空白骰子：骰面为空白，不输出任何结果，作为容器可变换为其余骰子，例如在某个空白骰子上放置技能则变为技能骰子，放置物品则变为物品骰子，放置魔药则变为魔药骰子等，空白骰子固定为6面，每个面都没有结果，固定使用贴图textures\dice\blank_face.png
- 数字骰子：基本骰子类型，骰面为数字，输出结果为相应骰面数字
- 技能骰子：骰面为技能图标，输出结果为技能id，通过id触发相应技能
- 物品骰子：骰面为物品图标，输出结果为物品id，通过id使用相应物品
- 魔药骰子：骰面为材料图标，投掷结果为材料id，通过id判定炼制魔药是否成功。
- 属性骰子：骰面用数字表示而不是贴图而是文本字符串，其骰面为角色属性数值，会根据角色属性数值发生变化

## 骰子配置

配置文件采用**JSON 优先，CSV 回退**的策略，读取路径在项目文件夹 `table` 之中。

### 配置加载策略

- **优先加载 JSON 格式**：代码首先尝试加载 JSON 配置文件
- **CSV 作为回退**：当 JSON 文件不存在时，自动回退到 CSV 格式加载
- **属性骰子使用双配置**：属性骰子同时使用 `hero.json`（属性值和贴图）和 `attr_dices.json`（文字颜色）

### 数字骰子

**配置文件**: `NumDices.json`（优先） / `NumDices.csv`（回退）

**JSON 数据结构**:
```json
{
  "num_dices": [
    {
      "id": "1001",
      "face_count": 6,
      "values": [1, 2, 3, 4, 5, 6],
      "textures": ["dice_face_1", "dice_face_2", "dice_face_3", "dice_face_4", "dice_face_5", "dice_face_6"]
    }
  ]
}
```

**字段说明**:
|字段 | 类型 | 是否必填 | 功能 | 示例 |
|-----|------|---------|------|------|
| id | String | 是 | 骰子 id | "1001" |
| face_count | Integer | 是 | 骰子面数 | 6 |
| values | Array | 是 | 骰子各面对应点数，按骰面顺序排列 | [1, 2, 3, 4, 5, 6] |
| textures | Array | 是 | 骰子贴图 ID，按骰面顺序排列，贴图路径为 `res://textures/dice/dice_face_{id}.png` | ["dice_face_1", ...] |

**CSV 格式**（回退用）:
|表头 | 是否必填 | 功能 | 示例 |
|------|---------|------|------|
| id | 是 | 骰子 id | 1001 |
| face_count | 是 | 骰子面数 | 6 |
| values | 是 | 骰子各面对应点数，以组形式表示，按骰面顺序排列 | 1,2,3,4,5,6 |
| textures | 是 | 骰子贴图，以组形式表示，按骰面顺序排列，贴图路径在 `textures\dice\` 目录下，前缀默认为 `dice_face_` | 1,2,3,4,5,6 |

### 技能骰子

**配置文件**: `SkillDices.json`（优先） / `SkillDices.csv`（回退）

**JSON 数据结构**:
```json
{
  "skill_dices": [
    {
      "id": "1",
      "face_count": 6,
      "skill_ids": ["10001", "10002", "10003", "10004", "10005", "10006"]
    }
  ]
}
```

**字段说明**:
|字段 | 类型 | 是否必填 | 功能 | 示例 |
|------|------|---------|------|------|
| id | String | 是 | 骰子 id | "1" |
| face_count | Integer | 是 | 骰子面数 | 6 |
| skill_ids | Array | 是 | 骰子各面对应技能 id，按骰面顺序排列，可为空（为空时当前面作为空白骰子面） | ["10001", "10002", ...] |

**说明**: 
- 技能骰子每面绑定一个技能，贴图对应技能 icon
- 需要根据技能 id 从 `skill.json` 中获取贴图
- 例如：技能 10001 的贴图为 `skill.json` 中 10001 的 `icon` 字段

### 属性骰子

**配置文件**: 
- `hero.json`（主要配置）：属性值、贴图
- `attr_dices.json`（辅助配置）：文字颜色

**hero.json 数据结构**:
```json
{
  "heroes": [
    {
      "id": "1",
      "name": "测试角色",
      "attr_str": ["5", "11", "17", "23", "29", "35"],
      "attr_agi": ["4", "10", "16", "22", "30", "32"],
      "attr_int": ["1", "2", "3", "4", "5", "10"],
      "attr_hp": "100",
      "skill_slot": "1",
      "skill_dice_id": ["4001"],
      "texture": ["1001", "1001", "1001", "1001", "1001", "1001"],
      "portrait": "1",
      "hero_texture": ["hit", "idle", "idle", "idle", "idle", "idle"]
    }
  ]
}
```

**attr_dices.json 数据结构**:
```json
{
  "attr_dices": {
    "1": {
      "hero_id": "1",
      "hero_name": "测试角色",
      "power": {
        "attr_name": "str",
        "points_color": "#C00000",
        "values": [5, 11, 17, 23, 29, 35]
      },
      "agility": {
        "attr_name": "agi",
        "points_color": "#A9D08E",
        "values": [4, 10, 16, 22, 30, 32]
      },
      "intelligence": {
        "attr_name": "int",
        "points_color": "#8EA9DB",
        "values": [1, 2, 3, 4, 5, 10]
      }
    }
  }
}
```

**字段说明**:

**hero.json 字段**:
|字段 | 类型 | 是否必填 | 功能 | 示例 |
|------|------|---------|------|------|
| id | String | 是 | 英雄 id | "1" |
| name | String | 是 | 英雄名称 | "测试角色" |
| attr_str | Array | 是 | 力量属性值数组，骰子各面对应数值 | ["5", "11", ...] |
| attr_agi | Array | 是 | 敏捷属性值数组，骰子各面对应数值 | ["4", "10", ...] |
| attr_int | Array | 是 | 智力属性值数组，骰子各面对应数值 | ["1", "2", ...] |
| attr_hp | String | 是 | 英雄血量 | "100" |
| skill_slot | String | 是 | 技能骰子槽位数量 | "1" |
| skill_dice_id | Array | 是 | 技能骰子配置 id 数组 | ["4001"] |
| texture | Array | 是 | 英雄骰子贴图 id 数组，按骰面顺序排列 | ["1001", ...] |
| portrait | String | 是 | 英雄立绘 id | "1" |
| hero_texture | Array | 是 | 英雄状态贴图数组 | ["hit", "idle", ...] |

**attr_dices.json 字段**:
|字段 | 类型 | 是否必填 | 功能 | 示例 |
|------|------|---------|------|------|
| hero_id | String | 是 | 英雄 id | "1" |
| hero_name | String | 是 | 英雄名称 | "测试角色" |
| power | Object | 是 | 力量属性配置 | - |
| agility | Object | 是 | 敏捷属性配置 | - |
| intelligence | Object | 是 | 智力属性配置 | - |
| attr_name | String | 是 | 属性名 | "str", "agi", "int" |
| points_color | String | 是 | 字色，属性数值文字颜色 | "#C00000"（红色） |
| values | Array | 是 | 骰子各面对应属性数值 | [5, 11, 17, ...] |

**说明**:
- 属性骰子的骰面使用文本字符串显示属性数值，而不是贴图
- 属性骰子通过 `attr_dice_manager.gd` 创建和管理
- 配置从 `hero.json` 读取属性值和贴图，使用 `hero_csv_reader.gd` 解析
- 文字颜色从 `attr_dices.json` 读取，使用 `dice_csv_reader.gd` 解析
- 每个英雄有三个属性骰子：力量（str）、敏捷（agi）、智力（int）
- 不同属性类型使用不同文字颜色：力量=红色 (#C00000)，敏捷=绿色 (#A9D08E)，智力=蓝色 (#8EA9DB)
