# 摄像机水平倾斜测试说明（临时）

## 本次调整

### 1. 水平倾斜（绕 z 轴旋转）

**倾斜角度**: **5°**（默认预设）

**效果**: 
- ✅ 增强立体感和视觉层次
- ✅ 场景有轻微的动态感
- ✅ 不会引起眩晕或不适

### 2. 水平位移配合

**x 轴位移**: **2 单位**（向右）

**原因**: 
- 水平倾斜 5° 后，场景会向左偏移
- 向右移动 2 单位，保持场景在视野中心
- 确保所有场景内容仍然可见

## 所有预设配置

| 预设 | 位置 (x, y, z) | 俯视角度 | 水平倾斜 | 说明 |
|------|---------------|---------|---------|------|
| **default** | (2, 60, 3) | -88° | **5°** | 标准视角 |
| **high** | (1.5, 80, 2) | -87° | **4°** | 高位视角 |
| **low** | (2.5, 40, 4) | -89° | **6°** | 低位视角 |
| **wide** | (2, 60, 3) | -88° | **5°** | 广角视角 |

### 为什么不同预设的倾斜角度不同？

- **default (5°)**: 标准倾斜角度，平衡立体感和舒适度
- **high (4°)**: 高位视角因为高度更高，倾斜角度相应减小
- **low (6°)**: 低位视角因为高度更低，倾斜角度相应增大
- **wide (5°)**: 广角视角保持标准倾斜

## 调整建议

### 如果倾斜角度不合适

**增加倾斜**（更明显）:
```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-88 * PI/180, 0, 8 * PI/180)  # 8° 倾斜
# 或
camera_rotation = Vector3(-88 * PI/180, 0, 10 * PI/180)  # 10° 倾斜
```

**减少倾斜**（更轻微）:
```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-88 * PI/180, 0, 3 * PI/180)  # 3° 倾斜
# 或
camera_rotation = Vector3(-88 * PI/180, 0, 2 * PI/180)  # 2° 倾斜
```

**完全移除水平倾斜**:
```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-88 * PI/180, 0, 0)  # 无水平倾斜
camera_position = Vector3(0, 60, 3)  # x=0，居中
```

### 如果场景不在中心

**场景偏左**（需要向右移动）:
```gdscript
# 增加 x 值
camera_position = Vector3(3, 60, 3)  # 向右 3 单位
# 或
camera_position = Vector3(4, 60, 3)  # 向右 4 单位
```

**场景偏右**（需要向左移动）:
```gdscript
# 减少 x 值
camera_position = Vector3(1, 60, 3)  # 向右 1 单位
# 或
camera_position = Vector3(0, 60, 3)  # 居中
```

## 推荐角度范围

**水平倾斜推荐范围**: **3° 到 8°**

- **3°**: 轻微倾斜，几乎看不出
- **5°**: 适中倾斜，有明显立体感 ✅ 当前使用
- **8°**: 明显倾斜，立体感很强
- **>10°**: 倾斜太大，可能引起不适 ❌ 不推荐

**x 轴位移推荐范围**: **1 到 4**

- 根据倾斜角度自动调整
- 5° 倾斜 → x=2（当前配置）
- 8° 倾斜 → x=3 或 4
- 3° 倾斜 → x=1 或 2
