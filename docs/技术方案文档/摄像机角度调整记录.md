# 摄像机角度调整记录

## 问题描述

用户反馈：倾斜角度太大（-80°），导致看不到场景，影响游戏视野。

## 解决方案

将摄像机角度从 **-80°** 调整为 **-88°**，接近完全俯视，保持场景完整性。

## 角度对比

| 角度 | 效果 | 用户反馈 | 状态 |
|------|------|---------|------|
| **-90°** | 完全俯视，完全平面 | 缺乏立体感 | ❌ 不推荐 |
| **-88°** | **接近完全俯视，几乎看不到侧面** | **刚刚好，保持场景完整** | ✅ **已采用** |
| **-85°** | 轻微倾斜，能看到少量侧面 | 可以接受 | ⚠️ 备选 |
| **-80°** | 明显倾斜，看到较多侧面 | 倾斜太大，看不到场景 | ❌ 不可用 |

## 后续调整建议

### 如果觉得还是太倾斜

可以调整为 -89° 或 -90°：

```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-89 * PI/180, 0, 0)  # -89°，更接近完全俯视
# 或
camera_rotation = Vector3(-PI/2, 0, 0)  # -90°，完全俯视（无倾斜）
```

### 如果想要稍微多一点立体感

可以调整为 -86° 或 -85°：

```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-86 * PI/180, 0, 0)  # -86°，轻微倾斜
# 或
camera_rotation = Vector3(-85 * PI/180, 0, 0)  # -85°，更明显的倾斜
```

### 推荐角度范围

**推荐范围**: **-88° 到 -90°**

- **-88°**: 接近完全俯视，有极轻微立体感 ✅ 当前使用
- **-89°**: 几乎完全俯视，立体感更弱
- **-90°**: 完全俯视，无立体感（平面）

**不推荐**: 小于 -85° 的角度会影响场景视野
