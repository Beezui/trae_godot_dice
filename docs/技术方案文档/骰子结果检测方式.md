# 骰子结果检测方式

## 概述

本文档详细介绍了骰子结果检测的实现方式，包括核心代码、原理说明和使用方法。

## 核心检测代码

### 1. 结果检测核心函数

```gdscript
func check_dice_value():
	# 如果有控制结果，直接使用控制值
	if controlled_result != -1:
		dice_value = controlled_result
		has_valid_result = true
		print("Dice rolled (controlled): ", dice_value)
		trigger_skill()
		return
	
	# 直接根据骰子的旋转计算朝上的面
	var up_direction = Vector3.UP
	var dice_transform = global_transform
	var global_directions = []
	
	# 定义骰子六个面的本地方向，与create_fallback_mesh函数中的面索引顺序匹配
	var local_directions = [
		Vector3(0, 0, -1),  # 前面 (面索引0)
		Vector3(0, 0, 1),   # 后面 (面索引1)
		Vector3(-1, 0, 0),  # 左面 (面索引2)
		Vector3(1, 0, 0),   # 右面 (面索引3)
		Vector3(0, 1, 0),   # 顶面 (面索引4)
		Vector3(0, -1, 0)   # 底面 (面索引5)
	]
	
	# 将每个面的本地方向转换为全局方向
	for local_dir in local_directions:
		global_directions.append(dice_transform.basis * local_dir)
	
	# 找到最接近全局向上方向的面
	var max_dot = -1
	closest_index = 0
	
	for i in range(global_directions.size()):
		var dot = up_direction.dot(global_directions[i])
		if dot > max_dot:
			max_dot = dot
			closest_index = i
	
	# 设置骰子值，使用从CSV读取的点数配置
	if dice_value_config.size() > 0:
		# 使用从CSV读取的点数配置
		dice_value = dice_value_config.get(closest_index, 1)
	else:
		# 使用默认值
		var values = [1, 2, 3, 4, 5, 6]
		dice_value = values[closest_index]
	has_valid_result = true
	print("Dice rolled: ", dice_value)
	trigger_skill()
```

```gdscript
func _on_roll_timer_timeout():
```

```gdscript
func _on_result_check_timeout():
	# 定期检查骰子状态
	if not is_rolling and not has_valid_result:
		# 骰子停止但没有有效结果，应用预防措施
		_apply_preventive_measure()
```

### 4. 预防措施

```gdscript
func _apply_preventive_measure():
	# 应用预防措施，给骰子施加随机力使其重新运动
	if not is_rolling:
		is_rolling = true
		# 施加随机的线性力
		var linear_force = Vector3(
			randf_range(-2, 2),
			randf_range(1, 3),
			randf_range(-2, 2)
		)
		# 施加随机的旋转力
		var angular_force = Vector3(
			randf_range(-5, 5),
			randf_range(-5, 5),
			randf_range(-5, 5)
		)
		
		# 应用力
		linear_velocity = linear_force
		angular_velocity = angular_force
		
		print("Applied preventive measure: small force to reposition dice")
		
		# 重启滚动计时器
		roll_timer.start()
```

### 5. 控制结果功能

```gdscript
func _on_result_control_timeout():
	# 控制骰子结果
	if controlled_result != -1:
		# 计算目标旋转
		var target_rotation = get_target_rotation(controlled_result)
		# 平滑过渡到目标旋转
		rotation = target_rotation
		# 确保骰子稳定
		linear_velocity = Vector3.ZERO
		angular_velocity = Vector3.ZERO
		# 直接设置骰子值
		dice_value = controlled_result
		has_valid_result = true
		print("Controlled dice result: ", dice_value)
		# 重置控制状态
		controlled_result = -1

func get_target_rotation(value: int) -> Quaternion:
	# 根据骰子值计算目标旋转
	match value:
		1:
			# 1点朝上
			return Quaternion()
		2:
			# 2点朝上
			return Quaternion(Vector3(0, 1, 0), deg_to_rad(90))
		3:
			# 3点朝上
			return Quaternion(Vector3(0, 0, 1), deg_to_rad(-90))
		4:
			# 4点朝上
			return Quaternion(Vector3(0, 0, 1), deg_to_rad(90))
		5:
			# 5点朝上
			return Quaternion(Vector3(0, 1, 0), deg_to_rad(-90))
		6:
			# 6点朝上
			return Quaternion(Vector3(0, 1, 0), deg_to_rad(180))
		_:
			return Quaternion()
```

## 检测原理

### 1. 向量点积方法

- **基本原理**：使用向量点积计算骰子每个面的法线与全局向上方向的夹角
- **具体步骤**：
  1. 获取骰子的全局变换矩阵
  2. 计算每个面的全局法线方向
  3. 与全局向上方向（Vector3.UP）计算点积
  4. 找到点积最大的面，即最接近向上方向的面

### 2. 停止检测机制

- **停止条件**：当骰子的线性速度和角速度都小于0.1时，认为骰子已停止
- **超时处理**：如果骰子在计时器超时后仍未停止，重新启动计时器继续等待
- **结果判定时机**：只有在骰子完全停止后才进行结果判定，确保结果的准确性

## 面索引与配置对应关系

### 面索引定义

| 面索引 | 本地方向 | 对应方向 | 默认点数 |
|--------|----------|----------|----------|
| 0 | Vector3(0, 0, -1) | 前面 | 1 点 |
| 1 | Vector3(0, 0, 1) | 后面 | 2 点 |
| 2 | Vector3(-1, 0, 0) | 左面 | 3 点 |
| 3 | Vector3(1, 0, 0) | 右面 | 4 点 |
| 4 | Vector3(0, 1, 0) | 顶面 | 5 点 |
| 5 | Vector3(0, -1, 0) | 底面 | 6 点 |

### 点数配置说明

- **点数配置来源**：通过 `dice_csv_reader.gd` 从 CSV 配置文件读取
- **配置格式**：`dice_value_config` Dictionary，键为面索引，值为点数
- **默认配置**：当没有 CSV 配置时，使用默认值 `[1, 2, 3, 4, 5, 6]`
- **自定义配置**：可通过修改 CSV 配置文件来自定义每个面的点数


## 实现细节

### 1. 面方向定义

- 与 `create_fallback_mesh` 函数中的面索引顺序保持一致
- 确保每个面的法线方向正确指向外部

### 2. 全局方向转换

- 使用 `transform.basis * local_dir` 将本地方向转换为全局方向
- 考虑骰子的旋转，确保方向计算准确

### 3. 结果判定时机

- 确保骰子完全停止后再进行结果判定
- 避免在骰子滚动过程中进行判定，确保结果的一致性

### 4. 错误处理

- 即使骰子处于特殊姿势，也能通过向量点积找到最接近向上方向的面
- 不需要额外的预防措施，因为总能找到一个面作为朝上的面

## 优势

1. **准确性**：使用向量点积方法计算，结果准确可靠
2. **稳定性**：不受周围环境影响，只依赖骰子自身的旋转
3. **效率**：计算简单，性能开销小
4. **一致性**：确保骰子完全停止后再进行判定，结果一致

## 使用方法

1. **配置骰子面**：通过 CSV 配置文件设置每个面的点数（使用 `dice_csv_reader.gd` 读取）
2. **加载贴图**：通过 `dice_csv_reader.gd` 从 CSV 文件加载贴图路径和点数配置
3. **投掷骰子**：调用 `roll` 方法投掷骰子
4. **等待结果**：骰子停止后自动进行结果判定
5. **获取结果**：通过 `get_dice_value` 方法获取骰子结果

## 注意事项

1. **面索引顺序**：确保 `local_directions` 数组的顺序与 `create_fallback_mesh` 函数中的面索引顺序一致
2. **配置对应**：确保 `dice_value_config` 与 CSV 配置文件中的配置对应
3. **停止检测**：确保在骰子完全停止后再进行结果判定
4. **方向计算**：确保方向转换正确，考虑骰子的旋转
5. **CSV 配置**：确保 CSV 配置文件格式正确，包含面索引、贴图路径和点数配置

## 结论

向量点积方法是一种高效、准确的骰子结果检测方式，通过计算每个面与全局向上方向的夹角，找到最接近向上方向的面作为朝上的面。结合停止检测机制，确保骰子完全停止后再进行结果判定，提高了结果的一致性和可靠性。

这种方法不受周围环境影响，只依赖骰子自身的旋转，适用于各种场景和骰子类型。
