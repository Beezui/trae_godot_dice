# 统一摄像机管理器使用指南

## 概述

`CameraManager` 是一个 Autoload 单例，用于统一管理所有场景的摄像机配置。通过此管理器，可以：

- ✅ **统一配置**：一处修改，全局生效
- ✅ **动态调整**：运行时实时调整摄像机参数
- ✅ **预设支持**：快速切换不同摄像机配置
- ✅ **自动注册**：场景中的摄像机会自动应用配置

## 配置参数

### 标准配置（默认）

```gdscript
位置：Vector3(0, 60, 0)    # 正上方 60 单位
FOV: 15.0                   # 15 度视野（接近平视）
旋转：Vector3(-PI/2, 0, 0) # -90 度俯视
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `camera_position` | Vector3 | (0, 60, 0) | 摄像机位置 |
| `camera_fov` | float | 15.0 | 视野角度（度数） |
| `camera_rotation` | Vector3 | (-90°, 0, 0) | 摄像机旋转 |

## 使用方法

### 方法 1：场景脚本中使用（推荐）

在场景脚本的 `_ready()` 方法中注册摄像机：

```gdscript
extends Node3D

@onready var camera = $Camera3D

func _ready():
    # 注册摄像机到管理器（自动应用配置）
    CameraManager.register_camera(camera)
    
    # 后续只需修改 CameraManager 的配置，所有场景同步更新
```

### 方法 2：运行时动态调整

在任何场景中都可以通过 `CameraManager` 调整摄像机：

```gdscript
# 调整位置
CameraManager.update_position(Vector3(0, 80, 0))

# 调整 FOV
CameraManager.update_fov(20.0)

# 调整旋转
CameraManager.update_rotation(Vector3(-PI/2, 0.5, 0))

# 使用预设
CameraManager.set_preset("high")  # 高位视角
CameraManager.set_preset("low")   # 低位视角
CameraManager.set_preset("wide")  # 广角视角
CameraManager.set_preset("default")  # 默认视角

# 重置为默认
CameraManager.reset_to_default()
```

### 方法 3：批量应用到所有场景

```gdscript
# 修改配置
CameraManager.camera_position = Vector3(0, 100, 0)
CameraManager.camera_fov = 10.0

# 应用到所有已注册的摄像机
CameraManager.apply_to_all_cameras()
```

## 预设配置

## 完整示例

### 示例 1：标准场景脚本

```gdscript
extends Node3D

@onready var camera = $Camera3D
@onready var sandbox = $Sandbox

func _ready():
    # 1. 注册摄像机（自动应用统一配置）
    CameraManager.register_camera(camera)
    
    # 2. 设置沙盘等其他配置...
    _setup_sandbox()

func _setup_sandbox():
    # 沙盘设置代码...
    pass

func _input(event):
    # 按 H 键切换高位视角
    if event.is_action_pressed("ui_home"):
        CameraManager.set_preset("high")
    
    # 按 L 键切换低位视角
    if event.is_action_pressed("ui_end"):
        CameraManager.set_preset("low")
    
    # 按 R 键重置为默认
    if event.is_action_pressed("ui_cancel"):
        CameraManager.reset_to_default()
```

### 示例 2：UI 控制摄像机

```gdscript
extends Control

@onready var fov_slider = $VBoxContainer/FOVSlider
@onready var height_slider = $VBoxContainer/HeightSlider

func _ready():
    # 初始化滑块值
    fov_slider.value = CameraManager.camera_fov
    height_slider.value = CameraManager.camera_position.y
    
    # 连接信号
    fov_slider.value_changed.connect(_on_fov_changed)
    height_slider.value_changed.connect(_on_height_changed)

func _on_fov_changed(value):
    CameraManager.update_fov(value)

func _on_height_changed(value):
    var new_pos = CameraManager.camera_position
    new_pos.y = value
    CameraManager.update_position(new_pos)
```

### 示例 3：摄像机动画

```gdscript
extends Node3D

var is_animating: bool = false

func _ready():
    CameraManager.register_camera($Camera3D)

func _input(event):
    if event.is_action_pressed("ui_accept"):
        # 空格键播放摄像机动画
        if not is_animating:
            animate_camera()

func animate_camera():
    is_animating = true
    
    # 动画 1：拉远摄像机
    var tween = create_tween()
    tween.tween_method(
        func(value):
            var pos = CameraManager.camera_position
            pos.y = value
            CameraManager.update_position(pos),
        CameraManager.camera_position.y,  # 起始值
        100.0,  # 目标值
        2.0  # 持续时间
    )
    
    tween.tween_method(
        func(value):
            CameraManager.update_fov(value),
        CameraManager.camera_fov,  # 起始值
        10.0,  # 目标值
        2.0  # 持续时间
    )
    
    tween.tween_callback(func(): is_animating = false)
```

## 注意事项

### ✅ 推荐做法

```gdscript
# 1. 在 _ready() 中注册摄像机
func _ready():
    CameraManager.register_camera($Camera3D)

# 2. 使用 CameraManager 统一管理
CameraManager.update_fov(20.0)

# 3. 使用预设快速切换
CameraManager.set_preset("high")
```

### ❌ 不推荐做法

```gdscript
# 1. 直接修改摄像机属性（绕过管理器）
camera.position = Vector3(0, 100, 0)  # ❌ 不会被统一管理

# 2. 在多个地方重复设置
camera.fov = 15.0  # ❌ 应该使用 CameraManager

# 3. 忘记注册摄像机
# func _ready():
#     pass  # ❌ 没有调用 register_camera()
```

## 配置持久化

如果需要保存摄像机配置，可以使用 Godot 的 `ConfigFile`：

```gdscript
# 保存配置
func save_camera_config():
    var config = ConfigFile.new()
    config.set_value("camera", "position", CameraManager.camera_position)
    config.set_value("camera", "fov", CameraManager.camera_fov)
    config.set_value("camera", "rotation", CameraManager.camera_rotation)
    config.save("user://camera_config.cfg")

# 加载配置
func load_camera_config():
    var config = ConfigFile.new()
    var err = config.load("user://camera_config.cfg")
    if err == OK:
        CameraManager.camera_position = config.get_value("camera", "position", Vector3(0, 60, 0))
        CameraManager.camera_fov = config.get_value("camera", "fov", 15.0)
        CameraManager.camera_rotation = config.get_value("camera", "rotation", Vector3(-PI/2, 0, 0))
        CameraManager.apply_to_all_cameras()
```

## 技术细节

### 单例模式

`CameraManager` 使用 Autoload 单例模式，确保全局只有一个实例：

```gdscript
static var _instance: CameraManager = null

func _ready():
    _instance = self

static func get_instance() -> CameraManager:
    return _instance
```

### 自动注册机制

场景中的摄像机需要手动注册到管理器：

```gdscript
func register_camera(camera: Camera3D):
    if not registered_cameras.has(camera):
        registered_cameras.append(camera)
    apply_camera_config(camera)
```

### 批量更新

修改配置后，调用 `apply_to_all_cameras()` 批量应用：

```gdscript
func apply_to_all_cameras():
    for camera in registered_cameras:
        if camera and is_instance_valid(camera):
            apply_camera_config(camera)
```

## 常见问题

### Q1: 为什么需要注册摄像机？
**A**: 管理器需要知道哪些摄像机应该被统一管理。注册后，管理器会自动应用配置并在配置变更时更新所有已注册的摄像机。

### Q2: 可以在运行时切换预设吗？
**A**: 可以！随时调用 `CameraManager.set_preset("preset_name")` 即可。

### Q3: 如果场景中有多个摄像机怎么办？
**A**: 可以注册多个摄像机，它们都会应用相同的配置。如果需要不同的配置，可以创建多个管理器实例（不推荐）。

### Q4: 摄像机会不会自动添加到管理器？
**A**: 不会。需要在场景脚本中手动调用 `CameraManager.register_camera()`。这是为了避免不必要的摄像机被注册。

### Q5: 如何移除已注册的摄像机？
**A**: 调用 `CameraManager.cleanup_invalid_cameras()` 会自动清理无效（已销毁）的摄像机。也可以手动从 `registered_cameras` 数组中移除。
