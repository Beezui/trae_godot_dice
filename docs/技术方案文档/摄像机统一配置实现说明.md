# 摄像机统一配置实现说明

## 实现目标

解决多个场景摄像机配置不统一的问题，实现：
- ✅ 一处修改，全局生效
- ✅ 运行时动态调整
- ✅ 预设配置快速切换
- ✅ 向后兼容现有场景

## 核心实现

### 1. CameraManager 单例

**位置**: `res://scripts/camera_manager.gd`

**功能**:
- 统一管理所有场景的摄像机配置
- 提供注册、更新、预设切换等功能
- 作为 Autoload 单例，全局访问

**配置参数**:
```gdscript
@export var camera_position: Vector3 = Vector3(0, 60, 0)
@export var camera_fov: float = 15.0
@export var camera_rotation: Vector3 = Vector3(-PI/2, 0, 0)
```

### 2. 场景使用方法

#### 旧方式（各场景独立设置）
```gdscript
# ❌ 每个场景都要重复设置
func _setup_camera():
    camera.position = Vector3(0, 60, 0)
    camera.fov = 15.0
    camera.rotation = Vector3(-PI/2, 0, 0)
```

#### 新方式（统一管理）
```gdscript
# ✅ 只需注册到管理器
func _ready():
    CameraManager.register_camera(camera)
```

### 3. 运行时控制

#### 键盘快捷键（使用 Godot 默认输入映射）

| 按键 | 功能 | 输入动作 |
|------|------|---------|
| **Home** | 高位视角 (high) | `ui_home` |
| **End** | 低位视角 (low) | `ui_end` |
| **Page Up** | 广角视角 (wide) | `ui_page_up` |
| **Page Down** | 默认视角 (default) | `ui_page_down` |

**说明**：这些按键是 Godot 引擎的默认输入映射，无需额外配置即可使用。

#### 代码控制
```gdscript
# 调整位置
CameraManager.update_position(Vector3(0, 80, 0))

# 调整 FOV
CameraManager.update_fov(20.0)

# 使用预设
CameraManager.set_preset("high")
```

## 预设配置

| 预设名称 | 位置 | FOV | 用途 |
|---------|------|-----|------|
| `default` | (0, 60, 0) | 15.0 | 标准俯视（推荐） |
| `high` | (0, 80, 0) | 12.0 | 更高视角 |
| `low` | (0, 40, 0) | 20.0 | 更低视角 |
| `wide` | (0, 60, 0) | 25.0 | 广角视角 |

## 迁移指南

### 逐步迁移现有场景

#### 步骤 1: 确认 CameraManager 已添加为 Autoload
1. 打开 Godot 项目设置
2. 进入 Autoload 标签
3. 添加 `res://scripts/camera_manager.gd`
4. 确认名称为 `CameraManager`

#### 步骤 2: 修改场景脚本

**修改前**:
```gdscript
extends Node3D

@onready var camera = $Camera3D

func _ready():
    camera.position = Vector3(0, 60, 0)
    camera.fov = 15.0
    camera.rotation = Vector3(-PI/2, 0, 0)
```

**修改后**:
```gdscript
extends Node3D

@onready var camera = $Camera3D

func _ready():
    # 注册到 CameraManager（自动应用配置）
    CameraManager.register_camera(camera)
    
    # 可选：添加键盘控制
    # 在 _input() 中添加摄像机切换逻辑
```

#### 步骤 3: 测试验证
1. 运行场景，确认摄像机配置正确
2. 按键盘 1/2/3/0 键切换视角
3. 检查控制台输出确认注册成功

### 批量更新建议

如果有大量场景需要更新，可以：

1. **优先更新常用场景**（如测试场景、主场景）
2. **新建场景使用新方式**
3. **旧场景保持兼容**（不修改也能正常运行）

## 技术优势

### 1. 统一管理
- 所有场景摄像机配置集中在一处
- 修改 `CameraManager` 的参数即可影响所有场景

### 2. 动态调整
- 运行时可随时调整摄像机参数
- 支持动画和过渡效果

### 3. 预设支持
- 快速切换不同配置
- 可自定义预设

### 4. 调试友好
- 输出详细日志
- 支持列出已注册的摄像机

### 5. 向后兼容
- 不修改现有场景也能正常运行
- 新旧方式可以共存

## 注意事项

### ✅ 推荐做法
```gdscript
# 1. 在 _ready() 中注册
func _ready():
    CameraManager.register_camera($Camera3D)

# 2. 使用统一管理
CameraManager.update_fov(20.0)

# 3. 使用预设
CameraManager.set_preset("high")
```

### ❌ 不推荐做法
```gdscript
# 1. 直接修改属性（绕过管理器）
camera.position = Vector3(0, 100, 0)  # ❌

# 2. 忘记注册
func _ready():
    pass  # ❌ 没有注册摄像机

# 3. 重复设置
camera.fov = 15.0  # ❌ 应该使用 CameraManager
```

## 示例代码

### 完整场景脚本示例
```gdscript
extends Node3D

@onready var camera = $Camera3D
@onready var sandbox = $Sandbox

func _ready():
    # 1. 注册摄像机
    CameraManager.register_camera(camera)
    
    # 2. 设置其他...
    _setup_sandbox()

func _input(event):
    # 切换视角预设
    if event.is_action_pressed("ui_1"):
        CameraManager.set_preset("high")
    elif event.is_action_pressed("ui_2"):
        CameraManager.set_preset("low")
    elif event.is_action_pressed("ui_0"):
        CameraManager.reset_to_default()
```

### UI 控制示例
```gdscript
extends Control

func _on_fov_slider_changed(value):
    CameraManager.update_fov(value)

func _on_height_slider_changed(value):
    var pos = CameraManager.camera_position
    pos.y = value
    CameraManager.update_position(pos)
```
