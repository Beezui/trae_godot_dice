# 摄像机控制按键更新说明

## 问题描述

之前使用了不存在的输入映射 `ui_0`, `ui_1`, `ui_2`, `ui_3`，导致运行时错误：

```
Error: The InputMap action "ui_0" doesn't exist. Did you mean "ui_up"?
```

## 解决方案

改用 Godot 引擎**默认存在的输入映射**，无需额外配置即可使用。

## 新的按键映射

| 功能 | 原按键 | 新按键 | 输入动作 | 状态 |
|------|--------|--------|---------|------|
| 高位视角 | 1 键 | **Home** | `ui_home` | ✅ 已修复 |
| 低位视角 | 2 键 | **End** | `ui_end` | ✅ 已修复 |
| 广角视角 | 3 键 | **Page Up** | `ui_page_up` | ✅ 已修复 |
| 默认视角 | 0 键 | **Page Down** | `ui_page_down` | ✅ 已修复 |

## Godot 默认输入映射

以下输入动作是 Godot 引擎内置的，无需在 `项目设置` → `输入映射` 中配置：

| 输入动作 | 默认按键 | 用途 |
|---------|---------|------|
| `ui_accept` | 空格键 / Enter | 确认、投掷骰子 |
| `ui_cancel` | R 键 / Escape | 取消、重置 |
| `ui_home` | Home 键 | 回到起点、高位视角 |
| `ui_end` | End 键 | 跳到结尾、低位视角 |
| `ui_page_up` | Page Up 键 | 向上翻页、广角视角 |
| `ui_page_down` | Page Down 键 | 向下翻页、默认视角 |
| `ui_up` | W 键 / ↑ | 向上移动 |
| `ui_down` | S 键 / ↓ | 向下移动 |
| `ui_left` | A 键 / ← | 向左移动 |
| `ui_right` | D 键 / → | 向右移动 |

## 使用方式

### 在代码中使用

```gdscript
func _input(event):
    # 按 Home 键切换高位视角
    if event.is_action_pressed("ui_home"):
        CameraManager.set_preset("high")
    
    # 按 End 键切换低位视角
    if event.is_action_pressed("ui_end"):
        CameraManager.set_preset("low")
    
    # 按 Page Up 键切换广角视角
    if event.is_action_pressed("ui_page_up"):
        CameraManager.set_preset("wide")
    
    # 按 Page Down 键重置为默认视角
    if event.is_action_pressed("ui_page_down"):
        CameraManager.reset_to_default()
```

### 自定义按键（可选）

如果你想使用其他按键，可以在 `项目设置` → `输入映射` 中添加：

1. 打开 `项目` → `项目设置`
2. 选择 `输入映射` 标签
3. 点击 `+` 添加新动作（如 `camera_high`）
4. 点击 `+` 添加按键绑定（如数字键 1）
5. 在代码中使用：
   ```gdscript
   if event.is_action_pressed("camera_high"):
       CameraManager.set_preset("high")
   ```

## 优点

### 使用默认输入映射 ✅

- ✅ **无需配置**：Godot 内置的输入映射，开箱即用
- ✅ **兼容性好**：所有 Godot 项目都支持
- ✅ **不易出错**：不会出现 "action doesn't exist" 错误
- ✅ **用户熟悉**：Home/End/PageUp/PageDown 是常用的导航键

### 避免自定义输入映射 ⚠️

- ⚠️ **需要配置**：必须在项目设置中添加
- ⚠️ **容易遗漏**：忘记配置会导致错误
- ⚠️ **维护成本**：需要文档说明如何配置

## 最佳实践

### ✅ 推荐：使用默认输入映射

```gdscript
# 使用 Godot 默认存在的输入动作
if event.is_action_pressed("ui_home"):
    # ...
```

### ⚠️ 仅在必要时自定义

只有当默认输入映射不够用时，才自定义输入映射：

```gdscript
# 例如：需要专门的摄像机控制键
if event.is_action_pressed("camera_zoom_in"):
    # ...
```
