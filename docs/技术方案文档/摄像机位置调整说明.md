# 摄像机位置调整说明

## 问题描述

用户反馈：部分场景不在屏幕中，需要将摄像机向屏幕下方移动。

## 解决方案

将摄像机在 z 轴上向正方向（屏幕下方/南墙方向）移动，确保所有场景内容都在视野内。

## 坐标系统说明

在 Godot 的 3D 坐标系中：
- **z 轴正方向** = 屏幕下方（南墙）
- **z 轴负方向** = 屏幕上方（北墙）
- **y 轴正方向** = 上方（高度）
- **x 轴正方向** = 右方

```
        北墙（z 负方向）
            ↑
            |
  西墙 ←----+----→ 东墙
  (x 负)    |    (x 正)
            |
            ↓
        南墙（z 正方向）= 屏幕下方
```

## 调整详情

### 标准配置（default）

**调整前**: `Vector3(0, 60, 0)`
**调整后**: `Vector3(0, 60, 3)`

**变化**: z 坐标从 0 增加到 3，向屏幕下方移动 3 个单位

### 所有预设配置

| 预设 | 调整前 | 调整后 | 移动距离 |
|------|--------|--------|---------|
| **default** | (0, 60, **0**) | (0, 60, **3**) | 向下 3 单位 |
| **high** | (0, 80, **0**) | (0, 80, **2**) | 向下 2 单位 |
| **low** | (0, 40, **0**) | (0, 40, **4**) | 向下 4 单位 |
| **wide** | (0, 60, **0**) | (0, 60, **3**) | 向下 3 单位 |

### 为什么不同预设移动距离不同？

- **default (3 单位)**: 标准视角，向下移动 3 单位，平衡视野
- **high (2 单位)**: 高位视角，因为高度更高（80），视野更广，只需向下 2 单位
- **low (4 单位)**: 低位视角，因为高度更低（40），视野更窄，需要向下 4 单位
- **wide (3 单位)**: 广角视角，与标准位置相同，FOV 更大

## 调整原理

### 摄像机位置计算

```gdscript
# 原始位置
camera_position = Vector3(0, 60, 0)

# 调整后位置
camera_position = Vector3(0, 60, 3)
#                    x  y  z
#                    |  |  |
#                    |  |  └─ 向屏幕下方（南墙）移动 3 单位
#                    |  └──── 高度 60 单位
#                    └─────── x 轴居中
```

### 为什么是 z=3？

- **沙盘尺寸**: 24.0 × 13.5（16:9 比例）
- **南墙位置**: z = 6.75
- **北墙位置**: z = -6.75
- **中心位置**: z = 0

**z=3 的优势**:
- ✅ 向南墙方向移动，但不靠近南墙
- ✅ 保持居中视野
- ✅ 确保南墙附近的骰子在视野内
- ✅ 不会导致北墙内容缺失

## 后续调整建议

### 如果还是看不到所有场景

可以继续向南移动（增加 z 值）：

```gdscript
# 在 camera_manager.gd 中修改
camera_position = Vector3(0, 60, 5)  # 向下移动 5 单位
# 或
camera_position = Vector3(0, 60, 7)  # 向下移动 7 单位（接近南墙）
```

**注意**: z 值不要超过 6.75（南墙位置），否则会超出沙盘

### 如果移动太多

可以减少 z 值：

```gdscript
# 在 camera_manager.gd 中修改
camera_position = Vector3(0, 60, 2)  # 向下移动 2 单位
# 或
camera_position = Vector3(0, 60, 1)  # 向下移动 1 单位
```

### 快速测试不同位置

```gdscript
func _input(event):
    # 按 = 键向南移动
    if event.keycode == KEY_EQUAL:
        camera_position.z += 1
        print("当前 z 位置：", camera_position.z)
    
    # 按 - 键向北移动
    if event.keycode == KEY_MINUS:
        camera_position.z -= 1
        print("当前 z 位置：", camera_position.z)
```

## 坐标参考

### 沙盘关键位置

| 位置 | z 坐标 | 说明 |
|------|--------|------|
| **北墙** | -6.75 | 屏幕上方墙体 |
| **中心** | 0 | 沙盘中心 |
| **南墙** | 6.75 | 屏幕下方墙体 |
| **摄像机（旧）** | 0 | 原摄像机位置 |
| **摄像机（新）** | 3 | 新摄像机位置 |

### 推荐范围

**摄像机 z 坐标推荐范围**: **2 到 5**

- **z=2**: 轻微向南移动
- **z=3**: 适中向南移动 ✅ 当前使用
- **z=4**: 较多向南移动
- **z=5**: 明显向南移动

**不推荐**:
- **z<0**: 向北移动，可能导致南墙内容缺失
- **z>6**: 太靠近南墙，可能导致北墙内容缺失
