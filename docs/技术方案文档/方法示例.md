动态创建Viewport纹理后，贴图只有一小部分显示在骰子面上，而静态贴图正常，这说明问题不在于模型的UV映射，而是出在动态生成的纹理或材质设置上。以下是可能的原因和解决方案。

### 1. 材质纹理重复模式设置不当
**现象**：如果材质的纹理重复模式为 `Repeat` 且UV范围被放大，会导致只显示纹理的一小部分。
**解决**：在材质中，将纹理的 `flags repeat` 设置为 `Disabled`（或 `Clamp to edge`），确保纹理不重复。
```gdscript
material.texture_filter = BaseMaterial3D.TEXTURE_FILTER_LINEAR  # 根据需要设置
# 在 StandardMaterial3D 中，通过下面方式禁用重复
material.albedo_texture.set_flags(0)  # 清除所有标志，包括重复
# 或者使用 set_flag 方法
material.albedo_texture.set_flag(Texture.FLAG_REPEAT, false)
```

### 2. 材质的UV变换被意外修改
**现象**：材质的 `uv1_scale` 或 `uv1_offset` 可能不是默认值，导致UV缩放或偏移。
**解决**：显式设置材质的UV1变换为默认值。
```gdscript
material.uv1_scale = Vector3(1, 1, 1)
material.uv1_offset = Vector3(0, 0, 0)
```

### 3. Viewport 内容没有填满整个渲染区域
**现象**：如果 `Control` 节点没有覆盖整个 `SubViewport`，渲染出的纹理四周会有空白，而模型的UV可能只采样到中间区域，导致看起来只显示一部分。
**解决**：确保 `Control` 节点及其子节点正确填满整个Viewport。使用锚点预设 `PRESET_FULL_RECT`，并确保所有节点的大小都正确。
```gdscript
control.anchors_preset = Control.PRESET_FULL_RECT
texture_rect.anchors_preset = Control.PRESET_FULL_RECT
label.anchors_preset = Control.PRESET_FULL_RECT
```
此外，可以临时在 `Control` 下添加一个颜色鲜明的 `ColorRect` 并设为全屏，观察渲染出的纹理是否覆盖整个区域，以验证布局。

### 4. 获取纹理的时机问题
**现象**：如果在 `SubViewport` 完成首次渲染前就获取纹理并赋值，可能会导致纹理内容不完整或映射异常。
**解决**：使用 `await get_tree().process_frame` 等待一帧，确保Viewport已经渲染。
```gdscript
add_child(viewport)
await get_tree().process_frame  # 等待一帧，让Viewport完成渲染
var texture = viewport.get_texture()
material.albedo_texture = texture
```

### 5. Viewport 的透明背景与材质混合
**现象**：如果 `SubViewport` 启用了透明背景，且材质混合模式不匹配，可能会导致视觉异常，但通常不会导致只显示一小部分。
**解决**：可以尝试关闭透明背景，或者确保材质正确处理透明。
```gdscript
viewport.transparent_bg = false  # 先关闭透明测试
```

### 6. 材质未正确分配给对应的面
**现象**：如果分配材质时使用了错误的索引，可能导致纹理被应用到其他面，看起来只有一部分。
**解决**：确认 `face_index` 与面的对应关系。对于 `BoxMesh`，面的索引顺序通常是：0=前，1=后，2=左，3=右，4=上，5=下（具体取决于模型导出设置，但Godot内置 `BoxMesh` 的顺序是固定的：前、后、左、右、上、下）。确保你为每个面创建了独立的材质，并分配到了正确的槽位。
```gdscript
mesh.surface_set_material(face_index, material)
```

### 7. 纹理坐标可能被模型本身的材质设置覆盖
**现象**：如果 `MeshInstance3D` 使用了多个材质覆盖，可能某些面的材质被共享，导致纹理映射错误。
**解决**：确保每个面有独立的材质实例，不要共享同一个材质。

### 综合修正后的代码示例
以下代码整合了上述建议，并添加了调试步骤：

```gdscript
extends MeshInstance3D

var face_labels = {}

func create_face_texture(face_index: int, static_texture: Texture2D, dynamic_text: String) -> void:
    # 1. 创建 SubViewport
    var viewport = SubViewport.new()
    viewport.name = "DynamicFaceViewport_%d" % face_index
    viewport.size = Vector2i(256, 256)
    viewport.render_target_update_mode = SubViewport.UPDATE_ALWAYS
    viewport.transparent_bg = false  # 先关闭透明，避免干扰
    add_child(viewport)

    # 2. 构建UI树，确保填满
    var control = Control.new()
    control.anchors_preset = Control.PRESET_FULL_RECT
    viewport.add_child(control)

    var texture_rect = TextureRect.new()
    texture_rect.texture = static_texture
    texture_rect.stretch_mode = TextureRect.STRETCH_KEEP_ASPECT_COVERED
    texture_rect.anchors_preset = Control.PRESET_FULL_RECT
    control.add_child(texture_rect)

    var label = Label.new()
    label.text = dynamic_text
    label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
    label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
    label.add_theme_font_size_override("font_size", 48)
    label.add_theme_color_override("font_color", Color.BLACK)
    label.anchors_preset = Control.PRESET_FULL_RECT
    control.add_child(label)

    # 保存标签引用以便后续更新
    face_labels[face_index] = label

    # 3. 等待一帧确保Viewport渲染
    await get_tree().process_frame

    # 4. 创建材质并设置纹理
    var material = StandardMaterial3D.new()
    material.albedo_texture = viewport.get_texture()
    # 确保纹理不重复，UV不变换
    material.albedo_texture.set_flag(Texture.FLAG_REPEAT, false)
    material.uv1_scale = Vector3(1, 1, 1)
    material.uv1_offset = Vector3(0, 0, 0)
    # 可选：设置纹理过滤
    material.texture_filter = BaseMaterial3D.TEXTURE_FILTER_LINEAR

    # 5. 应用到指定面
    mesh.surface_set_material(face_index, material)

func _ready():
    # 假设你有6个面的静态贴图
    var dot_texture_1 = preload("res://assets/dice_face_1.png")
    create_face_texture(0, dot_texture_1, "好")
    # 为其他面重复...
```

### 调试建议
如果问题仍然存在，可以在 `SubViewport` 的UI中加入一个全屏的纯色矩形（例如红色 `ColorRect`），观察骰子表面是否显示为纯色。如果是纯色，说明纹理映射正确，问题出在纹理内容上（比如文字或图片没有填满）。如果纯色也只显示一小部分，则说明纹理映射本身有问题，需要进一步检查材质的UV设置。

此外，可以临时编写一个简单的 `ShaderMaterial` 来可视化UV坐标，确认模型表面的UV范围是否正常。

希望以上分析和修正能帮助你解决问题。动态创建Viewport纹理是完全可行的，只要注意这些细节。
