# 摄像机倾斜角度调整说明

## 调整目标

增强场景骰子的立体感，让摄像机有轻微倾斜，可以看到骰子的侧面，但保持俯视视角的清晰度。

## 调整方案

### 角度对比

| 配置 | 角度 | 效果 | 选择 |
|------|------|------|------|
| **完全俯视** | -90° | 看不到骰子侧面，完全平面 | ❌ 不选 |
| **轻微倾斜** | -80° | 可以看到骰子侧面，增强立体感 | ✅ **已选择** |
| **中度倾斜** | -70° | 立体感更强，但可能影响操作 | ⚠️ 备选 |
| **大角度倾斜** | -60° | 立体感很强，但操作不便 | ❌ 不选 |

### 最终配置

**标准配置（default）**:
```gdscript
camera_position = Vector3(0, 60, 0)
camera_fov = 15.0
camera_rotation = Vector3(-80 * PI/180, 0, 0)  # -80 度
```

**效果说明**:
- ✅ **可以看到骰子的顶面和少量侧面**
- ✅ **保持俯视视角的清晰度**
- ✅ **增强立体感和深度感**
- ✅ **不影响骰子操作和识别**

**用途**: 更高的视角，适合观察大场景
**说明**: 因为高度增加，倾斜角度相应减小，保持相似的视觉效果

### 3. low（低位视角）

```gdscript

```

**用途**: 更低的视角，适合观察细节
**说明**: 因为高度降低，倾斜角度相应增大，避免过度倾斜

### 4. wide（广角视角）

```gdscript

FOV: 25.0
旋转：-80°（保持标准倾斜）
```

**用途**: 更广的视野，适合展示
**说明**: 保持标准倾斜角度，只改变 FOV

## 技术实现

### 角度计算

```gdscript
# Godot 使用弧度制
-90° = -PI/2 弧度  # 完全俯视
-80° = -80 * PI/180 弧度  # 轻微倾斜
-75° = -75 * PI/180 弧度  # 倾斜更小
-85° = -85 * PI/180 弧度  # 倾斜更大

# 转换公式
弧度 = 角度 * PI / 180
```

### 代码实现

```gdscript
# camera_manager.gd

@export var camera_rotation: Vector3 = Vector3(-80 * PI/180, 0, 0)

func reset_to_default():
    camera_rotation = Vector3(-80 * PI/180, 0, 0)
```

## 调整原因

### 为什么要倾斜？

1. **增强立体感**
   - 完全俯视（-90°）看到的是平面
   - 轻微倾斜（-80°）可以看到侧面
   - 增强 3D 效果和深度感

2. **提升视觉体验**
   - 骰子看起来更真实
   - 场景更有层次感
   - 减少平面感

3. **保持游戏性**
   - 倾斜角度不大，不影响操作
   - 仍然保持俯视视角的优势
   - 容易识别骰面信息

### 为什么是 -80°？

**角度选择考虑**:
- **-90°**: 完全俯视，太平面 ❌
- **-80°**: 轻微倾斜，刚刚好 ✅
- **-70°**: 倾斜较大，可能影响操作 ⚠️
- **-60°**: 倾斜太大，不适合俯视游戏 ❌

**-80° 的优势**:
- ✅ 立体感明显
- ✅ 不影响操作
- ✅ 保持清晰度
- ✅ 视觉舒适

## 后续调整建议

### 如果觉得倾斜不够

可以调整为 -75° 或 -70°：

```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-75 * PI/180, 0, 0)  # -75°，倾斜更大
# 或
camera_rotation = Vector3(-70 * PI/180, 0, 0)  # -70°，倾斜更明显
```

### 如果觉得倾斜太多

可以调整为 -85° 或 -88°：

```gdscript
# 在 camera_manager.gd 中修改
camera_rotation = Vector3(-85 * PI/180, 0, 0)  # -85°，更接近俯视
# 或
camera_rotation = Vector3(-88 * PI/180, 0, 0)  # -88°，非常接近平面
```

### 快速测试不同角度

```gdscript
func _input(event):
    # 按 = 键增加倾斜
    if event.keycode == KEY_EQUAL:
        var current_angle = camera_rotation.x * 180 / PI
        current_angle += 1
        camera_rotation = Vector3(-current_angle * PI/180, 0, 0)
        print("当前角度：", current_angle, "°")
    
    # 按 - 键减少倾斜
    if event.keycode == KEY_MINUS:
        var current_angle = camera_rotation.x * 180 / PI
        current_angle -= 1
        camera_rotation = Vector3(-current_angle * PI/180, 0, 0)
        print("当前角度：", current_angle, "°")
```
