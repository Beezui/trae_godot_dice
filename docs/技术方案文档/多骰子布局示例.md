# 多骰子布局使用示例

## 概述
本文档展示如何使用 `DiceThrowController` 的多骰子自动布局功能。

## 新增功能

### 1. 自动计算位置
```gdscript
# 计算 5 个骰子的居中位置（间距 2.0）
var positions = DiceThrowController.calculate_dice_positions(5, 4.75, 2.0)
# 返回：[-4, -2, 0, 2, 4] 的 x 坐标
```

### 2. 直接应用布局
```gdscript
# 直接应用居中布局到骰子数组
var dice_array = [dice1, dice2, dice3, dice4, dice5]
DiceThrowController.apply_centered_layout(dice_array, 4.75, 2.0)
```

## 使用场景

### 场景 1：3 个属性骰子（标准布局）
```gdscript
extends Node3D

var power_dice, agility_dice, intelligence_dice

func _ready():
    # 创建骰子...
    
    # 使用自动布局（推荐）
    var attr_dices = [power_dice, agility_dice, intelligence_dice]
    DiceThrowController.apply_centered_layout(attr_dices, 4.75, 2.0)
    
    # 结果：
    # 力量骰子：(-2, 4, 4.75)
    # 敏捷骰子：(0, 4, 4.75)
    # 智力骰子：(2, 4, 4.75)
```

### 场景 2：10 个骰子（最大数量）
```gdscript
extends Node3D

var many_dices = []

func _ready():
    # 创建 10 个骰子...
    for i in range(10):
        var dice = create_dice()
        many_dices.append(dice)
    
    # 使用自动布局（间距 2.0）
    DiceThrowController.apply_centered_layout(many_dices, 4.75, 2.0)
    
    # 结果（x 坐标）：
    # [-9, -7, -5, -3, -1, 1, 3, 5, 7, 9]
    # 总宽度：18，不会超出沙盘（可用宽度 21）
```

### 场景 3：8 个骰子（自定义间距）
```gdscript
extends Node3D

var skill_dices = []

func _ready():
    # 创建 8 个技能骰子...
    for i in range(8):
        var dice = create_dice()
        skill_dices.append(dice)
    
    # 使用较大间距（2.5）
    DiceThrowController.apply_centered_layout(skill_dices, 4.75, 2.5)
    
    # 结果（x 坐标）：
    # [-8.75, -6.25, -3.75, -1.25, 1.25, 3.75, 6.25, 8.75]
    # 总宽度：17.5，安全
```

### 场景 4：超出边界自动调整
```gdscript
extends Node3D

var many_dices = []

func _ready():
    # 创建 10 个骰子，使用过大的间距
    for i in range(10):
        var dice = create_dice()
        many_dices.append(dice)
    
    # 尝试使用 3.0 的间距（会超出边界）
    DiceThrowController.apply_centered_layout(many_dices, 4.75, 3.0)
    
    # 系统会自动调整：
    # 可用宽度 = 24.0 - 2*1.5 = 21.0
    # 实际间距 = 21.0 / 9 ≈ 2.33
    # 输出：【布局调整】骰子数量过多，调整间距为：2.33
```

## 布局参数说明

### 默认参数
```gdscript
@export var default_start_position: Vector3 = Vector3(0, 4, 4.75)
@export var dice_spacing: float = 2.0
@export var max_dice_count: int = 10
@export var safe_margin: float = 1.5
```

### 参数含义
- `default_start_position`: 单个骰子的默认位置
- `dice_spacing`: 骰子之间的标准间距
- `max_dice_count`: 支持的最大骰子数量
- `safe_margin`: 沙盘边缘安全距离（避免骰子超出）

### 沙盘尺寸
- 总宽度：24.0
- 可用宽度：24.0 - 2×1.5 = 21.0
- x 范围：-12 到 12

## 布局计算原理

### 1. 计算总宽度
```gdscript
var total_width = (dice_count - 1) * spacing
```

### 2. 计算起始位置（居中）
```gdscript
var start_x = -total_width / 2.0
```

### 3. 检查边界
```gdscript
var sandbox_half_width = 12.0
var left_bound = start_x - safe_margin
var right_bound = start_x + total_width + safe_margin

if left_bound < -sandbox_half_width or right_bound > sandbox_half_width:
    # 超出边界，调整间距
    var available_width = sandbox_half_width * 2 - safe_margin * 2
    spacing = available_width / (dice_count - 1)
    start_x = -sandbox_half_width + safe_margin + spacing / 2.0
```

### 4. 生成位置
```gdscript
for i in range(dice_count):
    var x = start_x + i * spacing
    positions.append(Vector3(x, 4.0, base_z))
```

## 最佳实践

### ✅ 推荐做法
```gdscript
# 1. 使用自动布局（最简单）
var dices = get_all_dices()
DiceThrowController.apply_centered_layout(dices)

# 2. 自定义间距
DiceThrowController.apply_centered_layout(dices, 4.75, 1.5)

# 3. 手动计算位置（需要精确控制时）
var positions = DiceThrowController.calculate_dice_positions(5, 4.75, 2.0)
for i in range(dices.size()):
    dices[i].position = positions[i]
```

### ❌ 不推荐做法
```gdscript
# 1. 手动计算每个骰子位置（容易出错）
dice1.position = Vector3(-4, 4, 4.75)
dice2.position = Vector3(-2, 4, 4.75)
dice3.position = Vector3(0, 4, 4.75)
# ... 容易忘记调整

# 2. 使用固定间距不考虑边界
var spacing = 3.0
for i in range(10):
    dices[i].position = Vector3(-15 + i * spacing, 4, 4.75)
    # 会超出沙盘边界！
```

## 常见问题

### Q1: 最多支持多少个骰子？
**A**: 理论上支持任意数量，但推荐最多 10 个。超过 10 个时间距会过小，影响视觉效果。

### Q2: 间距最小是多少？
**A**: 没有硬性限制，但建议不小于 1.0，避免骰子重叠。

### Q3: 如何创建 2 排骰子？
**A**: 当前版本只支持单排布局。如需多排，需要手动计算或扩展 `calculate_dice_positions()` 方法。

### Q4: z 坐标必须是 4.75 吗？
**A**: 不是。可以传入任意 z 值，但 4.75 是标准投掷区域（靠近南墙但不超出）。

### Q5: y 坐标必须是 4 吗？
**A**: 当前实现固定为 4（悬浮高度）。如需调整，可以修改代码中的 `Vector3(x, 4.0, base_z)`。
