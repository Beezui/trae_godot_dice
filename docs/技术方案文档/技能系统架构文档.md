# 技能系统架构文档

## 概述

技能系统为游戏提供统一的技能管理、调用和执行机制。所有技能独立于场景运行，可在任意场景中通过技能 ID 调用。系统采用配置驱动设计，通过 CSV 配置文件即可设计新技能，无需修改代码。

## 核心设计原则

1. **技能独立性** - 技能代码不依赖任何特定场景
2. **参数化设计** - 所有需要的数据通过参数传递
3. **统一接口** - 通过 SkillManager 统一调用
4. **配置驱动** - 技能行为由 skill.json 配置决定
5. **可扩展性** - 支持通过 CSV 配置轻松添加新技能

## 配置系统

### CSV 配置格式

#### 表头结构

```csv
id，名称，描述，图标，p1, p2, p3, p4, p5, p6
```

| 列名 | 说明 | 示例 |
|------|------|------|
| id | 技能 ID（唯一标识） | 10001 |
| 名称 | 技能名称 | 火球术 |
| 描述 | 技能描述，使用 p1/p2 等占位符 | "造成 p1 点伤害" |
| 图标 | 技能图标标识 | 10001 |
| p1-p6 | 参数计算公式（最多 6 个） | str*2 |

#### 参数公式语法

支持以下属性变量：
- `str` - 力量（Strength）
- `agi` - 敏捷（Agility）
- `int` - 智力（Intelligence）

支持的运算符：
- `*` - 乘法
- `/` - 除法
- `+` - 加法
- `-` - 减法
- 小数 - 如 `1.5`、`0.5`

**公式示例**：
```csv
str*2           # 力量 × 2
agi*3 + int     # 敏捷 × 3 + 智力
int*1.5         # 智力 × 1.5
str*2 + agi     # 力量 × 2 + 敏捷
```

#### 完整 CSV 示例

```csv
id，名称，描述，图标，p1,p2,p3,p4,p5,p6
10001，火球术，"向最近目标发射一枚火球，造成 p1 点伤害，命中目标后爆炸，对范围内敌人造成 p2 点伤害",10001,str*2,agi*2,,,,
10002，闪电链，"对目标及周围敌人造成 p1 点伤害",10002,int*3,,,,,
10003，冰冻术，"冻结目标 p1 秒",10003,int*1,,,,,
10004，毒爆术，"造成 p1 点伤害，并在 p2 秒内每秒造成 p3 点伤害",10004,int*2,int*1,int*0.5,,,
```

## 核心代码实现

### 1. SkillManager (Autoload)

**路径**: `res://skills/skill_manager.gd`

**功能**:
- 统一管理所有技能
- 提供全局技能调用接口
- 管理技能冷却
- 自动注册技能

**核心代码**:
```gdscript
extends Node

var registered_skills: Dictionary = {}
var skill_cooldowns: Dictionary = {}
var skill_csv_reader: RefCounted

func _ready():
	skill_csv_reader = preload("res://scripts/skill_csv_reader.gd").new()
	_auto_register_skills()

func _auto_register_skills():
	var all_skills = skill_csv_reader.get_all_skills()
	
	for skill_id in all_skills.keys():
		var skill_config = all_skills[skill_id]
		var skill_instance = _create_skill_instance(skill_id)
		
		if skill_instance:
			skill_instance.init(skill_config)
			register_skill(skill_id, skill_instance)

func _create_skill_instance(skill_id: String) -> RefCounted:
	match skill_id:
		"10001":
			return preload("res://skills/fireball_skill.gd").new()
		"10002":
			return preload("res://skills/blizzard_skill.gd").new()
		_:
			return null

func register_skill(skill_id: String, skill_instance: RefCounted) -> void:
	if skill_instance:
		registered_skills[skill_id] = skill_instance

func use_skill(skill_id: String, caster: Node = null, targets: Array = [], params: Dictionary = {}) -> bool:
	if not registered_skills.has(skill_id):
		push_error("Skill not found: " + skill_id)
		return false
	
	if not can_use_skill(skill_id):
		return false
	
	var skill = registered_skills[skill_id]
	
	skill.execute(caster, targets, params)
	
	_set_cooldown(skill_id)
	
	return true

func can_use_skill(skill_id: String) -> bool:
	var cooldown = skill_cooldowns.get(skill_id, 0)
	return cooldown <= 0

func _set_cooldown(skill_id: String) -> void:
	skill_cooldowns[skill_id] = 1.0

func get_skill(skill_id: String) -> Dictionary:
	return skill_csv_reader.get_skill(skill_id)

func _process(delta: float) -> void:
	for skill_id in skill_cooldowns.keys():
		skill_cooldowns[skill_id] = max(0, skill_cooldowns[skill_id] - delta)

func clear_cooldowns() -> void:
	skill_cooldowns.clear()

func get_all_skill_ids() -> Array:
	return registered_skills.keys()

func get_skill_count() -> int:
	return registered_skills.size()
```

### 2. 具体技能实现

#### FireballSkill (火球术)

**路径**: `res://skills/fireball_skill.gd`

**技能 ID**: 10001

**效果**: 向目标发射火球，造成范围伤害

**核心代码**:
```gdscript
extends RefCounted

var fireball_speed: float = 25.0
var explosion_radius: float = 2.0
var current_fireball: Node3D = null
var skill_config: Dictionary = {}
var is_executing: bool = false

func init(config: Dictionary) -> void:
	skill_config = config

func cleanup() -> void:
	is_executing = false
	if current_fireball:
		current_fireball.queue_free()
		current_fireball = null

func get_config() -> Dictionary:
	return skill_config

func get_skill_id() -> String:
	return skill_config.get("id", "")

func get_skill_name() -> String:
	return skill_config.get("name", "Unknown")

func execute(caster: Node = null, targets: Array = [], params: Dictionary = {}) -> void:
	var dice_results = params.get("dice_results", {})
	
	var scene_node: Node = params.get("scene", null)
	if not scene_node and caster:
		scene_node = caster.get_tree().current_scene
	
	var caster_position: Vector3 = params.get("caster_position", Vector3(-6, 0.5, 0))
	if caster and caster.has_method("get_global_position"):
		caster_position = caster.global_position
	
	var p1 = calculate_damage("str*2 + agi*2", dice_results)
	
	if targets.is_empty():
		cleanup()
		return

	var target = targets[randi() % targets.size()]
	var target_pos = target.global_position if target else Vector3(6, 0.5, 0)
	
	_launch_fireball(caster_position, target_pos, p1, scene_node)

func _launch_fireball(start_pos: Vector3, target_pos: Vector3, damage: int, scene_node: Node = null) -> void:
	var fireball_mesh = SphereMesh.new()
	fireball_mesh.radius = 0.3
	fireball_mesh.height = 0.6
	
	var fireball_material = StandardMaterial3D.new()
	fireball_material.albedo_color = Color(1, 0.8, 0, 1)
	fireball_material.emission_enabled = true
	fireball_material.emission = Color(1, 0.6, 0, 1)
	fireball_material.emission_energy_multiplier = 3.0
	
	var fireball_mesh_instance = MeshInstance3D.new()
	fireball_mesh_instance.mesh = fireball_mesh
	fireball_mesh_instance.material_override = fireball_material
	fireball_mesh_instance.position = start_pos
	fireball_mesh_instance.name = "Fireball"
	
	if scene_node:
		scene_node.add_child(fireball_mesh_instance)
	
	current_fireball = fireball_mesh_instance
	
	var distance = start_pos.distance_to(target_pos)
	var travel_time = distance / fireball_speed
	
	var tween = fireball_mesh_instance.create_tween()
	tween.tween_property(fireball_mesh_instance, "position", target_pos, travel_time)
	tween.tween_callback(_on_fireball_hit.bind(target_pos, damage, scene_node))

func _on_fireball_hit(hit_position: Vector3, damage: int, scene_node: Node = null) -> void:
	_trigger_explosion(hit_position, scene_node)
	
	if current_fireball:
		current_fireball.queue_free()
		current_fireball = null
	
	cleanup()

func _trigger_explosion(hit_position: Vector3, scene_node: Node = null) -> void:
	var explosion_particles = CPUParticles3D.new()
	explosion_particles.name = "FireballExplosion"
	explosion_particles.position = hit_position
	explosion_particles.amount = 400
	explosion_particles.lifetime = 1.3
	explosion_particles.explosiveness = 1.0
	explosion_particles.emission_shape = CPUParticles3D.EMISSION_SHAPE_SPHERE
	explosion_particles.emission_sphere_radius = explosion_radius
	explosion_particles.gravity = Vector3(0, 0, 0)
	explosion_particles.initial_velocity_min = 4.0
	explosion_particles.initial_velocity_max = 4.0
	
	var material = StandardMaterial3D.new()
	material.albedo_color = Color(1, 0.6, 0, 1)
	material.emission_enabled = true
	material.emission = Color(1, 0.4, 0, 1)
	material.emission_energy_multiplier = 2.0
	material.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
	explosion_particles.material_override = material
	
	if scene_node:
		scene_node.add_child(explosion_particles)
	
	explosion_particles.emitting = true
	
	var timer = Timer.new()
	timer.wait_time = 2.0
	timer.one_shot = true
	timer.timeout.connect(func():
		if is_instance_valid(explosion_particles):
			explosion_particles.queue_free()
		if is_instance_valid(timer):
			timer.queue_free()
	)
	
	if scene_node:
		scene_node.add_child(timer)
	
	timer.start()

func calculate_damage(formula: String, dice_results: Dictionary) -> int:
	var evaluated_formula = formula
	
	if dice_results.has("str"):
		evaluated_formula = evaluated_formula.replace("str", str(dice_results["str"]))
	if dice_results.has("agi"):
		evaluated_formula = evaluated_formula.replace("agi", str(dice_results["agi"]))
	if dice_results.has("int"):
		evaluated_formula = evaluated_formula.replace("int", str(dice_results["int"]))
	
	return _evaluate_expression(evaluated_formula)

func _evaluate_expression(expr: String) -> int:
	var tokens = expr.replace(" ", "").split("+")
	var total = 0.0
	
	for token in tokens:
		if "-" in token and token != tokens[0]:
			var parts = token.split("-")
			if parts.size() == 2:
				total += _evaluate_multiplication(parts[0])
				total -= _evaluate_multiplication(parts[1])
			else:
				total += _evaluate_multiplication(token)
		else:
			total += _evaluate_multiplication(token)
	
	return int(total)

func _evaluate_multiplication(expr: String) -> float:
	var tokens = expr.split("*")
	var result = 1.0
	
	for token in tokens:
		if "/" in token:
			var div_parts = token.split("/")
			if div_parts.size() == 2:
				result *= float(div_parts[0]) / float(div_parts[1])
			else:
				result *= float(token)
		else:
			result *= float(token)
	
	return result
```

### 3. 配置读取器

**路径**: `res://scripts/skill_csv_reader.gd`

**核心代码**:
```gdscript
extends RefCounted

var skills = {}

func _init():
	load_skills()

func load_skills():
	var file = FileAccess.open("res://table/skill.json", FileAccess.READ)
	if not file:
		push_error("Cannot open skill.json")
		return
	
	var json_text = file.get_as_text()
	file.close()
	
	var json = JSON.new()
	var parse_result = json.parse(json_text)
	
	if parse_result != OK:
		push_error("Error parsing skill.json: " + json.get_error_message())
		return
	
	var data = json.get_data()
	
	if not data is Dictionary or not data.has("skills"):
		push_error("skill.json missing 'skills' array")
		return
	
	var skills_array = data["skills"]
	for skill_data in skills_array:
		if skill_data is Dictionary and skill_data.has("id"):
			var skill_id = str(skill_data["id"])
			skills[skill_id] = skill_data

func get_skill(skill_id: String) -> Dictionary:
	return skills.get(skill_id, {})

func get_all_skills() -> Dictionary:
	return skills

func get_skill_count() -> int:
	return skills.size()
```

## 技术难点与解决方案

### 1. 场景节点传递

**问题**: 技能需要在不同场景中运行，但无法硬编码场景节点。

**解决方案**:
- 通过 `params` 参数传递场景节点
- 提供 fallback 机制：从 `caster.get_tree().current_scene` 获取
- 确保技能效果能在任何场景中正常显示

### 2. 资源管理

**问题**: 技能创建的临时对象（粒子效果、计时器等）需要正确清理。

**解决方案**:
- 实现 `cleanup()` 方法统一清理资源
- 使用 `is_instance_valid()` 检查对象有效性
- 确保所有临时对象在技能结束时被正确释放

### 3. 计时器使用规范

**问题**: Timer 必须在添加到场景树后才能启动。

**解决方案**:
- 严格遵循先 `add_child()` 再 `start()` 的顺序
- 在技能效果中正确管理计时器生命周期

### 4. 伤害计算系统

**问题**: 需要支持复杂的伤害计算公式。

**解决方案**:
- 实现表达式解析器，支持 +、-、*、/ 运算符
- 支持属性变量替换（str、agi、int）
- 处理嵌套表达式和优先级

### 5. 技能独立性

**问题**: 技能代码不能依赖特定场景结构。

**解决方案**:
- 所有数据通过参数传递
- 避免使用 `get_node()` 硬编码节点路径
- 使用配置驱动的设计模式

### 6. 配置系统

**问题**: 需要一个灵活的技能配置系统。

**解决方案**:
- 使用 CSV 作为配置源文件，易于编辑
- 开发转换工具生成结构化 JSON
- 支持最多 6 个参数和复杂公式

### 7. 技能冷却管理

**问题**: 需要统一管理技能冷却。

**解决方案**:
- SkillManager 负责冷却时间管理
- 在 `_process()` 中更新冷却时间
- 提供 `can_use_skill()` 检查方法

## 重要注意事项

### 1. 场景节点传递
**必须**在 params 中传递场景节点，否则技能效果无法添加到场景：
```gdscript
var params = {
    "dice_results": {...},
    "scene": self  # 必需
}
```

### 2. 技能独立性
技能代码不能硬编码引用任何场景节点，所有需要的数据必须通过参数传递：
- ❌ `var target = get_node("Target")` 
- ✅ `var target = targets[0]`

### 3. 资源管理
技能创建的临时对象必须正确清理：
```gdscript
func cleanup() -> void:
    is_executing = false
    if current_effect:
        current_effect.queue_free()
        current_effect = null
```

### 4. 错误处理
处理目标不存在、配置缺失等异常情况：
```gdscript
if targets.is_empty():
    print("错误：没有目标")
    cleanup()
    return

if not scene_node:
    print("警告：无法获取场景节点")
```

### 5. Timer 使用规范
Timer 必须在添加到场景树后才能调用 start()：
```gdscript
var timer = Timer.new()
scene_node.add_child(timer)  # 先添加到场景
timer.start()  # 再启动
```

### 6. 对象有效性检查
在 queue_free() 前检查对象是否有效：
```gdscript
if is_instance_valid(obj):
    obj.queue_free()
```
