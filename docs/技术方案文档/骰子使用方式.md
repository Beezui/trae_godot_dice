## 概述

本骰子系统采用**统一化 + 模块化 + 配置驱动**的设计理念，提供:

- ✅ **统一的投掷逻辑** - 所有场景使用相同的投掷控制器，保证手感一致
- ✅ **统一的结果检测** - 所有骰子使用相同的检测算法 (向量点积法)
- ✅ **策略模式贴图映射** - 通过骰子类型选择不同的贴图策略
- ✅ **配置驱动** - 通过配置文件管理骰子属性

### 核心优势

1. **代码复用** - 减少重复代码，提高可维护性
2. **易于扩展** - 新增骰子类型只需添加新策略
3. **类型安全** - 通过枚举确保正确性
4. **保留特色** - 属性骰子的 SubViewport 动态纹理完全保留

### 0.5. 属性骰子贴图映射难点及解决方案 ⭐

#### 难点 1: SubViewport 必须添加到场景树才能渲染

**问题描述**:
```gdscript
# ❌ 错误示例：Viewport 未添加到场景树
func create_attr_face_texture():
    var viewport = SubViewport.new()
    var control = Control.new()
    viewport.add_child(control)
    return viewport.get_texture()  # 贴图不会渲染，是黑色的
```

**解决方案**:
```gdscript
# ✅ 正确示例：必须将 Viewport 添加到场景树
func create_attr_face_texture(mesh_instance: MeshInstance3D):
    var viewport = SubViewport.new()
    var control = Control.new()
    viewport.add_child(control)
    
    # 关键：将 Viewport 添加到场景树
    if mesh_instance and mesh_instance.get_parent():
        mesh_instance.get_parent().add_child(viewport)
    
    return viewport.get_texture()  # 贴图正常渲染
```

**原理**:
- SubViewport 是渲染目标，必须添加到场景树中才能被渲染引擎处理
- 未添加到场景树的 Viewport 不会渲染，返回的贴图是黑色的

#### 难点 2: 动态贴图需要包含静态贴图和动态文字

**问题描述**:
- 属性骰子需要在英雄贴图基础上叠加属性数值文字
- 需要保证文字清晰、位置居中、颜色可配置

**解决方案**:
```gdscript
func create_attr_face_texture():
    # 1. 创建 SubViewport（渲染目标）
    var viewport = SubViewport.new()
    viewport.size = Vector2i(512, 512)  # 最小 512x512 保证清晰度
    viewport.render_target_update_mode = SubViewport.UPDATE_ONCE
    viewport.transparent_bg = true
    
    # 2. 创建根 Control 节点（必须充满 Viewport）
    var control = Control.new()
    control.anchors_preset = Control.PRESET_FULL_RECT
    control.size = viewport.size
    viewport.add_child(control)
    
    # 3. 添加静态贴图（英雄贴图）
    if static_texture:
        var texture_rect = TextureRect.new()
        texture_rect.texture = static_texture
        texture_rect.stretch_mode = TextureRect.STRETCH_SCALE  # 完全覆盖
        texture_rect.anchors_preset = Control.PRESET_FULL_RECT
        texture_rect.size = viewport.size
        control.add_child(texture_rect)
    
    # 4. 添加动态文本标签
    var label = Label.new()
    label.text = "10"  # 属性值
    label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
    label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
    label.add_theme_font_size_override("font_size", 96)
    label.add_theme_color_override("font_color", Color.BLACK)
    label.anchors_preset = Control.PRESET_FULL_RECT
    label.size = viewport.size
    control.add_child(label)
    
    # 5. 返回动态生成的贴图
    return viewport.get_texture()
```

**关键点**:
- 使用 `PRESets_FULL_RECT` 确保所有节点充满 Viewport
- 使用 `STRETCH_SCALE` 确保英雄贴图完全覆盖
- 字体大小设置为 96 保证清晰度
- 文字颜色可配置（从配置文件读取）

#### 难点 3: 配置格式不统一（数组 vs 字典）

**问题描述**:
- JSON 配置文件使用数组格式：`"values": [10, 20, 30, 40, 50, 60]`
- 代码需要字典格式：`"values": {0: 10, 1: 20, ...}`

**解决方案**:
```gdscript
# 在 DiceTextureManager 中自动转换
func _apply_attr_dice_textures(config: Dictionary):
    var values_array = config.get("values", [])
    
    # 自动将数组转换为字典
    var values = {}
    for i in range(values_array.size()):
        values[i] = values_array[i]
    
    # 现在可以使用字典格式访问
    for i in range(6):
        var attr_value = values.get(i, 0)
```

**优势**:
- 配置文件使用人类可读的数组格式
- 代码自动转换，开发者无需关心
- 向后兼容旧的字典格式配置

#### 难点 4: 文字颜色配置的理解误区

**问题描述**:
- ❌ 错误理解：`points_color` 是骰子底色
- ✅ 正确理解：`points_color` 是**属性数值文字的颜色**

**配置示例**:
```json
{
    "attr_name": "str",
    "points_color": "#C00000",  // 文字颜色（红色）
    "values": [5, 11, 17, 23, 29, 35]
}
```

**正确用法**:
```gdscript
# 文字颜色从配置读取
var points_color = Color(config.get("points_color", "#000000"))

# 创建动态贴图时使用文字颜色
var label = Label.new()
label.add_theme_color_override("font_color", points_color)

# 骰子底色根据属性类型自动设置
var attr_color = _get_attr_color(attr_type)  # 力量=红色，敏捷=绿色，智力=蓝色
```

#### 难点 5: 统一管理 vs 独立功能的平衡

**问题描述**:
- 需要统一管理所有骰子贴图
- 但属性骰子有特殊的 SubViewport 动态纹理需求
- 如何既统一管理又保留特殊性？

**解决方案**:
```gdscript
# 在 attr_dice.gd 中
func apply_dice_textures(mesh_instance):
    # 构建配置字典
    var config = {
        "hero_id": hero_id,
        "attr_type": attr_type,
        "values": attr_values,
        "textures": attr_textures
    }
    
    # 调用 DiceTextureManager 统一管理
    if DiceTextureManager.get_instance():
        DiceTextureManager.get_instance().apply_textures_to_dice(self, config)
    else:
        # 备用方案：使用本地方法
        _apply_dice_textures_local(mesh_instance)
```

**优势**:
- ✅ 统一管理：所有骰子都通过 `DiceTextureManager`
- ✅ 保留特色：属性骰子的 SubViewport 功能完全保留
- ✅ 向后兼容：`DiceTextureManager` 不可用时使用本地方法
- ✅ 易于扩展：新增骰子类型只需添加新策略

#### 难点 6: 属性骰子文字颜色配置 ⭐

**问题描述**:
- 属性骰子的数值文字颜色需要根据属性类型区分（力量=红色，敏捷=绿色，智力=蓝色）
- 颜色配置存储在 `attr_dices.json` 中，而不是硬编码
- 需要在 `update_attributes()` 时动态读取并应用颜色配置

**配置示例** (`attr_dices.json`):
```json
{
  "attr_dices": {
    "1": {
      "hero_id": "1",
      "hero_name": "测试角色",
      "power": {
        "attr_name": "str",
        "points_color": "#C00000",  // 力量属性文字颜色（红色）
        "values": [5, 11, 17, 23, 29, 35]
      },
      "agility": {
        "attr_name": "agi",
        "points_color": "#A9D08E",  // 敏捷属性文字颜色（绿色）
        "values": [4, 10, 16, 22, 30, 32]
      },
      "intelligence": {
        "attr_name": "int",
        "points_color": "#8EA9DB",  // 智力属性文字颜色（蓝色）
        "values": [1, 2, 3, 4, 5, 10]
      }
    }
  }
}
```

**解决方案**:

**步骤 1**: 在 `attr_dice.gd` 中添加 `points_color` 属性
```gdscript
extends RigidBody3D

@export var attr_type: String = "str"
@export var hero_id: int = 1
@export var attr_values: Array = []
@export var attr_textures: Array = []
@export var attr_color: Color = Color(1, 1, 1, 1)
@export var points_color: Color = Color.BLACK  # 属性数值文字颜色
```

**步骤 2**: 在 `update_attributes()` 中读取颜色配置
```gdscript
func update_attributes(hero_attributes: Dictionary, hero_textures: Array):
    # 更新属性值
    match attr_type:
        "str":
            attr_values = _convert_to_int_array(hero_attributes.get("attr_str", []))
        "agi":
            attr_values = _convert_to_int_array(hero_attributes.get("attr_agi", []))
        "int":
            attr_values = _convert_to_int_array(hero_attributes.get("attr_int", []))
    
    # 更新贴图
    attr_textures = hero_textures
    
    # 从 attr_dices.json 读取文字颜色配置
    _update_points_color_from_config()
    
    # 更新骰子贴图
    update_dice_textures()
```

**步骤 3**: 实现 `_update_points_color_from_config()` 方法
```gdscript
func _update_points_color_from_config():
    # 从 attr_dices.json 读取文字颜色配置
    var DiceCSVReaderClass = load("res://scripts/dice_csv_reader.gd")
    var dice_csv_reader = DiceCSVReaderClass.new()
    var attr_dices_config = dice_csv_reader.load_attr_dices()
    
    # 检查配置是否有效
    if attr_dices_config.size() > 0:
        var hero_key = str(hero_id)
        if attr_dices_config.has(hero_key):
            var hero_config = attr_dices_config[hero_key]
            
            # 根据 attr_type 获取对应的配置
            var attr_config = null
            match attr_type:
                "str":
                    attr_config = hero_config.get("power", null)
                "agi":
                    attr_config = hero_config.get("agility", null)
                "int":
                    attr_config = hero_config.get("intelligence", null)
            
            if attr_config and attr_config.has("points_color"):
                var color_str = attr_config["points_color"]
                if color_str is String:
                    points_color = Color(color_str)
                else:
                    points_color = color_str
                print("【文字颜色】从配置读取：", attr_type, " = ", points_color)
            else:
                # 默认颜色
                points_color = Color.BLACK
                print("【文字颜色】配置中未找到 points_color，使用默认黑色")
        else:
            # 默认颜色
            points_color = Color.BLACK
            print("【文字颜色】未找到英雄 ", hero_id, " 的配置，使用默认黑色")
    else:
        # 默认颜色
        points_color = Color.BLACK
        print("【文字颜色】未找到 attr_dices.json 配置，使用默认黑色")
```

**步骤 4**: 在 `apply_dice_textures()` 中传递颜色配置
```gdscript
func apply_dice_textures(mesh_instance):
    # 构建配置字典（包含 points_color）
    var config = {
        "hero_id": hero_id,
        "attr_type": attr_type,
        "values": attr_values,
        "textures": attr_textures,
        "points_color": points_color  # 传递文字颜色配置
    }
    
    # 调用 DiceTextureManager 应用贴图
    if DiceTextureManager.get_instance():
        DiceTextureManager.get_instance().apply_textures_to_dice(self, config)
        print("【属性骰子】使用 DiceTextureManager 统一管理贴图，文字颜色：", points_color)
    else:
        # 备用方案
        _apply_dice_textures_local(mesh_instance)
```

**步骤 5**: `DiceTextureManager` 读取并使用颜色配置
```gdscript
func _apply_attr_dice_textures(mesh_instance: MeshInstance3D, config: Dictionary):
    var points_color = Color.BLACK  # 默认文字颜色
    
    # 读取配置中的 points_color
    if config.has("points_color"):
        var color_str = config.get("points_color", "#000000")
        if color_str is String:
            points_color = Color(color_str)
        else:
            points_color = color_str
    
    # 为每个面创建动态纹理（使用配置的文字颜色）
    for i in range(6):
        var attr_value = str(values.get(i, 0))
        
        # 创建包含属性文字的动态纹理
        var dynamic_texture = create_attr_face_texture(
            i, attr_type, attr_value, 
            points_color,  # 使用配置的文字颜色
            static_texture, face_size, mesh_instance
        )
```

**关键点**:
- ✅ 使用 `load()` 而不是 `preload()` 加载 `DiceCSVReader`（避免解析错误）
- ✅ `load_attr_dices()` 方法必须声明返回类型 `-> Dictionary`
- ✅ 检查配置有效性使用 `size() > 0` 而不是 `!is_empty()`（空字典也是有效的）
- ✅ 颜色值可能是字符串（`"#C00000"`）或 `Color` 类型，需要兼容处理
- ✅ 默认颜色为黑色，配置不存在时使用默认值

#### 难点 7: 属性骰子字体大小与视觉效果优化 ⭐

**问题描述**:
- 属性数值文字需要足够大且清晰
- 需要在不同背景颜色上都能清楚显示
- 需要根据文字长度自适应调整大小，避免超出骰面

**解决方案**:

**步骤 1**: 基础字体设置
```gdscript
# 在 create_attr_face_texture() 中
var label = Label.new()
label.name = "TextLabel"
label.text = value_text
label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER

# 基础字号：288（原始 96 的 300%）
label.add_theme_font_size_override("font_size", 288)

# 设置文字颜色（从配置读取）
label.add_theme_color_override("font_color", font_color)
```

**步骤 2**: 添加描边效果（双层渲染）
```gdscript
# 创建主标签（文字层）
var label = Label.new()
label.add_theme_font_size_override("font_size", 288)
label.add_theme_color_override("font_color", font_color)

# 创建描边标签（描边层）
var outline_label = Label.new()
outline_label.name = "TextOutline"
outline_label.text = value_text
outline_label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
outline_label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER

# 描边字号：比主文字大 15%
outline_label.add_theme_font_size_override("font_size", 331)  # 288 * 1.15 ≈ 331

# 描边颜色：使用更深的颜色（darkened(0.8)）
var outline_color = font_color.darkened(0.8)
outline_label.add_theme_color_override("font_color", outline_color)

# 先添加描边层（在底层），再添加主文字层
control.add_child(outline_label)
control.add_child(label)
```

**步骤 3**: 自适应缩小策略
```gdscript
func _adapt_label_font_size(label: Label, text: String, _viewport_size: Vector2i):
    var text_length = text.length()
    var base_font_size = 288  # 基础字号
    var final_font_size = base_font_size
    
    # 根据字符长度调整字号
    if text_length <= 3:
        final_font_size = 288  # 短文本，保持最大
    elif text_length <= 5:
        final_font_size = 240  # 中等长度
    elif text_length <= 7:
        final_font_size = 192  # 较长文本
    elif text_length <= 10:
        final_font_size = 144  # 长文本
    else:
        final_font_size = 96   # 超长文本
    
    # 如果包含 "k" 后缀（如 "1.5k"），额外缩小 10%
    if "k" in text or "K" in text:
        final_font_size = int(final_font_size * 0.9)
    
    # 应用最终字号
    label.add_theme_font_size_override("font_size", final_font_size)
```

**字体大小配置表**:

| 参数 | 值 | 说明 |
|------|-----|------|
| **基础字号** | 288 | 原始 96 的 300% |
| **描边字号** | 331 | 比主文字大 15% |
| **描边颜色** | darkened(0.8) | 文字颜色的暗色版本 |
| **短文本** | 288 | 1-3 个字符 |
| **中等文本** | 240 | 4-5 个字符 |
| **较长文本** | 192 | 6-7 个字符 |
| **长文本** | 144 | 8-10 个字符 |
| **超长文本** | 96 | 11+ 个字符 |
| **带 "k" 后缀** | -10% | 额外缩小 |

**自适应示例**:

```
文字："5"       → 288 号（最大）
文字："100"     → 288 号（最大）
文字："1000"    → 240 号（中等）
文字："10000"   → 240 号（中等）
文字："100000"  → 192 号（较长）
文字："1000000" → 192 号（较长）
文字："10000000"→ 144 号（长文本）
文字："1.5k"    → 259 号（288 * 0.9，带 k 后缀）
文字："100k"    → 216 号（240 * 0.9，带 k 后缀）
```

**渲染层级**:

```

│  [SubViewport - 512x512]            │

│   │  [Control - 根节点]            │ │

│   └───────────────────────────────┘ │
└─────────────────────────────────────┘
```

**关键点**:
- ✅ 基础字号 288（原始 96 的 300%），保证清晰度
- ✅ 双层渲染：描边层（331 号）+ 主文字层（288 号）
- ✅ 描边颜色使用 `darkened(0.8)`，比文字颜色深 80%
- ✅ 先添加描边层，再添加主文字层（描边在底层）
- ✅ 根据文字长度自动调整字号，避免超出骰面
- ✅ 带 "k" 后缀的数值额外缩小 10%
- ✅ 主文字和描边层都应用自适应缩小

### 方法 1: 单个骰子检测


### 方法 2: 批量检测

```gdscript
func check_all_results():
    var dices = get_all_dices()
    var results = DiceResultDetector.check_all_dice(dices)
    
    for dice_index in results:
        var result = results[dice_index]
        print("骰子 %d: 值=%d, 面索引=%d" % [dice_index, result.value, result.face_index])
    
    return results
```

### 方法 3: 等待稳定后检测

```gdscript
func wait_and_check():
    var dices = get_all_dices()
    
    # 等待所有骰子稳定
    var is_stable = await DiceResultDetector.wait_for_dice_stable(dices, 5.0)
    
    if is_stable:
        print("所有骰子已稳定")
        var results = DiceResultDetector.check_all_dice(dices)
        return results
    else:
        print("等待超时")
        return null
```

### 检测结果判定

- **向量点积法**: 检测最接近向上的面
- **稳定判定**: 线速度 < 0.1 且角速度 < 0.1
- **稳定持续时间**: 0.8 秒 (8 次检查 × 0.1 秒)
- **最大等待时间**: 5.0 秒

## 常见问题

### Q1: 骰子不滚动怎么办？

**A**: 检查以下几点:
1. 确保 `gravity_scale = 1.0`
2. 确保调用了 `roll()` 方法
3. 检查物理材质设置
4. 确保骰子不在其他物体内部

### Q2: 结果检测不准确？

**A**: 使用向量点积法确保准确性:
```gdscript
var value = DiceResultDetector.check_dice_value(dice)
```

### Q3: 贴图不显示？

**A**: 检查:
1. 贴图路径是否正确
2. 网格是否有 6 个独立表面
3. 是否正确调用 `DiceTextureManager.apply_textures()`
4. 材质是否正确应用到表面

### Q4: 属性骰子动态纹理不更新？

**A**: 确保:
1. SubViewport 正确创建
2. Control 节点使用 PRESET_FULL_RECT
3. TextureRect 使用 STRETCH_SCALE
4. Label 明确设置尺寸

### Q5: 投掷力度不一致？

**A**: 使用统一的投掷控制器:
```gdscript
DiceThrowController.throw_with_charge(dices, charge_ratio)
```

### Q6: 如何添加新的骰子类型？

**A**: 
1. 在 `BaseDice.DiceType` 枚举中添加新类型
2. 创建新的贴图策略类
3. 在 DiceSystemInitializer 中注册策略

```gdscript
# 1. 添加枚举
enum DiceType { NUM, ATTR, SKILL, ELEMENT }

# 2. 创建策略
class_name ElementDiceStrategy
```
