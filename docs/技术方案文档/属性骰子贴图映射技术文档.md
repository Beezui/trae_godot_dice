# 属性骰子贴图映射技术文档

## 📋 概述

本文档详细记录了 Godot 4.6.1 中属性骰子动态贴图映射的完整实现方案，包括核心代码、遇到的问题及解决方案。该方案实现了在骰子六个面上分别显示不同的静态贴图和动态属性数值。

**完成日期**：2026-03-17  
**Godot 版本**：4.6.1  
**核心文件**：`scenes/attr_dice.gd`

## 🎯 功能需求

1. **六面独立贴图**：每个骰子面显示不同的英雄属性贴图
2. **动态数值显示**：在贴图上叠加显示对应的属性数值
3. **完整覆盖**：贴图必须完全覆盖骰子面，无黑边或留白
4. **实时投掷检测**：投掷后正确检测朝上的面并显示对应属性值

### 1. 主函数流程

```gdscript
# 文件：scenes/attr_dice.gd

# 初始化流程
func _ready():
    init_dice_model()  # 初始化骰子模型

func init_dice_model():
    var mesh_instance = $MeshInstance3D
    if mesh_instance and mesh_instance.mesh:

    else:

func update_attributes(hero_attributes: Dictionary, hero_textures: Array):
    # 更新属性值和贴图
    attr_values = _convert_to_int_array(hero_attributes.get("attr_str", []))
    attr_textures = hero_textures
    update_dice_textures()  # 动态更新贴图
```

### 2. 贴图应用函数（核心）

```gdscript
func apply_dice_textures(mesh_instance):
    # 1. 加载静态贴图
    var static_texture = load("res://textures/hero/hero_" + attr_textures[0] + ".png")
    
    # 2. 获取骰面尺寸（从网格 AABB）
    var face_size = Vector2i(512, 512)
    if mesh_instance and mesh_instance.mesh:
        var aabb = mesh_instance.mesh.get_aabb()
        face_size = Vector2i(int(aabb.size.x), int(aabb.size.y))
    
    # 3. 为每个面创建独立材质
    var materials = []
    for i in range(6):
        var attr_value = format_attribute_value(attr_values[i] if i < attr_values.size() else 0)
        var dynamic_texture = create_face_texture(i, static_texture, attr_value, face_size)
        
        var material = StandardMaterial3D.new()
        material.roughness = 0.8
        material.metallic = 0.0
        material.albedo_texture = dynamic_texture
        material.uv1_scale = Vector3(1, 1, 1)  # 关键：设置 UV 为默认值
        material.uv1_offset = Vector3(0, 0, 0)
        materials.append(material)
    
    # 4. 应用材质到网格的每个表面
    var surface_count = mesh_instance.mesh.get_surface_count()
    for i in range(min(6, surface_count, materials.size())):
        mesh_instance.mesh.surface_set_material(i, materials[i])
```

### 3. 动态纹理创建（核心技术）

```gdscript
func create_face_texture(face_index: int, static_texture: Texture2D, 
                         dynamic_text: String, face_size: Vector2i) -> Texture2D:
    # 1. 创建 SubViewport（渲染目标）
    var viewport = SubViewport.new()
    viewport.name = "DynamicFaceViewport_%d" % face_index
    viewport.size = Vector2i(max(face_size.x, 512), max(face_size.y, 512))
    viewport.render_target_update_mode = SubViewport.UPDATE_ONCE
    viewport.transparent_bg = true
    
    # 2. 创建根 Control 节点（必须充满 Viewport）
    var control = Control.new()
    control.anchors_preset = Control.PRESET_FULL_RECT
    control.size = viewport.size  # 关键：明确设置尺寸
    viewport.add_child(control)
    
    # 3. 添加静态贴图（使用 STRETCH_SCALE 完全覆盖）
    if static_texture:
        var texture_rect = TextureRect.new()
        texture_rect.texture = static_texture
        texture_rect.stretch_mode = TextureRect.STRETCH_SCALE  # 关键：拉伸以完全覆盖
        texture_rect.anchors_preset = Control.PRESET_FULL_RECT
        texture_rect.size = viewport.size
        control.add_child(texture_rect)
    
    # 4. 添加动态文本标签
    var label = Label.new()
    label.text = dynamic_text
    label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
    label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
    label.add_theme_font_size_override("font_size", 96)
    label.add_theme_color_override("font_color", Color.BLACK)
    label.anchors_preset = Control.PRESET_FULL_RECT
    label.size = viewport.size
    control.add_child(label)
    
    # 5. 返回 ViewportTexture（动态生成的贴图）
    return viewport.get_texture()
```

### 4. 备用网格创建（六面独立表面）

```gdscript
func create_fallback_mesh():
    var mesh_instance = MeshInstance3D.new()
    add_child(mesh_instance)
    
    var mesh = ArrayMesh.new()
    
    # 立方体 8 个顶点
    var vertices = [
        Vector3(-0.5, -0.5, -0.5), Vector3(0.5, -0.5, -0.5),
        Vector3(0.5, 0.5, -0.5),   Vector3(-0.5, 0.5, -0.5),
        Vector3(-0.5, -0.5, 0.5),  Vector3(0.5, -0.5, 0.5),
        Vector3(0.5, 0.5, 0.5),    Vector3(-0.5, 0.5, 0.5)
    ]
    
    # 6 个面的顶点索引
    var faces = [
        [0, 1, 2, 3],  # 前面
        [5, 4, 7, 6],  # 后面
        [4, 0, 3, 7],  # 左面
        [1, 5, 6, 2],  # 右面
        [3, 2, 6, 7],  # 顶面
        [4, 5, 1, 0]   # 底面
    ]
    
    # 为每个面创建独立表面（关键：每个面有独立 UV）
    for i in range(6):
        var arrays = []
        arrays.resize(Mesh.ARRAY_MAX)
        
        # 顶点数据
        var surface_vertices = []
        for j in faces[i]:
            surface_vertices.append(vertices[j])
        arrays[Mesh.ARRAY_VERTEX] = PackedVector3Array(surface_vertices)
        
        # 法线数据
        var normal = get_face_normal(i)
        arrays[Mesh.ARRAY_NORMAL] = PackedVector3Array([normal, normal, normal, normal])
        
        # UV 数据（关键：每个面都是完整的 0-1 映射）
        arrays[Mesh.ARRAY_TEX_UV] = PackedVector2Array([
            Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)
        ])
        
        # 索引数据
        arrays[Mesh.ARRAY_INDEX] = PackedInt32Array([0, 1, 2, 0, 2, 3])
        
        mesh.add_surface_from_arrays(Mesh.PRIMITIVE_TRIANGLES, arrays)
    
    mesh_instance.mesh = mesh
    apply_dice_textures(mesh_instance)
```

### 5. 投掷结果检测

```gdscript
func check_dice_value():
    var up_direction = Vector3.UP
    var dice_transform = global_transform
    
    # 六个面的本地方向（与 create_fallback_mesh 的面索引顺序匹配）
    var local_directions = [
        Vector3(0, 0, -1),  # 前面 (索引 0)
        Vector3(0, 0, 1),   # 后面 (索引 1)
        Vector3(-1, 0, 0),  # 左面 (索引 2)
        Vector3(1, 0, 0),   # 右面 (索引 3)
        Vector3(0, 1, 0),   # 顶面 (索引 4)
        Vector3(0, -1, 0)   # 底面 (索引 5)
    ]
    
    # 计算每个面的全局方向
    var global_directions = []
    for local_dir in local_directions:
        global_directions.append(dice_transform.basis * local_dir)
    
    # 找到最接近向上的面（点积最大）
    var max_dot = -1
    closest_index = 0
    for i in range(global_directions.size()):
        var dot = up_direction.dot(global_directions[i])
        if dot > max_dot:
            max_dot = dot
            closest_index = i
    
    has_valid_result = true
    print("骰子结果：面索引 ", closest_index, " 对应点数 ", closest_index + 1)
    print("属性值：", attr_values[closest_index])
```

## ⚠️ 重点问题及解决方案

### 问题 1：贴图只覆盖骰面的 1/4

**现象**：
- 贴图只显示在骰子面的一小部分，大部分区域为黑色

**原因**：
1. `TextureRect` 的 `stretch_mode` 设置为 `STRETCH_KEEP_ASPECT_COVERED`，会保持宽高比但不一定完全覆盖
2. `Control` 节点没有明确设置 `size`，导致 UI 元素没有填满 Viewport

**解决方案**：
```gdscript
# 错误方式
texture_rect.stretch_mode = TextureRect.STRETCH_KEEP_ASPECT_COVERED

# 正确方式
texture_rect.stretch_mode = TextureRect.STRETCH_SCALE  # 强制拉伸以完全覆盖
texture_rect.size = viewport.size  # 明确设置尺寸
control.size = viewport.size  # 父节点也要设置尺寸
```

---

### 问题 2：材质应用失败（索引越界）

**错误信息**：
```
Index p_surface = 5 is out of bounds (surface_override_materials.size() = 0)
Invalid access to property or key 'surface_override_materials'
```

**原因**：
1. `MeshInstance3D` 没有 `surface_override_materials` 属性
2. `set_surface_override_material()` 需要先调整数组大小
3. 不同网格类型的表面数量不同

**解决方案**：
```gdscript
# 错误方式
mesh_instance.set_surface_override_material(i, materials[i])

# 正确方式
var surface_count = mesh_instance.mesh.get_surface_count()
for i in range(min(6, surface_count, materials.size())):
    mesh_instance.mesh.surface_set_material(i, materials[i])
```

**关键点**：
- 使用 `mesh_instance.mesh.surface_set_material()` 而不是 `mesh_instance.set_surface_override_material()`
- 在调用前获取 `surface_count` 并使用 `min()` 确保不越界

---

### 问题 3：Vector3.format() 方法不存在

**错误信息**：
```
Invalid call. Nonexistent function 'format' in base 'Vector3'.
```

**原因**：
- Godot 4 的 `Vector3` 没有 `format()` 方法（与 Godot 3 不同）

**解决方案**：
```gdscript
# 错误方式
print("方向：", global_dir.format(2))

# 正确方式
print("方向：", 
      str(global_dir.x).substr(0, 5) + ", " + 
      str(global_dir.y).substr(0, 5) + ", " + 
      str(global_dir.z).substr(0, 5))
```

### 问题 4：属性文字不显示

**现象**：
- 静态贴图显示正常，但属性数值不显示

**原因**：
1. `Label` 节点没有设置正确的锚点，导致不在 Viewport 内
2. 字体大小太小，在高分辨率下看不清

**解决方案**：
```gdscript
var label = Label.new()
label.anchors_preset = Control.PRESET_FULL_RECT  # 关键：充满整个 Viewport
label.size = viewport.size  # 明确设置尺寸

label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
```

### 问题 5：UV 映射不正确

**现象**：
- 贴图显示但扭曲或重复

**原因**：
1. 材质的 UV1 变换没有设置为默认值
2. 备用网格的 UV 坐标没有正确设置

**解决方案**：

```gdscript
material.uv1_scale = Vector3(1, 1, 1)
material.uv1_offset = Vector3(0, 0, 0)

# 备用网格 UV 坐标（每个面都是完整的 0-1 映射）

    Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)
])
```

## 🔑 核心技术要点

### 1. SubViewport 动态纹理生成

**原理**：
- 创建离屏渲染目标（SubViewport）
- 在 Viewport 中构建 UI 树（Control + TextureRect + Label）
- 将渲染结果作为 Texture2D 返回

**关键设置**：
```gdscript
viewport.render_target_update_mode = SubViewport.UPDATE_ONCE  # 只更新一次，节省性能
viewport.transparent_bg = true  # 透明背景
viewport.size = Vector2i(max(face_size.x, 512), max(face_size.y, 512))  # 足够大以保证清晰
```

### 2. 六面独立映射策略

**核心思想**：
- 每个骰子面是一个独立的表面（surface）
- 每个表面有独立的 UV 坐标（都是 0-1 完整映射）
- 每个表面有独立的材质实例

**实现方式**：
```gdscript
# 为每个面创建独立表面
for i in range(6):
    mesh.add_surface_from_arrays(Mesh.PRIMITIVE_TRIANGLES, arrays)
    
# 为每个表面应用独立材质
for i in range(min(6, surface_count, materials.size())):
    mesh_instance.mesh.surface_set_material(i, materials[i])
```

### 3. 点积检测朝上面

**原理**：
- 计算每个面的全局方向与向上向量 (0,1,0) 的点积
- 点积最大的面最接近向上方向

**数学公式**：
```
dot = up_direction · global_direction
dot ∈ [-1, 1]
dot = 1  → 面朝上
dot = -1 → 面朝下
dot = 0  → 面水平
```

## 📊 性能优化建议

1. **Viewport 更新模式**：使用 `UPDATE_ONCE` 而不是 `UPDATE_ALWAYS`
2. **Viewport 尺寸**：根据骰面大小动态调整，最小 512x512 保证清晰
3. **材质复用**：如果多个骰子使用相同贴图，可以共享材质实例
4. **清理旧 Viewport**：更新贴图时清理旧的 SubViewport，避免内存泄漏

```gdscript
func _cleanup_old_viewports():
    for child in get_children():
        if child is SubViewport and child.name.begins_with("DynamicFaceViewport_"):
            child.queue_free()
```
