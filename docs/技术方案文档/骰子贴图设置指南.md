# 骰子贴图设置指南

## 一、贴图系统概述

### 动态贴图系统
本游戏使用基于 CSV 配置的动态贴图系统，骰子的六个面可以独立设置贴图和点数。

- **配置文件**：通过 CSV 文件配置每个场景的骰子贴图和点数
- **读取器**：使用 `dice_csv_reader.gd` 读取 CSV 配置
- **动态加载**：骰子运行时动态加载贴图和点数配置
- **面索引系统**：骰子六个面使用面索引 0-5，对应不同的方向

### 面索引与方向对应关系
骰子的六个面在代码中的定义如下（与 `create_fallback_mesh` 函数中的面索引顺序匹配）：

| 面索引 | 本地方向 | 对应方向 | 默认点数 |
|--------|----------|----------|----------|
| 0 | `Vector3(0, 0, -1)` | 前面 | 1 点 |
| 1 | `Vector3(0, 0, 1)` | 后面 | 2 点 |
| 2 | `Vector3(-1, 0, 0)` | 左面 | 3 点 |
| 3 | `Vector3(1, 0, 0)` | 右面 | 4 点 |
| 4 | `Vector3(0, 1, 0)` | 顶面 | 5 点 |
| 5 | `Vector3(0, -1, 0)` | 底面 | 6 点 |

### 贴图要求
- **分辨率**：建议 512x512 或 1024x1024
- **格式**：PNG 格式
- **风格**：与游戏整体风格一致
- **清晰度**：点数清晰可见，易于识别

## 二、贴图文件准备

### 贴图文件命名规范
将骰子六个面的贴图文件保存在 `textures/dice/` 目录下，命名建议包含面索引或点数信息：

| 文件名示例 | 对应面索引 | 对应点数 | 对应方向 |
|--------|---------|----------|----------|
| `dice_face_0.png` 或 `dice_1.png` | 0 | 1 点 | 前面 (Vector3(0, 0, -1)) |
| `dice_face_1.png` 或 `dice_2.png` | 1 | 2 点 | 后面 (Vector3(0, 0, 1)) |
| `dice_face_2.png` 或 `dice_3.png` | 2 | 3 点 | 左面 (Vector3(-1, 0, 0)) |
| `dice_face_3.png` 或 `dice_4.png` | 3 | 4 点 | 右面 (Vector3(1, 0, 0)) |
| `dice_face_4.png` 或 `dice_5.png` | 4 | 5 点 | 顶面 (Vector3(0, 1, 0)) |
| `dice_face_5.png` 或 `dice_6.png` | 5 | 6 点 | 底面 (Vector3(0, -1, 0)) |

### 导入步骤
1. **打开 Godot 编辑器**
2. **在文件系统面板中**，导航到 `textures/dice/` 目录
3. **将贴图文件拖放到** `textures/dice/` 目录中
4. **等待 Godot 自动导入**贴图资源

## 三、CSV 配置文件

### CSV 文件格式
CSV 配置文件用于定义不同场景的骰子贴图和点数配置。

```csv
scene_name,face_index,texture_path,dice_value
1001,0,res://textures/dice/dice_face_0.png,1
1001,1,res://textures/dice/dice_face_1.png,2
1001,2,res://textures/dice/dice_face_2.png,3
1001,3,res://textures/dice/dice_face_3.png,4
1001,4,res://textures/dice/dice_face_4.png,5
1001,5,res://textures/dice/dice_face_5.png,6
```

### 配置说明
- **scene_name**：场景名称（如 1001、1002）
- **face_index**：面索引（0-5）
- **texture_path**：贴图资源路径（`res://` 开头）
- **dice_value**：对应的点数（1-6）

### 使用方法
1. 在 CSV 配置文件中定义场景的骰子配置
2. 使用 `dice_csv_reader.gd` 读取配置
3. 通过 `dice_manager.set_scene_config(scene_name)` 切换场景配置
4. 骰子会自动加载对应的贴图和点数配置

## 四、骰子材质设置

### 自动加载机制
骰子脚本 `dice_6.gd` 中的 `apply_dice_textures()` 函数会自动处理贴图加载：

1. 从 `dice_face_config` 字典获取每个面的贴图路径
2. 为每个面创建独立的 `StandardMaterial3D` 材质
3. 尝试加载贴图，如果失败则使用备用颜色
4. 将材质应用到骰子网格的对应表面

### 备用颜色系统
如果贴图加载失败，系统会使用备用颜色：

```gdscript
var id_colors = {
    1: Color(1, 0, 0, 1),   # 红色
    2: Color(0, 1, 0, 1),   # 绿色
    3: Color(0, 0, 1, 1),   # 蓝色
    4: Color(1, 1, 0, 1),   # 黄色
    5: Color(1, 0, 1, 1),   # 紫色
    6: Color(0, 1, 1, 1),   # 青色
    7: Color(1, 0.5, 0, 1), # 橙色
    8: Color(0.5, 0, 0.5, 1), # 深紫色
    9: Color(0, 0.5, 0.5, 1)  # 深青色
}
```

## 五、验证结果检测与贴图一致

### 测试方法
1. **在编辑器中**，手动旋转骰子，检查贴图显示是否正确
2. **运行游戏**，测试骰子投掷后的结果检测
3. **观察**骰子停止后，贴图显示的点数与游戏检测的结果是否一致
4. **测试多个骰子**同时投掷的情况
5. **切换场景配置**，验证不同场景的贴图配置是否正确加载

### 调试技巧
- 启用打印日志，查看贴图加载信息
- 检查 `dice_face_config` 和 `dice_value_config` 字典内容
- 验证 CSV 配置文件格式是否正确

## 六、故障排除

### 贴图不显示
- 检查贴图文件是否正确导入到 `textures/dice/` 目录
- 检查 CSV 配置文件中的贴图路径是否正确
- 检查贴图路径是否以 `res://` 开头
- 查看控制台日志，确认贴图是否成功加载

### 结果检测与贴图不一致
- 检查 CSV 配置文件中的 `dice_value` 是否正确
- 检查 `check_dice_value()` 函数中的面索引方向定义
- 确保骰子模型的 UV 映射正确
- 验证面索引与方向的对应关系

### 性能问题
- 优化贴图分辨率，避免使用过高分辨率的贴图
- 确保贴图格式正确，避免使用过大的文件
- 考虑使用纹理压缩

## 七、示例代码

### 设置骰子配置
```gdscript
# 在 dice_manager.gd 中
func set_scene_config(scene_name: String):
    current_scene = scene_name
    var dice_config = dice_csv_reader.get_num_dice_config(scene_name)
    var scene_config = dice_config.get("textures", {})
    var value_config = dice_config.get("values", {})
    
    # 更新所有骰子的贴图配置和点数配置
    for dice in dice_instances:
        if dice and is_instance_valid(dice) and dice.has_method("set_dice_face_config"):
            dice.set_dice_face_config(scene_config, value_config)
```

### 动态更新骰子贴图
```gdscript
# 在 dice_6.gd 中
func set_dice_face_config(config: Dictionary, value_config: Dictionary = {}):
    dice_face_config = config
    dice_value_config = value_config
    update_dice_textures()
```

## 八、注意事项

1. **UV 映射**：确保骰子模型的 UV 映射正确，否则贴图可能显示不正确
2. **物理参数**：调整骰子的物理参数，确保滚动效果自然
3. **结果检测**：验证结果检测的准确性，确保结果与贴图显示一致
4. **性能**：优化贴图和材质设置，确保游戏运行流畅
5. **CSV 配置**：确保 CSV 配置文件格式正确，包含面索引、贴图路径和点数配置
6. **路径正确性**：确保所有贴图路径都以 `res://` 开头，并且文件确实存在

当您完成贴图的创建和导入后，按照本指南进行设置，即可确保骰子的贴图显示与结果检测一致。
