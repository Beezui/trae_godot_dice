## 使用说明
1. 此模板已调整为16:9比例，与游戏视窗一致
2. 摄像机角度已优化，提供伪3D俯视视角
3. 墙壁可见高度已提升50%，增强视觉效果
4. 碰撞区域保持完整，确保游戏机制正常
5. 顶部设置了碰撞形状，防止骰子弹出摄像机视野
6. 可基于此模板创建不同的战斗场景

- 保持沙盘与视窗比例一致
- 如需调整摄像机，建议保持类似的倾斜角度以维持3D效果
- 墙壁碰撞区域应保持足够高度，防止骰子跳出

- 墙壁底部已与地面完全连接，确保无间隙
