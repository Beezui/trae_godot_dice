# 沙盘战斗模板配置

## 基本信息
- **创建日期**: 2026-03-03
- **场景文件**: `res://scenes/dice_demo_simple_final.tscn`
- **用途**: 作为日后创建新场景的标准模板

## 摄像机配置

### 位置与旋转
- **Transform**: `Transform3D(1, 0, 0, 0, 0.7071, -0.7071, 0, 0.7071, 0.7071, 0, 15, 0)`
- **位置**: (0, 15, 0) （优化高度，确保沙盘充满屏幕）
- **旋转角度**: 约45度倾斜（提供更好的3D效果）

### 投影设置
- **投影模式**: 透视投影 (`projection = 0`)
- **FOV**: 60.0度（标准视角，确保沙盘充满屏幕）
- **效果**: 良好的3D透视效果，同时确保沙盘完全可见

## 沙盘配置

### 基本设置
- **类型**: StaticBody3D
- **Transform**: `Transform3D(1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)` (默认坐标系)

### 地面
- **尺寸**: 动态调整（基于窗口比例）
- **碰撞形状**: BoxShape3D(size = Vector3(sandbox_width, 0.1, sandbox_height))
- **网格缩放**: Vector3(sandbox_width, 0.1, sandbox_height)
- **材质**: 灰色 (albedo_color = Color(0.5, 0.5, 0.5, 1))

### 墙壁

#### 北墙（屏幕上方）
- **碰撞形状**: BoxShape3D(size = Vector3(sandbox_width, 10, 0.1))
- **碰撞位置**: (-sandbox_width/2, 0, 0) (在Sandbox局部坐标系中)
- **网格位置**: (-sandbox_width/2, -3.95, 0) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(0.1, 3, sandbox_height) (可见高度3)
- **材质**: 蓝色 (albedo_color = Color(0.3, 0.3, 0.7, 1))

#### 南墙（屏幕下方）
- **碰撞形状**: BoxShape3D(size = Vector3(sandbox_width, 10, 0.1))
- **碰撞位置**: (sandbox_width/2, 0, 0) (在Sandbox局部坐标系中)
- **网格位置**: (sandbox_width/2, -3.95, 0) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(0.1, 3, sandbox_height) (可见高度3)
- **材质**: 红色 (albedo_color = Color(0.7, 0.3, 0.3, 1))

#### 东墙（屏幕右侧）
- **碰撞形状**: BoxShape3D(size = Vector3(0.1, 10, sandbox_height))
- **碰撞位置**: (0, 0, -sandbox_height/2) (在Sandbox局部坐标系中)
- **网格位置**: (0, -3.95, -sandbox_height/2) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(sandbox_width, 3, 0.1) (可见高度3)
- **材质**: 黄色 (albedo_color = Color(0.7, 0.7, 0.3, 1))

#### 西墙（屏幕左侧）
- **碰撞形状**: BoxShape3D(size = Vector3(0.1, 10, sandbox_height))
- **碰撞位置**: (0, 0, sandbox_height/2) (在Sandbox局部坐标系中)
- **网格位置**: (0, -3.95, sandbox_height/2) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(sandbox_width, 3, 0.1) (可见高度3)
- **材质**: 绿色 (albedo_color = Color(0.3, 0.7, 0.3, 1))

#### 顶部碰撞
- **碰撞形状**: BoxShape3D(size = Vector3(sandbox_width, 0.5, sandbox_height))
- **碰撞位置**: (0, 8, 0) (在Sandbox局部坐标系中)
- **用途**: 防止骰子跳出摄像机视野

### 碰撞区域
- **碰撞高度**: 10 (确保骰子无法跳出)
- **可见高度**: 3
- **边界范围**: 宽度16，深度根据窗口比例动态调整
- **顶部碰撞**: 在Y=8位置设置碰撞形状，防止骰子弹出摄像机视野

## 光照设置
- **类型**: DirectionalLight3D
- **位置**: (10, 10, 10)
- **旋转**: Transform3D(0.7071, 0.5, 0.5, 0, 0.7071, -0.7071, -0.7071, 0.5, 0.5)
- **效果**: 提供良好的阴影和光照效果

## 骰子设置
- **初始位置**: (0, 3, -sandbox_height/2 + 0.5) (屏幕靠下位置，悬浮状态)
- **投掷位置**: (0, 5, -sandbox_height/2 + 0.5) (离地面5个骰子高度)
- **类型**: 实例化的骰子场景
- **投掷力**: 
  - 蓄力投掷：根据蓄力时间计算，最大力度20
  - 方向：随机-45°到45°

## 视窗设置
- **分辨率**: 动态调整（基于实际窗口大小）
- **与沙盘比例**: 自动保持一致
- **比例计算**: sandbox_height = base_width * window_ratio  # 蓝色墙体长度
- **base_width**: 16.0（绿色墙体长度，基础宽度）
- **比例关系**: 蓝色墙体长度 : 绿色墙体长度 = 屏幕宽度 : 屏幕高度

## 控制设置
- **空格键**: 蓄力投掷骰子（根据按下时间增加力度）
- **R键**: 恢复骰子初始状态（悬浮在屏幕靠下位置）

## 使用说明
1. 此模板会自动根据窗口比例调整沙盘尺寸
2. 摄像机角度已优化，提供良好的3D俯视视角
3. 墙壁可见高度为3，增强视觉效果
4. 碰撞区域保持完整，确保游戏机制正常
5. 顶部设置了碰撞形状，防止骰子弹出摄像机视野
6. 可基于此模板创建不同的战斗场景
7. 墙壁颜色已按照屏幕方向标准化：北（上）- 蓝色，南（下）- 红色，西（左）- 绿色，东（右）- 黄色

## 注意事项
- 沙盘会自动适配窗口比例，保持16:9的基础比例
- 如需调整摄像机，建议保持类似的倾斜角度以维持3D效果
- 墙壁碰撞区域应保持足够高度，防止骰子跳出
- 可根据需要调整FOV和摄像机高度以获得最佳视角
- 墙壁底部已与地面完全连接，确保无间隙
- 骰子模型已使用圆滑边缘设计，提升滚动效果
