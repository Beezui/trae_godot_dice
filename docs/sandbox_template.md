# 沙盘战斗模板配置

## 基本信息
- **创建日期**: 2026-03-02
- **场景文件**: `res://scenes/dice_demo_simple_final.tscn`
- **用途**: 作为日后创建新场景的标准模板

## 摄像机配置

### 位置与旋转
- **Transform**: `Transform3D(1, 0, 0, 0, 0.9659, -0.2588, 0, 0.2588, 0.9659, 0, 20, 0)`
- **位置**: (0, 20, 0) （优化高度，确保沙盘充满屏幕）
- **旋转角度**: 约15度倾斜（接近2D效果，同时保持立体感）

### 投影设置
- **投影模式**: 透视投影 (`projection = 0`)
- **FOV**: 30.0度（缩小FOV以降低透视效果，更贴近2D效果）
- **效果**: 低透视效果，接近2D视角，同时通过轻微倾斜保持沙盘高度和骰子的立体感

## 沙盘配置

### 基本设置
- **类型**: StaticBody3D
- **Transform**: `Transform3D(0, 0, -1, 0, 1, 0, 1, 0, 0, 0, 4, 0)` (旋转90度)

### 地面
- **尺寸**: 16 x 9 (16:9比例)
- **碰撞形状**: BoxShape3D(size = Vector3(16, 0.1, 9))
- **网格缩放**: Vector3(16, 0.1, 9)
- **材质**: 灰色 (albedo_color = Color(0.5, 0.5, 0.5, 1))

### 墙壁

#### 北墙
- **碰撞形状**: BoxShape3D(size = Vector3(16, 10, 0.1))
- **碰撞位置**: (0, 0, 4.5) (在Sandbox局部坐标系中)
- **网格位置**: (0, -3.95, 4.5) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(16, 3, 0.1) (可见高度3)
- **材质**: 红色 (albedo_color = Color(0.7, 0.3, 0.3, 1))

#### 南墙
- **碰撞形状**: BoxShape3D(size = Vector3(16, 10, 0.1))
- **碰撞位置**: (0, 0, -4.5) (在Sandbox局部坐标系中)
- **网格位置**: (0, -3.95, -4.5) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(16, 3, 0.1) (可见高度3)
- **材质**: 红色 (albedo_color = Color(0.7, 0.3, 0.3, 1))

#### 东墙
- **碰撞形状**: BoxShape3D(size = Vector3(0.1, 10, 9))
- **碰撞位置**: (8, 0, 0) (在Sandbox局部坐标系中)
- **网格位置**: (8, -3.95, 0) (在Sandbox局部坐标系中)

- **材质**: 红色 (albedo_color = Color(0.7, 0.3, 0.3, 1))

#### 西墙
- **碰撞形状**: BoxShape3D(size = Vector3(0.1, 10, 9))
- **碰撞位置**: (-8, 0, 0) (在Sandbox局部坐标系中)
- **网格位置**: (-8, -3.95, 0) (在Sandbox局部坐标系中)
- **网格缩放**: Vector3(0.1, 3, 9) (可见高度3)
- **材质**: 红色 (albedo_color = Color(0.7, 0.3, 0.3, 1))

#### 顶部碰撞
- **碰撞形状**: BoxShape3D(size = Vector3(16, 0.5, 9))
- **碰撞位置**: (0, 8, 0) (在Sandbox局部坐标系中)
- **用途**: 防止骰子跳出摄像机视野

### 碰撞区域
- **碰撞高度**: 10 (确保骰子无法跳出)
- **可见高度**: 3
- **边界范围**: 宽度16，深度9
- **顶部碰撞**: 在Y=8位置设置碰撞形状，防止骰子弹出摄像机视野

## 光照设置
- **类型**: DirectionalLight3D
- **位置**: (10, 10, 10)
- **旋转**: Transform3D(0.7071, 0.5, 0.5, 0, 0.7071, -0.7071, -0.7071, 0.5, 0.5)
- **效果**: 提供良好的阴影和光照效果

## 骰子设置
- **初始位置**: (0, 2, 0) (屏幕靠下位置，悬浮状态)
- **投掷位置**: (0, 5, 0) (离地面5个骰子高度)
- **类型**: 实例化的骰子场景
- **投掷力**: 
  - X: randf_range(-5, 5)
  - Y: randf_range(5, 7.5)
  - Z: randf_range(-5, 5)

## 视窗设置
- **分辨率**: 1280x720 (16:9比例)
- **与沙盘比例**: 保持一致

## 控制设置
- **空格键**: 手动投掷骰子
- **R键**: 恢复骰子初始状态（悬浮在屏幕靠下位置）

## 使用说明
1. 此模板已调整为16:9比例，与游戏视窗一致
2. 摄像机角度已优化，提供伪3D俯视视角
3. 墙壁可见高度为3，增强视觉效果
4. 碰撞区域保持完整，确保游戏机制正常
5. 顶部设置了碰撞形状，防止骰子弹出摄像机视野
6. 可基于此模板创建不同的战斗场景

## 注意事项
- 保持沙盘与视窗比例一致
- 如需调整摄像机，建议保持类似的倾斜角度以维持3D效果
- 墙壁碰撞区域应保持足够高度，防止骰子跳出
- 可根据需要调整FOV和摄像机高度以获得最佳视角
- 墙壁底部已与地面完全连接，确保无间隙
- 骰子模型已使用圆滑边缘设计，提升滚动效果
