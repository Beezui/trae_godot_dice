# 游戏主入口场景实现说明

## 创建时间
2026-04-20

## 实现内容

### 1. 全局加载动画覆盖层 (LoadingOverlay)
**文件**: `scripts/ui/loading_overlay.gd`

**功能**:
- 黑色蒙版淡入淡出效果
- 用于场景切换时的加载动画
- 全局单例，任何场景都可使用

**使用方法**:
```gdscript
# 淡入
LoadingOverlay.fade_in(0.3)
await LoadingOverlay.wait_fade_in()

# 切换场景
get_tree().change_scene_to_file("res://scenes/xxx.tscn")

# 淡出
LoadingOverlay.fade_out(0.3)
await LoadingOverlay.wait_fade_out()
```

### 2. 游戏主入口场景 (GameMain)
**文件**: 
- `scenes/game_main/game_main.gd`
- `scenes/game_main/game_main.tscn`

**功能**:
- 作为关卡网的初始节点（奖励关卡）
- 玩家角色入场
- 命运骰子生成与投掷
- 地图 UI 集成（按 M 键切换）
- 关卡转换协调

**流程**:
```
角色选择完成 → 加载动画 → GameMain 场景
    ↓
玩家角色入场（3D 场景 + 角色骰子）
    ↓
命运骰子生成（投掷区域）
    ↓
玩家按空格投掷命运骰子
    ↓
选择下一节点
    ↓
加载动画 → 关卡转换
```

**操作**:
- `M` 键：切换地图显示
- `空格键`：蓄力投掷命运骰子

### 3. 角色选择界面 (CharacterSelect)
**文件**:
- `scenes/ui/character_select/character_select.gd`
- `scenes/ui/character_select/character_select.tscn`

**功能**:
- 从 `hero.json` 加载玩家角色
- 支持选择最多 3 个角色
- 点击卡片选择/取消选择
- 确认后传递英雄 ID 列表到游戏主入口

**UI 布局**:
- 标题："选择你的角色"
- 角色卡片容器（横向排列）
- 确认按钮："确认开始游戏"
- 提示标签

### 4. 标题界面 (TitleScreen)
**文件**:
- `scenes/ui/title_screen/title_screen.gd`
- `scenes/ui/title_screen/title_screen.tscn`

**功能**:
- 游戏标题显示
- 开始游戏按钮 → 角色选择界面
- 退出游戏按钮 → 退出应用

**UI 布局**:
- 标题："晋升吧骰子"
- 开始游戏按钮
- 退出游戏按钮

## 游戏完整流程

```
[标题界面] (title_screen.tscn)
    │
    ▼ (点击开始游戏)
[加载动画] (LoadingOverlay 淡入淡出)
    │
    ▼
[角色选择界面] (character_select.tscn)
    │
    ▼ (确认开始游戏)
[加载动画]
    │
    ▼
[游戏主入口场景] (game_main.tscn)
    │
    ├─ 玩家角色入场（3D 场景）
    ├─ 角色骰子生成
    └─ 命运骰子生成
    │
    ▼ (按空格投掷)
[命运骰子投掷]
    │
    ▼ (选择节点)
[关卡转换]
    │
    └─→ (后续接入战斗场景/奇遇场景等)
```
