# 命运骰子测试场景说明

## 场景文件
- **场景路径**: `res://scenes/test/destiny_dice_sandbox_test.tscn`
- **脚本路径**: `res://scripts/test/destiny_dice_sandbox_test.gd`
- **地图 UI 脚本**: `res://scripts/ui/destiny_dice_map_overlay.gd`

## 功能特性

### 1. 3D 沙盘环境
- 使用标准沙盘模板（24x13.5，16:9 比例）
- 四面墙壁：北（蓝）、南（红）、东（黄）、西（绿）
- 重力加速度：39.2 m/s²（4 倍重力）

### 2. 关卡系统
- 使用 `LevelGenerator` 自动生成关卡网
- 显示所有节点和连接关系
- 支持所有节点类型（战斗、奇遇、交易、奖励、精英、Boss）

### 3. 命运骰子
- 使用 `DestinyDiceManager` 管理
- 根据当前节点生成对应的骰面配置
- 投掷后自动选择目标节点

### 4. 地图 UI
- 按 **M 键** 切换地图显示/隐藏
- 显示节点类型颜色
- 当前节点用亮黄色高亮显示
- 显示蓄力百分比

## 操作说明

| 按键 | 功能 |
|------|------|
| **空格** | 蓄力投掷（按住蓄力，松开投掷） |
| **M** | 切换地图显示 |
| **R** | 重置骰子位置 |
| **Home** | 高位视角 |
| **End** | 低位视角 |
| **Page Up** | 广角视角 |
| **Page Down** | 默认视角 |

## 投掷系统

### 蓄力投掷流程
1. **按下空格** - 调用 `DiceThrowController.start_charge()`
2. **蓄力中** - 每帧调用 `update_charge(delta)` 更新蓄力比例
3. **震动效果** - 调用 `apply_shake()` 使骰子震动
4. **UI 显示** - 更新蓄力百分比（0-100%）
5. **松开空格** - 调用 `end_charge(dices)` 投掷

### 蓄力参数
- 最大蓄力时间：2.0 秒
- 最大投掷力度：20.0
- 最小力度比例：0.3（30%）
- 震动幅度：0.05
- 震动频率：15-40 Hz

## 地图显示

### 节点颜色
| 类型 | 颜色 |
|------|------|
| 战斗 | 红色 |
| 奇遇 | 蓝色 |
| 交易 | 黄色 |
| 奖励 | 绿色 |
| 精英战斗 | 深红色 |
| Boss | 紫色 |

### 当前节点高亮
- 背景色：亮黄色（`Color(1, 1, 0.3)`）
- 边框：金色，4 像素宽

## 运行步骤

1. 在 Godot 编辑器中打开项目
2. 设置主场景为 `res://scenes/test/destiny_dice_sandbox_test.tscn`
3. 运行场景（F5）
4. 按空格键蓄力投掷命运骰子
5. 按 M 键查看/隐藏地图
6. 观察当前节点在地图上的高亮显示

## 注意事项

1. **投掷区域**：骰子初始位置为 `(0, 4, 4.75)`，靠近南墙但不超出
2. **投掷方向**：朝向屏幕上方（z 轴负方向）
3. **蓄力时间**：建议蓄力 0.5-1.5 秒，力度适中
4. **地图刷新**：投掷完成后自动更新当前节点位置
