# 技能系统架构文档

## 概述

技能系统为游戏提供统一的技能管理、调用和执行机制。所有技能独立于场景运行，可在任意场景中通过技能 ID 调用。

## 核心设计原则

1. **技能独立性** - 技能代码不依赖任何特定场景
2. **参数化设计** - 所有需要的数据通过参数传递
3. **统一接口** - 通过 SkillManager 统一调用
4. **配置驱动** - 技能行为由 skill.json 配置决定

## 核心类说明

### SkillManager (Autoload)

**路径**: `res://skills/skill_manager.gd`

**功能**:
- 统一管理所有技能
- 提供全局技能调用接口
- 管理技能冷却
- 自动注册技能

**公共方法**:
```gdscript
# 调用技能
# 参数：
#   skill_id: 技能 ID (如 "10001")
#   caster: 施法者节点 (可选)
#   targets: 目标数组 (可选)
#   params: 额外参数 (可选，包含骰子结果、场景节点等)
# 返回：是否成功释放
func use_skill(skill_id: String, caster: Node = null, targets: Array = [], params: Dictionary = {}) -> bool

# 注册技能
func register_skill(skill_id: String, skill_instance: RefCounted)

# 检查技能是否可用
func can_use_skill(skill_id: String) -> bool

# 清除所有冷却
func clear_cooldowns()

# 获取所有已注册的技能 ID
func get_all_skill_ids() -> Array

# 获取技能配置
func get_skill(skill_id: String) -> Dictionary
```

**使用示例**:
```gdscript
# 在任何场景中调用技能
var caster = self
var targets = [enemy1, enemy2]
var params = {
    "dice_results": {"str": 5, "agi": 3, "int": 4},
    "scene": self  # 传递当前场景节点
}
SkillManager.use_skill("10001", caster, targets, params)
```

### FireballSkill (火球术)

**路径**: `res://skills/fireball_skill.gd`

**技能 ID**: 10001

**效果**: 向目标发射火球，造成范围伤害

**伤害公式**: `str*2 + agi*2`

**参数**:
- `fireball_speed`: 火球飞行速度 (25.0)
- `explosion_radius`: 爆炸半径 (2.0)

**关键方法**:
```gdscript

func init(config: Dictionary) -> void

# 执行技能
func execute(caster: Node = null, targets: Array = [], params: Dictionary = {}) -> void

# 清理效果
func cleanup() -> void

# 伤害计算
func calculate_damage(formula: String, dice_results: Dictionary) -> int
```

### BlizzardSkill (暴风雪)

**路径**: `res://skills/blizzard_skill.gd`

**技能 ID**: 10002

**效果**: 在目标区域降下暴风雪，持续造成伤害

**伤害公式**:

## 技能调用流程

```
1. 场景调用 SkillManager.use_skill()
   参数包含：
   - caster: 施法者节点
   - targets: 目标数组
   - params: {
       "dice_results": {...},
       "scene": current_scene  # 重要：传递场景节点
     }
   ↓
2. SkillManager 检查技能是否存在和冷却
   ↓
3. 获取技能实例
   ↓
4. 调用 skill.execute(caster, targets, params)
   ↓
5. 技能从 params 中获取 scene 节点
   ↓
6. 技能创建效果并添加到场景
   ↓
7. 效果结束时调用 cleanup()
```

## 开发指南

### 添加新技能

1. **创建技能类**:
```gdscript

extends RefCounted

var skill_config: Dictionary = {}
var is_executing: bool = false

func init(config: Dictionary) -> void:
    skill_config = config

func execute(caster: Node = null, targets: Array = [], params: Dictionary = {}) -> void:
    # 获取场景节点
    var scene_node: Node = params.get("scene", null)
    if not scene_node and caster:
        scene_node = caster.get_tree().current_scene
    
    # 实现技能逻辑
    pass

func cleanup() -> void:
    is_executing = false

func calculate_damage(formula: String, dice_results: Dictionary) -> int:
    # 实现伤害计算
    pass
```

2. **在 SkillManager 中注册**:
```gdscript
# skills/skill_manager.gd
func _create_skill_instance(skill_id: String) -> RefCounted:
    match skill_id:
        "10003":  # 新技能 ID
            return preload("res://skills/new_skill.gd").new()
```

3. **添加配置到 skill.json**:
```json
{
  "id": "10003",
  "name": "新技能",
  ...
}
```

## 重要注意事项

### 1. 场景节点传递
**必须**在 params 中传递场景节点，否则技能效果无法添加到场景：
```gdscript
var params = {
    "dice_results": {...},
    "scene": self  # 必需
}
```

### 2. 技能独立性
技能代码不能硬编码引用任何场景节点，所有需要的数据必须通过参数传递：
- ❌ `var target = get_node("Target")` 
- ✅ `var target = targets[0]`

### 3. 资源管理
技能创建的临时对象必须正确清理：
```gdscript
func cleanup() -> void:
    is_executing = false
    if current_effect:
        current_effect.queue_free()
        current_effect = null
```

### 4. 错误处理
处理目标不存在、配置缺失等异常情况：
```gdscript
if targets.is_empty():
    print("错误：没有目标")
    cleanup()
    return

if not scene_node:
    print("警告：无法获取场景节点")
```

### 5. Timer 使用规范
Timer 必须在添加到场景树后才能调用 start()：
```gdscript
var timer = Timer.new()
scene_node.add_child(timer)  # 先添加到场景
timer.start()  # 再启动
```

### 6. 对象有效性检查
在 queue_free() 前检查对象是否有效：
```gdscript
if is_instance_valid(obj):
    obj.queue_free()
```

## 已知 Bug 修复记录

### v1.0.1 修复内容

1. **技能无法添加到场景**
   - 问题：使用 `Engine.has_singleton("SceneProvider")` 但该单例不存在
   - 修复：通过 params 传递场景节点，或从 caster.get_tree().current_scene 获取

2. **Timer 启动错误**
   - 问题：Timer 在添加到场景树前调用 start()
   - 修复：确保先 add_child() 再 start()

3. **作用域错误**
   - 问题：`_trigger_explosion()` 和 `_on_fireball_hit()` 缺少 scene_node 参数
   - 修复：添加 scene_node 参数并通过 Tween 回调传递

4. **类型声明问题**
   - 问题：使用 SkillBase 类型但该基类已被移除
   - 修复：所有类型改为 RefCounted

5. **对象清理问题**
   - 问题：直接调用 queue_free() 可能导致崩溃
   - 修复：使用 is_instance_valid() 检查后再清理
