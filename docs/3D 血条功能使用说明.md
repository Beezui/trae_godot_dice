# 3D 血条功能使用说明

## 功能概述

为角色骰子添加了 3D 血条显示功能，血条贴在骰子朝上面与面向屏幕面的交界边处。

## 特性

- **3D 血条**：使用 MeshInstance3D 制作，贴在骰子表面
- **数值显示**：HP 数值显示在血条上（使用 Label3D）
- **动态颜色**：根据血量百分比自动变化（绿→黄→红）
- **平滑过渡**：血量变化时血条平滑动画过渡
- **自动创建**：角色骰子入场并完全稳定后自动创建

## 血条设计

```
Dice6 (RigidBody3D)
├── CollisionShape3D
├── MeshInstance3D
└── HealthBar3D (Node3D)  ← 3D 血条
    ├── Background (MeshInstance3D)  ← 深色背景框
    ├── Fill (MeshInstance3D)        ← 彩色填充条
    └── HPText (Label3D)             ← 3D 文字显示
```

## 颜色渐变

| 血量百分比 | 颜色 |
|-----------|------|
| 100% | 绿色 (0.2, 0.8, 0.2) |
| 50%  | 黄色 (0.8, 0.8, 0.2) |
| 0%   | 红色 (0.8, 0.2, 0.2) |

## 使用方式

### 1. 角色骰子创建时（自动创建血条）

```gdscript
# 使用 DiceManager 创建角色骰子时，血条会自动创建
var dice = DiceManager.create_character_dice(character, sandbox, position)
# 骰子锁定后会自动创建血条，无需额外代码
```

### 2. HP 变化时（自动更新血条）

```gdscript
# 受到伤害（血条自动更新）
character.take_damage(10)

# 治疗（血条自动更新）
character.heal(20)
```

### 3. 手动更新血条

```gdscript
# 如果需要手动更新血条
character.update_health_bar()

# 或者直接设置血条百分比
if dice.health_bar:
    dice.health_bar.set_hp_percent(0.5)  # 设置为 50%
    dice.health_bar.update_hp_text(50, 100)  # 更新文字显示
```

## 测试场景

### character_test_arena.gd

- **Home 键**：受到 10 点伤害（测试血条减少）
- **End 键**：恢复 10 点 HP（测试血条增加）

### 测试步骤

1. 打开 `scenes/character_test_arena.tscn` 场景
2. 运行场景，等待角色骰子投掷并稳定
3. 血条会自动创建在骰子上
4. 按 **Home** 键扣血，观察血条平滑减少和颜色变化
5. 按 **End** 键加血，观察血条平滑增加

## 配置文件

### 血条参数调整（scripts/ui/dice_health_bar_3d.gd）

```gdscript
# 血条尺寸配置
var bar_length: float = 0.9       # 血条长度（相对于骰子边长的比例）
var bar_height: float = 0.08      # 血条高度
var bar_thickness: float = 0.04   # 血条厚度
var offset_from_edge: float = 0.05  # 距离边的偏移

# 平滑过渡速度
var lerp_speed: float = 5.0  # 血量变化平滑速度

# 颜色配置
var color_full: Color = Color(0.2, 0.8, 0.2)  # 绿色（100% HP）
var color_half: Color = Color(0.8, 0.8, 0.2)  # 黄色（50% HP）
var color_low: Color = Color(0.8, 0.2, 0.2)   # 红色（0% HP）
```

## 注意事项

1. **血条创建时机**：血条在角色骰子完全稳定后创建（`_on_final_wait_timeout()` 调用 `create_health_bar()`）
2. **角色关联**：骰子必须通过 `set_character()` 方法与角色关联，血条才能正确更新
3. **DiceManager**：建议使用 `DiceManager.create_character_dice()` 创建角色骰子，会自动处理角色关联
